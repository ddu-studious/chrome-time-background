> 状态：原 18 个业务设计资产已完成并验收；YouTube 页面组已按独立 UI 规范扩展，当前共 19 个业务、121 个页面

> 设计母题：**夜色山水上的个人桌面工作台**

## 1. 本轮目标

v4 为原 18 个业务建立了统一视觉方向和一张代表性界面；v5 将每个业务扩展为可落地的页面组。YouTube 于 v3.20.0 作为第 19 个业务加入，覆盖连接、浏览、播放、本地清单、搜索与异常恢复。

每张设计图只展示一个真实页面或状态，不使用“一张图塞多个小界面”的情绪板。设计图位于 [`output/imagegen/v5-multi-screen/`](../../output/imagegen/v5-multi-screen/)，按业务分目录保存。

## 2. 全局设计约束

### 2.1 视觉语言

- 背景：真实但低干扰的中国夜色山水，主要内容区背后适度压暗。
- 容器：深蓝黑半透明工作台；外层可用毛玻璃，内层卡片使用更实的深色表面。
- 强调：紫色 `#8b6cff` 只用于主操作、当前导航和进度；红色只用于网易云来源标识、危险动作或错误。
- 字体：中文无衬线；标题 22px，面板标题 18px，正文 14px，辅助信息不低于 13px。
- 组件：16–20px 大容器圆角、12px 卡片圆角、40–44px 主按钮、36px 图标按钮。
- 图标：统一线性风格；不能只靠图标表达关键动作，复杂操作必须有文字标签。
- 密度：桌面端 16:9 或 16:10 单屏；主要内容无需滚动即可看清核心路径，但保留真实滚动边界。

### 2.2 页面结构

```text
桌面背景
└── 应用容器
    ├── 标题栏：业务名称 / 当前上下文 / 全局操作 / 关闭
    ├── 一级导航：最多 4 项，低频操作进入“更多”
    ├── 主内容：列表、画布、正文或播放器
    ├── 上下文区：详情抽屉、检查器或辅助面板
    └── 状态反馈：加载、空、错误、离线、权限、未保存
```

### 2.3 交互状态必须成套

每个业务至少包含：

1. 默认有数据状态。
2. 用户选择对象后的详情状态。
3. 新建或编辑状态。
4. 空状态或首次使用状态。
5. 错误、离线、权限或连接异常状态（按业务选择）。

## 4. 网易云音乐详细设计

网易云音乐作为 v5 的细节样板。页面之间共享同一播放器状态：关闭面板不停止音乐，切换导航不重建播放进度，断开连接必须从“更多”菜单主动执行。

### 4.2 信息层级

- 标题栏：`网易云音乐`、当前账号、搜索、最小化、关闭。
- 主导航：`正在播放 / 队列 / 歌单 / 发现`；歌词由正在播放页进入沉浸态。
- 常驻播放条：封面、歌曲、上一首、播放/暂停、下一首、进度、音量；除沉浸歌词页外保持可见。
- 详情页返回使用面包屑或明确的“返回歌单/返回歌手”，不把关闭按钮当返回。
- 搜索页优先展示单曲结果，搜索类型采用二级分段控件。

### 4.3 状态规则

- 未连接：保留本地队列和当前播放信息，网络能力显示不可用原因。
- 无歌词：展示封面、歌曲介绍和“暂未收录歌词”，不显示空白大区域。
- 队列为空：提供“前往发现”和“播放本地历史”两个入口。
- 睡眠定时：显示剩余时间，并支持“播完当前歌曲后停止”。
- 删除歌单、清空队列、断开连接使用带动词的确认界面。

## 5. 其余业务细节要求

### 5.1 效率与创作

- 计划、任务、日志共享日期导航、状态标签、对象选择器，减少学习成本。
- 知识库和写作共享引用卡片；引用必须显示来源、修改时间和跳转入口。
- 编辑态必须展示保存状态；自动保存失败不能只用 toast，要保留可恢复草稿。

### 5.2 媒体与阅读

- B 站、网易云、诗词共享媒体控制语义，但不强行共用同一布局。
- 阅读与诗词以内容可读性优先，背景山水在正文区域降低对比或完全遮蔽。
- 登录、Cookie、书签权限等外部依赖必须有明确诊断和恢复路径。

### 5.3 AI 与系统

- Agent、对话和 Prompt 共享连接状态、模型选择、日志与错误组件。
- AI 输出明确区分“生成中 / 已完成 / 已取消 / 失败”，并保留重试所需上下文。
- 设置修改支持预览、撤销和恢复默认；危险数据操作独立分区。

### 5.4 休闲

- 游戏统一外壳，但每款游戏保留自己的画布比例和信息布局。
- 暂停和结束状态覆盖在画布内，不隐藏得分、最高纪录和重新开始入口。

### 6.2 单图验收

- 是一个完整可理解的页面，而非拼贴图。
- 与 v4 母版属于同一产品，但不会机械复制同一布局。
- 至少存在一个清晰主操作，关闭、返回和危险操作语义不混淆。
- 正文、辅助文字、状态与控件有足够对比度和点击面积。
- 中文内容以页面规格为准；生成图中文字若有瑕疵，不作为最终实现文案。
- 无设备边框、浏览器边框、水印和无关品牌 Logo。

### 6.3 页面组验收

- 文件数量与矩阵一致。
- 列表、详情、编辑、空/错状态都有覆盖。
- 同一对象跨页面的信息、封面、状态与导航位置保持一致。
- 页面间差异来自业务状态，不是只改标题或换背景。
