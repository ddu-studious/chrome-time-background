# 快捷助手 P1：提醒管理、音乐编辑与视频检索

日期：2026-09-16。

## 已实现

本轮新增14个工具，加上P0共28个登记工具。它们不会一次全部注入模型。

| 工具组 | 新增工具 | 实际行为 |
| --- | --- | --- |
| alarm.manage | alarm.get、alarm.update.prepare、alarm.toggle、alarm.delete.prepare | 读取已有提醒；准备修改/删除并等待确认；按明确请求开启/关闭 |
| music.edit | music.playback.seek、music.queue.remove、music.queue.clear | 定位进度；移除指定曲目；确认停止并清空本地队列 |
| music.playback | music.playback.control | 显式暂停、继续、上下首和绝对音量设置，复用真实播放器回执 |
| music.library | music.search.next | 基于接口总数/hasMore继续检索，保留对象类型及原搜索条件 |
| video.inspect | video.details、video.progress.get、video.open、video.search.next | 获取真实时长和作者等信息；读取有来源的进度；打开已选视频；翻页 |
| app.connection | app.status | 只读查询网易云/B站/YouTube连接或闹钟通知权限，不发起授权、不返回凭据 |

同时增强已有工具：

- `alarm.list` 支持名称关键词、offset/limit，返回真实ref和目标版本；同名或多目标时提供选择，不默认第一条。
- `video.search` 支持minSeconds/maxSeconds，单位为秒。YouTube读取contentDetails；B站读取搜索结果的duration。未知时长与未结束直播不当作满足条件。
- `music.state` 返回currentTime、duration、volume，供定位和控制使用。
- 搜索结果提供下一页入口。B站单页超过8条时先展示剩余候选，再请求下一远端页，不丢掉中间结果。

## 使用示例

- `@闹钟 把开会提醒改到明天下午四点半，其他设置不变。`
- `@闹钟 关闭开会提醒。` 多条同名提醒时先选目标。
- `@闹钟 删除吃药提醒。` 展示目标后等待确认。
- `@音乐 把当前音乐进度跳到120秒，保持播放。`
- `@音乐 从当前队列移除逆战。` 先查询真实队列引用；移除正在播放的曲目会确认停止。
- `@音乐 清空当前队列。` 确认后停止并清空，不修改网易云云端歌单。
- `@YouTube 搜索MySQL入门视频，只要十分钟以内的，让我选择后告诉我真实时长和作者，不要打开。`
- 搜索后的下一页按钮，或在待选会话中继续输入 `下一页`。

## 正确性与执行边界

### 提醒

模型只能给真实ref和可编辑字段，不能指定数据库ID或完整任意对象。可编辑label、time，以及一次性提醒的date/dayOffset；date与dayOffset不能同时提供，time必须为24小时HH:mm，相对日期以任务开始时刻为基准。

未修改的重复、声音、音量、贪睡等字段保留。重复提醒不能通过指定单日日期隐式变成一次性提醒。过期的一次性提醒修改需提供未来时间。

修改/删除的确认卡显示准确目标，修改同时显示前后差异。提交前重读目标，核对revision及完整快照；自动状态变化也不能被旧确认覆盖。后台save/toggle/delete与已有rename共用串行写队列，确认等待期间的旧版本不得覆盖新修改。

### 音乐

上下首控制针对普通本地队列；私人FM继续使用播放器的专用控制，不会被转换为普通队列。

定位秒数必须小于当前曲目的真实时长，等待真实进度回执；不为定位动作暂停音乐。

移除非当前曲目保留当前播放。移除当前曲目或清空队列先展示确认卡，确认后先停止并核对音频状态，再修改队列，不擅自播放另一首。队列版本、手动操作版本和缓存快照共同阻止旧操作覆盖新队列。

音乐搜索依据实际接口返回的总数/hasMore提供下一页；不支持分页的suggest兜底不被假装成可分页来源。最多20页，结果仍使用真实对象和既有选择语义。

### 视频

打开使用已选真实视频引用，链接由程序构造。打开成功不等于播放器确认播放。详情来自平台接口，不根据标题生成摘要。

YouTube进度来自扩展本地；B站进度只查询最近一页观看记录。没有续播秒数不代表从未观看。搜索分页引用封装真实页面令牌/页码，不把这些值交给模型编造。

### 会话与上下文

待选/待确认会话中的用户补充保留原观察和资源引用，并绑定到新的任务ID；旧页面任务ID仍不能操作新任务。已过期、已消费、跨类型或跨平台引用都不能写入。

应用未明确时，只注入简短能力说明和少量基础入口；指定应用后加载其详细技能。高级工具仍按组发现/强相关预加载。各组参数枚举按当前应用过滤；继续保留6200估算输入tokens、1200输出tokens、12轮规划和12次工具调用上限。不是让28个工具始终同时出现在提示词里。
