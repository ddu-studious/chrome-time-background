## 当前播放语义（2026-09-16，覆盖之前的仅追加行为）

- 单曲 `+`：保留原队列，去重加入并立即播放；已有歌曲也直接切换播放。
- 专辑、歌单、歌手 Top `+`：准备真实曲目和可播放资源后，用该组曲目替换整个队列并播放，不混入旧队列。
- 浏览歌手/专辑仍只浏览。整组播放最多300首，歌手热门歌曲最多100首，结果按实际可加载数量显示。
- 满队列加入新单曲会明确报错，不静默删掉末尾歌曲；整组资源准备失败保留旧队列。
- 点击后立即显示准备进度；成功后显示实际曲目和队列数量，失败显示原因。结果列表在执行中保留且禁用，完成后可继续选择，不再通过清空结果造成闪屏。
- 一次复合请求中的定时只在首次播放确认后推进；播放完成后再次手动选择其他歌曲不会重新执行原定时步骤。
- 本规则用于快捷助手当前播放队列，不修改网易云云端歌单。

## 当前版本

- 普通 HTTP/HTTPS 网页通过快捷键或扩展右键菜单唤出页内浮层；受限页面、无法注入或 iframe 加载失败时使用紧凑小窗。
- 输入栏默认一行，按内容增高。去掉可见的大标题、MVP 标签和大执行按钮；使用深蓝黑与紫色统一配色。
- 示例形象、界面文案和新验收示例使用张杰。当前设计图：[张杰音乐结果](../../output/imagegen/assistant-light-v3/music-results-zhangjie.png)。
- 原有快捷键绑定保留。代码更新后需要重载扩展，新增加的 activeTab 用于用户唤出时临时注入，不持续读取全部网页。

## 拼音与输入

- `@yy` → 音乐；`/ssyy` → 搜索音乐；`/jxk` → 继续看。
- 支持直接输入 `@yy /ssyy 张杰`；模糊结果不唯一时要求从菜单选择。
- 原文优先、拼音作为补充，显示匹配的中文字符高亮。
- 音乐结果可以按 `zj`、`zhangjie` 筛选。实际查询过的对象写入最多200个条目的本地索引；再次输入拼音可以先选择已知对象。
- 首次远端纯拼音查询仍依赖网易云接口，不把未知拼音编造为中文实体或资源 ID。

## 音乐对象和动作

| 对象 | 展示 | 操作 |
| --- | --- | --- |
| 歌手 | 圆头像、姓名、歌手标识 | 浏览热门歌曲，再选单曲或播放热门歌曲 |
| 专辑 | 专辑封面、名称、歌手 | 浏览曲目、整张加入当前队列或播放 |
| 歌单 | 方封面卡、名称、真实曲目数/创建者 | 浏览曲目，再播放歌单或选单曲 |
| 歌曲 | 紧凑行、封面、歌手、时长 | 播放或加入队列 |

综合搜索分别查询歌曲、歌手、歌单；类型标签切换当前已返回的对象。一次最多16首歌曲、8名歌手、8个歌单。
歌单最多读取300首，热门歌曲最多100首；曲目列表展示前30首，此版不提供曲目分页。播放歌单的标签会说明超过300首时只处理前300首。

浏览和返回不更改队列。单曲加号加入并播放，整组加号替换并播放；播放确认后推进复合需求下一步。
返回搜索结果保留当前页面会话内的类型、筛选词和滚动位置。后台重启仍沿用 MVP 的中断保护，不自动重放副作用。
真实歌曲、头像和封面均来自接口，生成的设计图不作为真实歌手资料来源。

## 实现边界

- 页内浮层使用隔离的扩展 iframe；令牌绑定标签页、页面来源和具体 frame。未由用户唤出的 iframe 无权调用助手接口。
- 关闭浮层恢复原焦点；点击页面其他位置时不会把焦点抢回旧输入框。加载期间主动收起不会再弹出兜底窗口。
- 消息中的候选版本用于拒绝旧页面操作；模型不生成歌曲、歌手、歌单 ID。
- 播放歌单沿用真实播放器回执；不可播放的开头曲目最多尝试5首。成功后同步缓存队列，工作台收到带独立版本的队列更新后再次核对状态，避免旧异步数据覆盖新队列。
- 拼音库复制自用户引用项目的现有打包文件，保留 MIT 许可证；库版本未凭空推断，副本校验值记录在 vendor/pinyin-match/README.md。
