# B 站框式工作台与播放快捷控制提案

> 状态：待产品确认，暂不进入 B 站实现。

## 目标

- B 站工作台采用 YouTube 工作台的“桌面窗口”框架，不再铺满整个屏幕。
- 保留 B 站现有业务能力、登录方式、播放记忆和播放器桥接，不改变接口与数据语义。
- B 站与 YouTube 使用一致的浏览路径、列表布局切换和播放快捷控制位置。

## 框架

```text
┌──── B站工作台 ───────── 搜索 ───────── 账号 / 抽屉 / 关闭 ┐
│ 推荐       │ 页面标题 / 加载或错误状态                         │
│ 热门       │ ┌──────────────── 主内容 / 播放器 ─────────────┐ │
│ 排行榜     │ │                                             │ │
│ 课程       │ └─────────────────────────────────────────────┘ │
│ 收藏       │ [−10s] ━━━━━━━●━━━━━━ 12:34 / 38:20 [+10s]     │
│ 历史       │ 倍速  0.75  1.0  1.25  1.5  2.0                │
│ 稍后看     │ 视频信息 / 收藏 / 稍后看 / 原站打开                │
│ 关注       │                              [上下文列表抽屉 →]   │
└────────────┴──────────────────────────────────────────────────┘
```

### 桌面布局

- 外框距窗口四边 18px，22px 圆角、半透明边框和阴影，保留桌面背景作为空间边界。
- 顶栏高 72px：左侧品牌，中间搜索，右侧账号状态、上下文抽屉和关闭。
- 左侧导航宽 176px，将现有两排入口统一为 8 个纵向入口：推荐、热门、排行榜、课程、收藏、历史、稍后看、关注。
- 浏览页面的主内容区支持方框和列表两种布局，并记住用户上一次选择。
- 播放页默认只展示播放器和视频信息；选集、课程目录或相关推荐进入 320–360px 的右侧抽屉，默认收起。

### 响应式

- 宽度不超过 900px：外框距边 12px，左侧导航缩成 72px 图标栏，右侧抽屉覆盖内容。
- 宽度不超过 620px：才允许回到全屏工作台，并把主导航移到底部。

## 播放快捷控制

控制条放在官方播放器下方，不覆盖播放器原有按钮。

- 可拖动进度条，拖动时显示目标时间；松手后跳转。
- `−10s` / `+10s` 快捷按钮。
- 倍速：0.75×、1×、1.25×、1.5×、2×，当前倍速有明确选中态。
- 键盘：空格播放/暂停，方向键前后 5 秒，J/L 前后 10 秒，`Shift + ,/.` 降低/提高倍速。
- 拖动、倍速和播放状态必须与播放器实时同步；失败时回退到原生播放器控制，并给出可恢复提示。

## 两个平台的实现边界

- B 站继续复用现有本地播放器桥接，实现真实进度、跳转和倍速同步。
- YouTube 只通过官方 IFrame Player API 控制，不读取 iframe DOM、不注入 Cookie；`enablejsapi=1` 的真实扩展验证已完成，现已开放外部进度条、±10 秒和倍速按钮。清晰度继续留在 YouTube 原生菜单，因为官方已停止支持外部清晰度控制。
- 两个平台共享控制条的视觉和键盘规则，但不强行共享底层播放器实现。

## 已完成的 YouTube 导航优化

- 从订阅频道进入视频时，播放器顶部显示“返回「频道名」的视频列表”。
- 返回后恢复进入前的频道、方框/列表模式和滚动位置。
- 从播放列表、搜索结果进入视频时复用同一返回机制；直接粘贴视频链接时不显示虚假的来源入口。

## 待确认的三个决定

1. B 站使用左侧 8 项纵向导航，替代现在的两排横向导航。
2. 播放页右侧上下文抽屉默认收起，课程页可按场景自动展开。
3. 快捷控制条固定放在播放器下方，不覆盖站点官方控件。
