# 中国风景时钟：全产品 UI/UX 改版设计 v4

> 状态：已实施并完成本地 Chrome 回归  
> 日期：2026-08-07  
> 范围：新标签页外壳、全部 Dock 应用、设置页、跨模块状态与可访问性  
> 设计母题：**夜色山水上的个人桌面工作台**

## 1. 目标与边界

本次不是单独美化网易云播放器，而是把现有扩展从“功能不断叠加的新标签页”整理成一套可理解、可扩展、可维护的个人桌面系统。

目标：

1. 用户在 3 秒内看懂首页重点：时间、天气、今日状态、热榜与高频入口。
2. 全部功能都有明确归属、打开形态、加载状态、空状态、错误状态与关闭方式。
3. 正文不低于 14px，主要点击目标不小于 36px，高频/关键控件优先达到 44px。
4. 保留“夜色山水 + 毛玻璃 + 紫蓝强调”的产品气质，但减少低对比小字、无标签图标和过度透明。
5. UI 改造和代码重构同步进行，禁止继续把新功能堆进 `style.css`、`memo.js`、`music-controller.js` 等超大文件。

不在本轮改变的内容：业务数据协议、网易云/B 站接口语义、任务存储结构、现有用户数据键名。

## 3. 信息架构

### 3.1 首页只承担四件事

1. **感知时间与环境**：时间、日期、农历、天气、空气、日落。
2. **了解外部世界**：热榜精简为 5 条，完整列表进入热榜工作台。
3. **了解自己今天**：今日计划、待办、工作日志进度、稍后阅读、正在播放。
4. **快速启动**：Dock 只放用户固定的 6–9 个应用，全部应用进入启动台。

### 3.2 应用分类

| 分类 | 功能 |
|---|---|
| 今日 | 计划、任务、工作日志、阅读 |
| 创作 | 写作空间、常用信息、Prompt 管理 |
| AI | Agent 矩阵、AI 对话 |
| 媒体 | 网易云音乐、B 站、诗词电台 |
| 休闲 | 贪吃蛇、俄罗斯方块、立体方块 |
| 系统 | 设置、扩展监控、极简模式、快捷导航、热榜管理 |

### 3.3 三种容器

| 容器 | 使用场景 | 尺寸规则 | 对应模块 |
|---|---|---|---|
| 轻量浮窗 | 30 秒内完成、不中断当前视线 | 360–560px；不超过 60vh | 快捷导航、游戏、关键词监控、诗词迷你条、音乐迷你态 |
| 标准工作台 | 需要浏览、编辑、筛选 | `min(1200px, 92vw)`；80–88vh | 计划、任务、工作日志、知识库、Prompt、网易云展开态、启动台 |
| 沉浸页 | 内容消费或复杂长任务 | 全视口，保留明确退出 | B 站、写作空间、Agent、AI 对话、设置 |

统一关闭规则：右上角 `关闭`/×，支持 `Esc`；点击遮罩只关闭轻量浮窗；有未保存内容时必须确认；“断开连接”“删除”“清空”不得使用关闭图标。

## 4. 设计系统

### 4.1 颜色

```css
--ui-canvas: #070b14;
--ui-surface-1: rgba(13, 20, 34, .84);
--ui-surface-2: rgba(20, 29, 47, .88);
--ui-surface-3: rgba(31, 42, 64, .92);
--ui-border: rgba(255, 255, 255, .12);
--ui-border-strong: rgba(255, 255, 255, .20);
--ui-text-1: rgba(255, 255, 255, .96);
--ui-text-2: rgba(255, 255, 255, .72);
--ui-text-3: rgba(255, 255, 255, .54);
--ui-accent: #8b6cff;
--ui-accent-strong: #9d85ff;
--ui-success: #42c98b;
--ui-warning: #f4b860;
--ui-danger: #f06a78;
--ui-info: #63a9ff;
```

禁止用透明度低于 `.50` 的文字承载必要信息。状态不可只靠颜色，必须同时使用图标、文字或形状。

### 4.2 排版

| 用途 | 字号/行高 | 字重 |
|---|---|---|
| 页面标题 | 22/30 | 650 |
| 面板标题 | 18/26 | 650 |
| 卡片标题 | 16/24 | 600 |
| 正文 | 14/22 | 400 |
| 辅助信息 | 13/20 | 400 |
| 极小标签 | 12/18 | 500；仅徽标/快捷键 |
| 首页时钟 | clamp(64px, 7vw, 112px) | 600 |

### 4.3 空间、圆角与阴影

- 8px 基础网格；常用间距为 8/12/16/24/32。
- 浮窗圆角 16px；大型工作台 20px；卡片 12px；按钮 10px。
- 主要操作高度 40–44px；图标按钮最小 36×36px。
- 毛玻璃只用于容器，不用于每一张内层卡片。内层卡片使用更实的底色，保证阅读对比度。
- 一个界面最多同时使用一个强阴影层级。

### 4.4 操作层级

1. 主操作：每个区域最多一个实色按钮。
2. 次操作：描边或柔和底色。
3. 工具操作：图标按钮必须有 `aria-label` 与 tooltip。
4. 危险操作：红色 + 动词，不得只显示叉号。
5. 模式切换：使用分段控件或单个循环按钮，不平铺四个等价图标。

### 4.5 动效与无障碍

- 进入/退出 180–240ms；列表重排 160ms；不使用无限弹跳。
- 支持 `prefers-reduced-motion: reduce`，关闭非必要动画与背景粒子。
- 所有可交互元素具有 `:focus-visible` 2px 外框。
- 键盘顺序与视觉顺序一致；工作台打开后焦点进入标题/首个输入，关闭后回到触发按钮。
- 加载超过 400ms 显示骨架或进度；失败显示原因、重试与必要的权限/登录动作。

## 5. 模块设计规格

### 5.1 首页、热榜与启动台

- 热榜默认显示 5 条：序号、标题、热度；`换一换` 与设置使用文字 + 图标。
- 今日概览为可收起工作台，聚合计划、任务、日志、阅读、音乐，不复制完整模块。
- Dock 默认 7 个高频入口；溢出不再横向压缩，进入启动台。
- 启动台增加“最近使用”“固定到 Dock”，搜索支持拼音首字母；分类顺序使用“今日、创作、AI、媒体、休闲、系统”。
- 数据源管理增加搜索、已启用计数、批量选择、未启用折叠；保存按钮固定在底部。

### 5.2 网易云音乐

- 只保留一张“正在播放”主卡，删除私人 FM 内重复的歌曲信息。
- 一级导航：队列、歌单、歌词、发现；搜索移到右上角。
- 私人 FM 卡展示推荐原因，操作为“喜欢 / 不喜欢 / 下一首”，不再显示含义模糊图标。
- 四个播放模式合并为单个循环按钮 + 当前模式文字。
- 底栏保留播放模式、音量、睡眠定时、更多；断开连接放入更多菜单。
- 关闭面板和断开连接是两个动作；关闭后音乐继续播放。

### 5.3 计划、任务与工作日志

- 计划以时间轴为核心，例行事项和灵活计划放右侧；冲突、逾期、进行中明确显示文字。
- 任务顶部不再堆 9 个无标签图标；一级视图为列表/看板/日历/统计，其余进入更多。
- 任务详情使用右侧抽屉，不跳转独立页面；支持描述、检查项、提醒、重复、关联链接、活动记录。
- 工作日志输入区分“记录事实”和“开始计时”；日志时间线与右侧统计保持联动。
- 三者共享任务/计划选择器、状态组件、日期导航与空状态。

### 5.4 常用信息与写作空间

- 知识库默认卡片墙，类型筛选最多一行；密度选择进入视图设置。
- 选中内容后右侧展示详情与关联内容；卡片只展示摘要，不塞入全部元数据。
- 写作空间采用三栏：分类 200px、文章/编辑主体、AI 助手 320px；右栏可收起。
- 编辑区提供低刺激浅色纸张和深色主题，正文 15px、行高 1.7。
- AI 生成必须展示来源、插入点、撤销；知识库引用保留可追溯链接。

### 5.5 B 站、阅读与诗词

- B 站一级标签收敛为推荐、关注、收藏、课程；历史、稍后看、排行进入更多。
- 播放区与列表区使用 70/30，登录/Cookie 状态放顶部品牌区，错误显示重试与检查登录。
- 阅读为空或无书签权限时，显示“授权书签 / 添加稍后阅读”，不静默消失。
- 诗词迷你条优先显示题目与作者；展开后提供原文、译注、收藏与朗读，播放倍速放入更多。

### 5.6 Agent、AI 对话与 Prompt

- Agent 首页先显示项目、活跃 Agent、运行队列；模板只在空状态出现一次。
- AI 对话保留终端气质，但配置独立为设置抽屉；错误消息提供“打开配置”。
- Prompt 左侧角色按阶段折叠；中间表单分“身份 / 任务 / 约束 / 输出”四组；右侧改为实时预览与版本差异，不以空统计卡占空间。
- 三个 AI 模块共享连接状态、模型选择、错误提示与运行日志组件。

### 5.7 游戏与系统

- 三个游戏使用同一轻量浮窗外壳，统一标题、得分、状态、开始/暂停、重新开始、关闭。
- 2D 画布最小 320px；3D 画布根据窗口比例自适应；键位说明可折叠。
- 设置为独立沉浸页：外观、首页、Dock、数据与隐私、集成、快捷键、关于。
- 扩展监控展示 CPU/内存/存储、后台任务与权限状态；异常给出定位入口，不只展示曲线。

## 7. 代码重构方案

### 7.1 当前风险

| 文件 | 当前规模 | 问题 | 目标拆分 |
|---|---:|---|---|
| `css/style.css` | 20k+ 行 | 所有时期/模块样式混在一起 | tokens、shell、shared components、各模块 CSS |
| `js/memo.js` | 12k+ 行 | 数据、表单、视图、统计、同步耦合 | model/store、query、list/board/calendar views、editor、statistics |
| `js/cursor-bridge.js` | 4.8k+ 行 | Bridge、Agent UI、工作流与日志耦合 | client、store、agent view、workflow view、panels |
| `js/music-controller.js` | 4.5k+ 行 | DOM 模板、播放器、网易云 API、搜索/发现混合 | view、player、netease client、queue、discover、lyrics |
| `js/blog.js` | 3k 行 | 数据、编辑器、抽屉与导航混合 | store、editor、navigation、drawer shell |
| `js/ticker.js` | 2.7k 行 | 数据源、轮播、监控、配置面板混合 | source registry、feed store、ticker view、keyword alerts |

### 7.2 迁移原则

1. 先抽“纯配置/纯视图”，再抽状态与副作用；每次迁移保持现有全局入口兼容。
2. 不同时改业务协议和 UI，避免无法判断回归来源。
3. 新文件通过显式依赖加载，禁止复制旧逻辑形成双份实现。
4. 为每次拆分补结构测试：脚本加载顺序、DOM ID、存储键、事件契约。
