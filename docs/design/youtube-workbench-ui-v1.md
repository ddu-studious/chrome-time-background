# YouTube 工作台 UI 设计 v1

> 日期：2026-08-16  
> 状态：R2 已实现；1440px/480px 本地浏览器视觉与交互已验收，真实扩展与 OAuth 待验收
> 关联 PRD：[`prd-v3.20.0-youtube-workbench.md`](../requirements/prd-v3.20.0-youtube-workbench.md)  
> 可视原型：[`youtube-workbench-v1.html`](../../test/demos/youtube-workbench-v1.html)

## 1. 设计判断

YouTube 工作台沿用 B 站 v5 的「主播放器 + 右侧内容列表」结构，但不复制 B 站的粉色品牌、八项导航和外部画质控制。

本方案的三个核心差异：

1. **账号从 Cookie 状态改为 Google OAuth 状态**：顶部明确区分「OAuth 未配置 / 待授权 / 已连接 · 只读 / 授权过期」，不显示「Cookie 正常」，也不把网页登录误报为扩展登录。
2. **播放器以 YouTube 原生体验为边界**：不在 iframe 上覆盖按钮，不伪造画质、倍速和进度状态。
3. **不可用能力从导航中消失**：不展示历史和官方稍后看；本地能力始终带「扩展本地」标记。

## 2. 视觉系统

### 2.1 色彩

| 语义 | 色值 | 用途 |
|---|---|---|
| 工作台背景 | `#080b12` | 页面底色 |
| 主表面 | `#10141d` | 顶栏、侧栏、信息区 |
| 次表面 | `#151a24` | 列表卡、状态卡 |
| 边框 | `rgba(255,255,255,.09)` | 面板分界 |
| YouTube 来源 | `#ff0033` | Logo、播放主动作、来源状态 |
| 全局选择 | `#8b6cff` | 与产品 v5 一致的焦点和非来源型选择 |
| 成功 | `#55d990` | 已连接、同步成功 |
| 警告 | `#f5c665` | 配额、授权临期 |
| 错误 | `#ff6b7c` | 播放失败、授权失效 |
| 主文字 | `#f6f7fb` | 标题与关键数值 |
| 次文字 | `#9ca5b5` | 描述与元数据 |

YouTube 红只表示来源和播放动作，不把整个工作台染成红色；危险操作仍使用错误色并带文字。

### 2.2 字体与密度

- 页面标题 18px，内容标题 15px，正文 13–14px，辅助信息不低于 12px。
- 顶栏 68px，二级导航 46px。
- 大容器 16px 圆角，列表卡 12px，按钮 10px。
- 桌面播放器保持 16:9，推荐宽度不低于 720px。
- 右侧栏默认 360px，可在 1180px 以下收起为抽屉。

## 3. 默认工作台结构

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ YouTube  已连接 · 只读   [搜索视频、频道、播放列表或粘贴链接……]  账号  × │
├────────────────────────────────────────────────────────────────────────────┤
│ 发现  [为你推荐] [兴趣趋势]  我的 [订阅] [播放列表] [喜欢] [本地清单] │
├───────────────────────────────────────────────────────┬────────────────────┤
│                                                       │ FOR YOU · LOCAL     │
│       YouTube 官方播放器 16:9                        │ 订阅近期推荐     24 │
│       原生控制 / 字幕 / 画质 / 广告完整保留           ├────────────────────┤
│                                                       │ [缩略图] 标题       │
├───────────────────────────────────────────────────────┤          频道 · 时长 │
│ 正在播放：标题                                        │ [缩略图] 标题       │
│ 频道 · 发布时间 · YouTube 来源                        │          频道 · 时长 │
│ [扩展稍后看] [学习清单] [复制链接] [在 YouTube 打开] │ ...                │
├───────────────────────────────────────────────────────┴────────────────────┤
│ ✓ Google 账号已授权只读   历史与官方稍后看不可同步   [管理账号与隐私]    │
└────────────────────────────────────────────────────────────────────────────┘
```

### 3.1 顶栏

- 左侧：官方来源标识和账号状态。账号状态用「已连接 · 只读」而不是邮箱全文。
- 中间：搜索框可输入关键词、视频 URL 或 11 位视频 ID。
- 右侧：刷新、账号与隐私、关闭。关闭是最后一个按钮且始终可见。
- 不放「迷你播放器」入口：MVP 关闭工作台即销毁播放器，避免后台播放政策风险。

### 3.2 导航

- 所有内容能力常驻可见，不使用「更多」隐藏核心入口。
- 「扩展稍后看」和「学习清单」后显示小型 `LOCAL` 标识。
- 搜索结果不是常驻 tab；提交后在右侧列表和主区摘要中进入搜索状态，并保留返回前一列表。

### 3.3 播放器

- iframe 自身是唯一播放控制面，四周至少保留 12px 安全间距。
- Toast、错误卡、弹层和 Loading 不得覆盖 iframe；播放错误时先销毁 iframe，再在同区域显示错误页。
- 播放区下方只显示视频元数据和业务动作。
- 速度、画质、字幕使用 YouTube 原生设置；不在外部重复一套不可验证的控件。

### 3.4 侧栏

- 固定展示当前上下文的 eyebrow、标题、说明和已加载数量。
- 视频项最小高度 88px，缩略图 128×72；点击整卡选择，操作按钮独立。
- 当前播放项使用红色左边线和「播放中」文字，不只靠颜色。
- 分页显式显示「已加载 20 / 共 N」，不做无尽滚动。

## 4. 页面矩阵

| 页面 | 核心内容 | 主操作 | 与 B 站差异 |
|---|---|---|---|
| `youtube-01-connect` | 能力、权限用途、隐私链接、访客模式 | 连接 YouTube | OAuth，不读 Cookie |
| `youtube-02-recommended` | 订阅频道近期公开视频、推荐依据 | 播放视频 | 明示非 YouTube 首页算法 |
| `youtube-03-trending` | 兴趣分类选择、对应分类趋势列表 | 切换分类 / 播放视频 | 不展示全站混合趋势 |
| `youtube-04-player` | 官方 iframe、视频元数据、本地动作 | 在播放器中观看 | 无外部画质控件 |
| `youtube-05-subscriptions` | 订阅频道、搜索、频道最新视频 | 查看频道 | 点击后按需加载 |
| `youtube-06-library` | 播放列表、喜欢、列表内容 | 播放列表 | 不含官方稍后看 |
| `youtube-07-local-queue` | 扩展稍后看、学习清单、备注与状态 | 继续学习 | 明确标注本地数据 |
| `youtube-08-search` | 视频/频道/播放列表、配额提示、分页 | 播放或打开 | 显式提交才请求 |
| `youtube-09-error` | 授权、配额、不可嵌入、153、离线 | 对症恢复 | 错误码分层 |

## 5. 关键页面

### 5.1 首次连接

内容顺序：

1. YouTube 工作台能做什么：订阅推荐、兴趣趋势、搜索、订阅、播放列表、喜欢、官方播放。
2. 明确不能做什么：历史、官方稍后看、YouTube 官方首页推荐流。
3. 只读权限说明：查看频道、订阅和播放列表；不上传、不评论、不自动订阅。
4. 主操作「连接 YouTube」，次操作「先用访客模式」。
5. YouTube ToS、Google Privacy Policy、本扩展隐私政策。

授权弹窗只由主操作触发。

### 5.2 为你推荐与兴趣趋势

- 默认「为你推荐」展示最多 12 个订阅频道的近期公开视频，固定说明推荐依据与非官方算法边界。
- 「兴趣趋势」顶部提供文化、旅游、科学与技术、教育、娱乐、游戏、音乐、体育分类胶囊；默认进入文化，选中态清晰且本地持久化。
- 标题使用“跨圈层兴趣趋势”，下方固定展示中华文化圈 40%、欧美 30%、泛亚 30% 的目标配比。
- 配比进度条按 8/6/6 展示已完成、加载中、等待中和失败状态；完成一层就立即显示卡片，不阻塞后续浏览。
- 每张趋势卡显示中华文化圈、欧美或泛亚来源标签，颜色与配比进度条一致。
- 分类趋势合并近 90 天三个圈层的官方评分结果，只展示 4 分钟以上常规视频；最多展示 20 条，用户点击视频后才创建 iframe。
- 列表优先使用 YouTube 官方评分排序的 HD、非直播内容，并限制同一频道最多 2 条；不向用户展示自定义质量分。
- 不使用「全站热榜」或「YouTube 官方为你推荐」文案。

### 5.3 订阅工作台

- 右侧先展示频道头像、频道名和订阅时间/相关性。
- 主区是当前选中频道的 Hero、简介、最新公开视频。
- 「最新视频」由用户点击频道后加载，避免打开页面就为全部频道发请求。
- 顶部提供「最近更新」：显式点击后汇总当前页订阅频道的最新 1 条视频，按发布时间排序。
- 频道封面是可操作按钮，箭头覆盖层表示进入频道更新，不再呈现不可点击的禁用卡片。
- R1 不显示订阅/取消订阅开关；R2 获得写权限后再增加。

### 5.3.1 方框与列表

- 所有返回内容集合的页面都在内容区顶部提供方框、列表两个图标按钮，并使用 `aria-pressed` 表达当前状态。
- 方框布局用于快速浏览封面；列表布局使用横向缩略图和更宽标题区，适合连续扫描更新。
- 布局选择跨 YouTube 页面保持一致，并在窄屏降为单列紧凑列表。

### 5.4 资料库

- 顶部二级选择「播放列表 / 喜欢」。
- 播放列表卡展示封面拼贴、标题、隐私状态和视频数。
- 进入列表后保留面包屑，右侧切换为视频条目。
- 私密/删除视频保留占位和状态，不 silently 丢失位置。

### 5.5 本地学习

- 「扩展稍后看」是轻队列：添加时间、来源入口、单项移除。
- 「学习清单」增加状态、备注、最近打开；不显示观看百分比。
- 页首固定提示：「这些状态仅保存在本扩展，不会写回 YouTube」。
- 清空、删除本地数据和断开账号是三个独立动作。

## 6. 错误与降级文案

| 场景 | 标题 | 说明 | 操作 |
|---|---|---|---|
| OAuth 拒绝 | 未连接 YouTube | 账号数据未授权，访客能力仍可使用 | 继续访客 / 再次连接 |
| OAuth 过期 | 需要重新连接 | 私人列表暂时锁定，本地清单未受影响 | 重新连接 |
| 搜索配额 | 今日搜索额度已用尽 | 已有结果仍可查看，额度按太平洋时间重置 | 在 YouTube 搜索 |
| `101/150` | 此视频不允许嵌入播放 | 视频作者限制了第三方播放器 | 在 YouTube 打开 |
| `153` | 播放器客户端标识缺失 | 当前扩展包未通过来源识别 | 在 YouTube 打开 / 查看诊断 |
| 私密/删除 | 视频不可用 | 视频已删除、设为私密或当前账号无权访问 | 返回列表 |
| 离线 | 暂时无法连接 YouTube | 本地稍后看和学习清单仍可查看 | 重试 |

## 7. 响应式规则

### ≥ 1180px

- 主区 + 360px 侧栏双列。
- 顶部所有导航常驻。

### 760–1179px

- 侧栏缩窄到 320px；导航允许横向滚动但不折叠核心能力。
- 视频元数据动作换行。

### < 760px

- 单列：播放器在上，列表在下。
- 一级导航使用两行分组，不藏入更多菜单。
- 播放器最小高度满足 YouTube 200×200 要求；优先保持 16:9。

### 480px

- 顶部 Logo 与搜索同排，账号/关闭位于第二行。
- 视频列表缩略图 112×63。
- 本地标识与标题不重叠；页面本身不产生横向溢出。

## 8. 无障碍与键盘

- 工作台是 `role="dialog" aria-modal="true"`，打开后焦点进入搜索，关闭后返回 Dock 入口。
- Tab 焦点限制在工作台；Escape 关闭，但 iframe 全屏时由播放器优先处理。
- 所有导航使用按钮和 `aria-pressed` / `aria-selected`。
- 当前播放、授权、配额、错误均有文字，不只使用颜色和图标。
- 列表缩略图使用空 `alt`，标题按钮提供完整可读名称，避免重复播报。
- 动态状态用克制的 `aria-live="polite"`，播放器时间不持续播报。

## 9. 原型评审清单

- [ ] 一眼能看出这是 YouTube 来源，但仍属于中国风景时钟 v5 工作台。
- [ ] 用户不会误以为能同步 YouTube 历史或官方稍后看。
- [ ] 播放器区域没有任何自定义遮挡。
- [ ] 搜索配额、账号权限和本地数据范围容易理解。
- [ ] 当前内容列表和播放对象同时可见。
- [ ] 关闭、原页打开、账号与隐私三个逃生入口始终可达。
