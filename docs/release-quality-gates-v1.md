# 发布质量门禁 v1

**状态**：草案（供产品 / 架构 / QA / 技负评审后冻结）  
**适用范围**：Chrome 扩展宿主页内嵌的休闲方块类玩法（Canvas / WebGL 渐进增强）  
**原则**：**判定与规则正确性优先于帧率与特效**；门禁数值可在 Spike 与低端抽样后修订，但**分级结构与矩阵形状**先行锁定。

---

## 1. 最低设备档（Minimum Device Tier）

| 档位 ID | 代号 | 硬件 / 环境画像（对内口径） | 必测浏览器 |
|--------|------|-----------------------------|------------|
| **T0（阻塞档）** | `min-supported` | 近 4 年内主流笔记本核显或同级集显；**8 GB 系统内存**；1080p；Windows / macOS **当前稳定版 Chromium**（与扩展目标通道一致） | Chromium + 扩展打包形态 |
| **T1（推荐档）** | `target` | 独显或 Apple Silicon / 近年高性能核显；16 GB；1080p 或更高 | 同上 |

**说明**

- **T0 为发布门禁底线**：在 T0 上未通过的项按本文第 3 节分级处理；**P0 缺陷不得带缺陷上线**。
- **移动端 / 平板**：若未列入首期对外承诺，标注为 **Non-Goal** 或「后续档位」；一旦承诺，需单独增列 `touch-min` 档（CPU/GPU/内存/Chrome Android 版本），并扩展 §4 矩阵。
- **扩展语境**：须在 **`chrome-extension://`  Origin** 下复测（CSP、打包资源路径与 `file://` 差异）。

## 2. FPS / 内存阈值

### 2.1 帧率（Gameplay Loop）

| 指标 | T0（min-supported） | T1（target） | 测量方法 |
|------|---------------------|--------------|----------|
| **可持续帧率（1 分钟稳定窗）** | **≥ 30 FPS**，且掉帧尖峰不超过连续 **6 帧** 低于 24 FPS | **≥ 55 FPS**（允许偶发掉至 ≥45） | Performance API + 自建 rAF 采样；**不含**后台 Tab |
| **开局首秒** | 允许瞬时抖动；**第 2 秒起**须进入上表窗口 | 同上 | 冷启动后从「开始游戏」起算 |

**降级策略（非阻塞但必须备案）**

- 关闭阴影 / 后处理 / 粒子；降低渲染分辨率（沿用 effect tier 思路）；强制 Canvas 路径。
- 任一降级触发须在 MR / 发布说明中标注「生效条件」与「对用户可见差异」。

### 2.2 内存与工作集（警戒）

浏览器精确 RSS 依赖 OS，门禁以 **可观测代理指标** 为准：

| 指标 | T0 警戒 | T1 参考 | 说明 |
|------|---------|---------|------|
| **JS 堆（Chrome DevTools Memory / Performance）** | 开局后 5 分钟对局，堆增长相对开局基点 **≤ 80 MB**；无持续上升趋势（泄漏嫌疑） | 同上，建议 **≤ 50 MB** 增量 | 以「典型对局 + 重开 10 次」为脚本 |
| **标签页崩溃 / GPU 进程重启** | **0 容忍**（视为 P0） | 同上 | 需在 T0 机器上保留复现日志 |

**导航 / 后台**

- 文档化「后台暂停 / 恢复」策略（与 PRD 一致）：恢复后**不允许**出现盘面与内核状态不一致；若不可修复须降级为「强制暂停并要求确认继续」。

## 3. 已知 Issue 分级（P0–P3）与上线裁决

| 级别 | 定义 | 典型示例 | **默认发布** |
|------|------|----------|--------------|
| **P0** | 规则 / 判定错误；数据损坏；崩溃；安全；核心操作无法完成 | 穿模、悬浮、消行残留非法占用；分数与规则不符；扩展内脚本错误导致白屏 | **阻塞（No-Go）** |
| **P1** | 高频路径严重影响体验或可导致错误胜负 | 锁定延迟与输入系统性冲突；默认相机下误触旋转；结算文案与实现不一致 | **带风险上线须技负 + 产品双签**；须有计划修复版本 ≤ **7 日** |
| **P2** | 中频干扰或边界缺陷 | 极端分辨率布局错位；特效偶现 Z-fighting（不影响判定） | **可上线**；列入里程碑 |
| **P3** | 低频、观感或文案 polish | 动画轻微抖动；非关键音效缺失 | **可上线** |

**与既有决策对齐**：「帧率与特效为非阻塞项」**不等于**「卡顿不设上限」——在 T0 若持续低于 §2.1 且无法降级达标，归 **P1**，是否放行按上表双签流程。

## 4. 手感相关：输入缓冲 QA 用例矩阵

**目的**：验证「离散内核 + 输入适配」下，**缓冲队列、重复键、冲突方向、触屏与默认相机**不引入非确定性或可感知滞后失控。

### 4.1 维度说明

| 维度 | 取值 |
|------|------|
| **输入通道** | 键盘；鼠标（若映射按键或 UI）；触屏（若承诺）；游戏板 **focus 内** |
| **相机** | **默认相机（首发）**；若有多预设，增列「俯视 / 斜视角」为 P1 扩展列 |
| **时间节奏** | 低速（开局）；高速（Level 曲线后端，或调试注入） |

### 4.2 矩阵（默认相机 · 必测）

行：**操作意图**；列：**输入通道**。单元格：期望（内核命令序列可回放一致）。

| 操作 / 场景 | 键鼠 | 触屏（若适用） |
|-------------|------|----------------|
| **单次移动**（左/右 各 1 格） | 单次 keydown → 正好 1 次横移；keyup 不触发额外移动 | 短点划 → 1 次横移；无虚触双移 |
| **长按重复** | 系统 KeyRepeat 与内核采样一致；**最后一次有效方向**在锁定前生效；无「反向吞键」 | N/A 或滑动连续移动策略与 PRD 一致 |
| **软降按住** | 按住期间步进频率符合规则包；松开后恢复重力；与 lock delay 无竞态 | 长按下落映射同上 |
| **旋转连按（≤ lock delay 窗内）** | 每次旋转均有合法踢墙或可解释失败；**缓冲：窗末最后一次旋转意图**须兑现或在锁定后丢弃（与规格书一致） | 双指误触防护；旋转优先级 documented |
| **同时反向键**（左+右） | 规格书优先方向（或抵消）；**不得交替抖动** | N/A |
| **落地瞬间：横移 + 旋转交错** | DAS/ARR（若启用）与旋转顺序可回放；无非法穿透 | 同步手势若不支持须明确忽略顺序 |
| **暂停 / 失焦** | 失焦自动暂停或弹出确认（与 PRD 一致）；恢复后状态一致 | 系统手势打断 vs 游戏暂停优先级 |
| **快捷键冲突**（扩展页） | 游戏区内 `preventDefault` 范围收敛；**不得**全局阻断浏览器关键快捷键（按清单验收） | N/A |

### 4.3 鼠标专项（若鼠标参与）

| 用例 | 期望 |
|------|------|
| 点击 UI「开始 / 暂停」 | 一次点击一次状态迁移；无双击误触发 |
| 拖拽（若用于视角 — **首发默认相机可为 N/A**） | 不改变内核判定；仅影响视图 |

### 4.4 默认相机专项

| 用例 | 期望 |
|------|------|
| 静止默认视角 | 幽灵块 / 下一块 HUD 与棋盘对齐误差 ≤ **半格**（视觉），且与内核坐标映射文档一致 |
| 相机动画（若有Intro） | 动画期间 **禁止** 提交旋转/硬降除非规格书允许；或输入进入缓冲队列 |

## 5. 证据与签核

- **T0/T1 各至少 1 台物理机**跑 §2 + §4 抽样；保留录屏与 DevTools Performance 导出。
- **P0/P1 清单**：必须与对外「已知问题」文案同源（避免口径漂移）。
- **Go/No-Go**：由技负召集；**P0 = No-Go**；**P1 上线**须书面记录缓解措施与修复 ETA。
