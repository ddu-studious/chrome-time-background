# PRD：即将到期任务提醒与紧迫感设计

## 1. 背景与问题

### 痛点描述
用户设定的任务可能跨越较长周期（一周甚至更久），随着新任务的增加，旧任务被折叠到列表下方，导致即将到期的任务被遗忘。当用户注意到时，任务可能已经过期。

### 核心诉求
- 让即将到期的任务主动**浮出水面**，而非被埋没在列表中
- 通过视觉设计提高**紧迫感**，引导用户优先处理
- 不打断用户正常使用流程，但确保关键信息不被遗漏

---

## 2. 竞品调研

### 2.1 Apple iOS Reminders（iOS 26.2+）
- **"紧急"标记**：任务可标记为 Urgent，到期时触发全屏闹钟式提醒
- **紧急智能列表**（iOS 26.4）：自动聚合所有紧急任务到独立列表
- **渐进式通知**：锁屏全屏提醒 → 解锁时顶部 Banner → Watch 同步
- **启发**：独立的智能列表 + 分级通知是成熟方案

### 2.2 Todoist
- **智能过滤器**：支持 `(today | overdue)` 等时间查询
- **颜色编码**：过期红色、今天蓝色、未来灰色
- **Favorites 快捷访问**：常用过滤器置顶
- **启发**：过滤器表达式灵活，颜色编码直观

### 2.3 TickTick（滴答清单）
- **内置智能列表**：Today / Tomorrow / Next 7 Days / All
- **持续提醒**：Constant Reminder 功能，未处理则反复通知
- **艾森豪威尔矩阵**：按紧急+重要四象限分类
- **启发**：时间分组（今天/明天/本周）是通用模式

### 2.4 倒计时/紧迫感设计（UX 研究）
- 倒计时在 3 天以内产生真正紧迫感，14 天以上无效
- 渐进式展示：先完整显示，再收缩为小图标，平衡注意力与干扰
- 粘性浮动条占屏幕 <5% 时用户接受度最高
- 颜色渐变传递紧迫程度（绿 → 黄 → 橙 → 红）

---

## 3. 设计方案

### 3.1 方案概述：「紧急任务仪表盘」

在现有侧边栏顶部和任务管理页增加一个**紧急任务区域**，自动聚合即将到期和已过期的任务，通过颜色、倒计时、动画传递紧迫感。

### 3.2 数据分层（紧急度模型）

| 级别 | 条件 | 颜色 | 图标 | 标签文案 |
|------|------|------|------|----------|
| 🔴 已过期 | `dueDate < today && !completed` | `#ff4757` 红 | ⚠ 感叹号 | 已逾期 N 天 |
| 🟠 今天到期 | `dueDate === today && !completed` | `#ffa502` 橙 | 🔥 火焰 | 今天到期 |
| 🟡 明天到期 | `dueDate === tomorrow && !completed` | `#f0c040` 黄 | ⏰ 闹钟 | 明天到期 |
| 🔵 3天内到期 | `dueDate <= today+3 && !completed` | `#64b4ff` 蓝 | 📅 日历 | N 天后到期 |
| ⚪ 7天内到期 | `dueDate <= today+7 && !completed` | `rgba(255,255,255,0.5)` 灰 | 📋 列表 | N 天后到期 |

**位置**：在任务列表最上方，固定不随列表滚动

│ ┌──────┐ ┌──────┐ ┌──────┐          │
│ │⚠ 逾期 │ │🔥今天 │ │⏰明天 │         │
│ │  1个  │ │  1个  │ │  1个  │         │
│ └──────┘ └──────┘ └──────┘          │
└──────────────────────────────────────┘
```

**交互**：
- 点击某个分类跳转/筛选到对应任务
- 所有紧急任务都处理完后，横幅自动消失
- 可折叠为一行摘要：`🔥 3个任务即将到期`
- 展开后显示分组摘要卡片

#### B. 任务项内 —— 倒计时徽章 (Countdown Badge)

**位置**：任务卡片右上角或截止日期旁

```
┌─────────────────────────────────────┐

```

**视觉特征**：
- 过期：红色背景脉冲动画 + ⚠ 图标
- 今天：橙色背景 + 🔥 图标，轻微呼吸动画
- 3天内：蓝色静态标签
- 文案：`逾期2天` / `今天到期` / `还剩3天`

**位置**：任务管理页顶部，表格/卡片视图上方

```
┌──────────────────────────────────────────────┐
│ ⚡ 需要关注的任务                              │
│                                               │

│ ├─ Chrome扩展V2      ├─ 修复登录Bug            │

**交互**：
- 可折叠/展开
- 点击任务项直接打开详情
- 任务完成后自动从面板移除（带淡出动画）

#### D. 新标签页 —— 浮动提示气泡 (Floating Reminder)

**位置**：新标签页右下角，非侵入式

```
                            ┌─────────────┐
                            │ 🔥 3个任务    │
                            │ 即将到期      │
                            │ [查看] [忽略] │

```

**行为**：
- 打开新标签页时自动检查，有紧急任务时弹出
- 3秒后自动缩小为角标圆点 `🔴3`
- 点击展开查看详情
- 每天最多提醒3次，避免疲劳

## 4. 数据模型

### 无需新增存储字段

所有紧急度信息均可从现有 `dueDate` + `completed` 实时计算：

```javascript
function getUrgencyLevel(task) {
    if (!task.dueDate || task.completed) return null;
    const today = new Date().toISOString().split('T')[0];
    const tomorrow = new Date(Date.now() + 86400000).toISOString().split('T')[0];
    const in3days = new Date(Date.now() + 3 * 86400000).toISOString().split('T')[0];
    const in7days = new Date(Date.now() + 7 * 86400000).toISOString().split('T')[0];

    if (task.dueDate < today) return 'overdue';
    if (task.dueDate === today) return 'today';
    if (task.dueDate === tomorrow) return 'tomorrow';
    if (task.dueDate <= in3days) return 'soon';     // 3天内
    if (task.dueDate <= in7days) return 'upcoming';  // 7天内
    return null;
}
```

### 用户偏好（可选，存储在 sync）

```javascript
{
    urgencyReminder: {
        enabled: true,          // 是否启用紧急提醒
        showBanner: true,       // 侧边栏横幅
        showFloating: true,     // 新标签页浮动提示
        maxDailyPopups: 3,      // 每日最多浮动提示次数
        urgencyThreshold: 3     // 提前几天开始提示（默认3天）
    }
}
```

## 6. 技术要点

- **无额外权限需求**：完全基于现有数据字段计算
- **性能**：紧急度计算在每次渲染时按需执行，无需定时器
- **向后兼容**：不修改现有数据结构，纯 UI 增强
- **响应式**：横幅组件适配侧边栏宽度和任务管理页宽度
