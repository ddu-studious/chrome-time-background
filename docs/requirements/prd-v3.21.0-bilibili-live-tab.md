# PRD v3.21.0：B 站直播 TAB

## 目标

在现有 B 站工作台中增加常驻“直播”入口，让用户不离开新标签页即可发现、筛选和观看直播；登录不是浏览热门直播的前置条件。

## 使用路径

1. 顶部“热门”与“排行”之间增加“直播”TAB，并用低干扰呼吸点表达实时内容。
2. 进入后默认显示“全部”，排序规则为“关注开播优先，其次热门直播；同来源按人气降序”。
3. 侧栏提供“全部 / 关注 / 影视 / 热门”四个一键筛选，筛选按钮直接显示数量。
4. 主区域首次展示焦点直播和三个快捷选择；点击后在工作台内打开轻量直播播放器。
5. 每张直播卡和播放器标题栏都保留“原页打开”，用于弹幕、互动、送礼等完整 B 站能力。
6. 右侧悬浮刷新沿用现有工作台行为，刷新直播时不影响当前已打开的直播间。

## 信息层级

直播卡片只保留决策所需信息：

- 开播状态：固定“直播中”，不与普通视频时长混用。
- 主信息：直播标题、主播。
- 辅助信息：分区、人气、是否为已关注主播。
- 操作：点击主体在工作台内观看；独立按钮跳转原直播间。

## 数据与降级

| 数据 | 接口 | 登录要求 | 降级策略 |
| --- | --- | --- | --- |
| 关注开播 | `/xlive/web-ucenter/v1/xfetter/GetWebList` | 是 | 失败时仍展示热门直播 |
| 热门直播 | `/room/v1/room/get_user_recommend` | 否 | 失败但关注数据可用时只展示关注开播 |
| 认证影视直播 | `/room/v3/area/getRoomList`（生活 → 电子榨菜） | 否 | 只保留可信房间或“放映厅/影视”认证账号 |
| 影评直播搜索 | `/x/web-interface/search/type`（影评/电影解说/放映厅） | 否 | 搜索失败时仍保留认证放映厅直播 |
| 内嵌播放 | `https://www.bilibili.com/blackboard/live/live-activity-player.html?cid={roomId}` | 否 | 始终提供原页打开 |
| FLV 兼容流 | `/room/v1/Room/playUrl` | 否 | 新版流为空或官方播放器启动超时后在 App 内自动切换 |

三个来源按 `roomId` 去重；同一直播同时出现在关注与影视或热门中时保留“关注开播”身份，并合并影视直播标识。

### 影视直播筛选

- 固定可信频道：`迷影社`，房间号 `545007`。
- 扩展候选包括认证放映厅，以及标题、标签或主播信息明确属于影评、电影解说、影视解说、观影或看电影的直播。
- 只保留 `live_status=1` 的真实直播；不再加载电视剧点播、录播或普通视频。
- 排除游戏、手游、网游、单机和电竞分区，避免“电视台”“电影”等蹭词结果混入。
- 直播卡明确标记“放映厅直播”或“影评直播”，点击后始终在当前 App 工作台播放。
- “放映直播”和“影评直播”按钮均在 App 内切换到对应直播间，不打开官网。
- 排序为“关注开播 → 影视直播 → 热门”，同房间保留最高优先级来源并合并影视直播身份。

### 播放降级

- 播放前调用 `/xlive/web-room/v2/index/getRoomPlayInfo` 检查新版播放流；存在流时继续使用 B 站官方活动播放器。
- 新版接口成功但返回空流时，立即调用 `/room/v1/Room/playUrl` 获取 FLV 兼容线路，不进入 `94001` 错误页。
- 官方活动播放器 10 秒内没有发出 `playing`、`MutePlay`、`NotAutoPlay` 或 `paused` 事件时自动切换 FLV。
- FLV 第一条线路失败后自动尝试下一条线路；全部失败才显示可重试状态。
- FLV 播放使用本地锁定的 `flv.js@1.6.2`，不加载远程脚本，不离开 App。

## 交互边界

- 直播使用 B 站原生轻量播放器，不复用普通视频的倍速、进度、画质和评论控制条，避免展示不可用操作。
- 登录用户通过现有 Cookie DNR 链路共享 B 站登录态；扩展不保存密码。
- 直播 TAB 只读，不自动点赞、关注、发送弹幕或产生礼物消费。
- 页面脚本与后台 Service Worker 版本不一致时，先展示可操作的“应用更新并重新打开”，不再暴露内部白名单错误。
- 窄屏时侧栏覆盖显示，直播卡压缩封面宽度；主区快捷直播改为单列。
- 支持键盘焦点、可读按钮名称和 `prefers-reduced-motion`。

## 验收口径

- 顶部九项能力均常驻可见，直播 TAB 可恢复为上次访问页。
- 未登录时热门直播可展示；登录时关注开播排列在热门之前。
- 重复房间只出现一次，且保留关注身份。
- 点击直播卡可在工作台内观看，原页按钮打开正确房间。
- 切回普通视频后，倍速、进度、画质与评论控制恢复，不残留直播模式。
- 定向 B 站、v5、音乐契约测试与全量测试通过。
