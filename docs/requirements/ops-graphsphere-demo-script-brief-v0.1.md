## 执行摘要（运营视角）

| 维度 | 结论 |
|------|------|
| **商业定位** | 演示获客杠杆，非独立商业化 App；首期 ROI 看「演示漏斗」而非 ARR |
| **核心 KPI（6 个月）** | 完播率 ≥60% · Demo→注册 ≥8% · 渠道新增占比 ≥15% · D7 留存 ≥15% |
| **传播主资产** | 1 条 90s 主录屏 + 3 条 15s GIF + 1 条 5min 完整路演版 |
| **预算封顶** | 30–60 万 / 6 个月；3 个月 KPI 未达标则收缩为扩展内嵌组件 |
| **差异化叙事** | 「零导入、3 秒进图、双场景叙事、演示不翻车」—— 对比 Obsidian/Neo4j 的「需自备数据 + 学习成本」 |

**Go/No-Go 运营门禁**：D10 后 30 天内，主录屏完播率 <45% 或 Demo→注册 <5% 连续 2 周 → 触发传播素材 A/B 重做；90 天 Demo 渠道占比 <10% → 收缩为内嵌组件，停止独立域名投放。

## 一、商业价值与 ROI 预估

### 1.1 需求对现有用户与获客的影响

| 用户群 | 影响类型 | 预期效果 | 数据依据 |
|--------|----------|----------|----------|
| **现有扩展用户** | 间接 | 架构可视化增强品牌专业度；不强制触达，零打扰 | 内嵌入口为 P1；P0 不影响主路径 |
| **潜在客户（开发者/PM）** | 直接获客 | 5 分钟建立「复杂系统关系一眼可见」认知 | 开发者工具类交互 Demo 完播率行业中枢 **45–55%**；结构化脚本可拉升 **10–15pp** |
| **投资人/合作伙伴** | 品牌杠杆 | 90 秒内完成视觉冲击 + 可交互证明 | B 端路演 Demo 平均 attention span **60–90s**；前 30s 决定续看 |
| **内部干系人** | 对齐效率 | 场景 A 减少架构评审 PPT 往返 | 对内评审准备时间可压缩 **30–40%**（基于同类架构可视化工具内部反馈） |

### 1.2 竞品对比（传播与转化维度）

| 竞品/参照物 | 定位 | 演示门槛 | 3D/关系可视化 | 传播友好度 | GraphSphere 差异点 |
|-------------|------|----------|---------------|------------|-------------------|
| **Obsidian 3D Graph** | 个人知识库插件 | 需自备 Markdown 库 | 有，依赖本地数据规模 | 中（用户自发录屏为主） | **零导入预置场景**；对外可讲 AI 产业链而非个人笔记 |
| **Neo4j Bloom** | 企业图数据库 | 需连接 DB + 授权 | 2D/2.5D 探索为主 | 低（销售驱动 Demo） | **纯静态 Web、无后端**；链接即可传播 |
| **Gephi / yEd** | 桌面分析工具 | 需导入 GEXF/CSV | 2D 为主 | 低（文件型工作流） | **浏览器即开、3D 力导向**；无需安装 |
| **Kumu / Graphistry** | 在线关系图 SaaS | 账号 + 数据录入 | 2D/高级分析 | 中（模板有限） | **双预置叙事场景**；对内对外一键切换 |
| **3d-force-graph 示例站** | 技术 Demo | 开发者向 | 3D 有 | 低（无产品叙事） | **产品级 UX**：侧栏详情、巡航、降级 |

**竞争结论**：GraphSphere v0.1 **不在「知识管理深度」竞争**，而在 **「最低成本完成一次完整、可复现、可传播的关系洞察演示」** 上建立差异。传播素材应强化：**打开即看、不翻车、能讲两个故事**。

### 1.3 ROI 预估（演示获客路径）

**假设参数（保守 / 基准 / 乐观）**

| 参数 | 保守 | 基准 | 乐观 | 说明 |
|------|------|------|------|------|
| 月 Demo UV | 800 | 2,000 | 5,000 | 自然 + 渠道 + 路演回流 |
| 完播率 | 45% | **60%** | 72% | KPI 门禁 ≥60% |
| Demo→注册转化 | 5% | **8%** | 12% | 扩展/Bridge 注册或 Waitlist |
| 单注册 CAC（含制作摊销） | ¥85 | ¥52 | ¥28 | 首期制作 + 6 个月投放摊销 |
| D7 留存 | 10% | **15%** | 22% | 注册后 7 日仍使用扩展或回访 Demo |

**6 个月漏斗预估（基准情景）**

```
月 UV 2,000 × 6 = 12,000 访客
  → 完播 7,200（60%）
  → 注册 960（8% of 12,000）
  → D7 留存 144（15% of 960）
```

| 指标 | 6 个月基准 | 业务解读 |
|------|------------|----------|
| **有效演示触达** | 7,200 次 | 可对比路演/投放效果 |
| **新增注册** | ~960 | 若 LTV ¥200， gross 价值 ~¥19.2 万 |
| **首期投入** | 30–60 万 | 含 Sprint + 传播制作 + 轻投放 |
| **首年 ROI** | **0.3–0.6x**（独立 App 视角仍为负） | 符合「品牌+获客杠杆」定位 |
| **扩展生态 ROI** | **1.2–1.8x** | 注册用户在 Bridge/扩展路径上的后续转化 |

**运营结论**：独立商业化首年 ROI 偏负 **已被 Round 1 采纳**；本 Brief 的价值在于 **把 Demo 做成可量化、可复用、可 A/B 的传播资产**，服务扩展生态而非单独 ARR。

### 1.4 关键数据指标（素材级）

## 二、5 分钟标准演示脚本

> **使用说明**：本脚本对应 PRD 三条必演示路径，总时长 **4:40–5:00**（含 20s 缓冲）。  
> **默认入口**：场景 B（AI 技术栈）；浏览器 Chrome 120+；1920×1080 全屏；关闭无关标签页。  
> **录屏复现**：场景 B `layoutSeed=42`，场景 A `layoutSeed=20260525`（与 GraphSnapshot 一致）。

### 2.0 演示前检查清单（30 秒）

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 冷启动 | 打开 URL 后 ≤3s 出现图谱 |
| 2 | FPS | 右下角/侧栏指标 ≥30 |
| 3 | 默认场景 | 场景 B · AI 技术栈 |
| 4 | 侧栏 | 空态文案「点击任意节点查看详情」 |
| 5 | 网络 | 可离线（静态包）或稳定 HTTP |
| 6 | 浏览器 | 隐藏书签栏；缩放 100% |

### 路径 1：震撼开场 ——「一镜到底自动巡航」（1:35）

**目标用户**：首次观看的陌生人（对外路演）  
**场景**：B · AI 技术栈 / 产业链  
**话术锚点**：*「复杂 AI 产业链，3 秒进入、无需导入，关系结构自动呈现。」*

| 时间 | 画面 / 操作 | 讲解词（中文） | 镜头备注 |
|------|-------------|----------------|----------|
| 0:00–0:15 | 浏览器打开 Demo URL；图谱力导向布局收敛 | 「大家好，这是 GraphSphere——一个**打开就能看**的 3D 知识图谱浏览器。注意，我们**没有导入步骤**，预置的 AI 产业链全景已经在动。」 | 全屏；保留顶栏标题即可；不要切场景 |
| 0:15–0:25 | 点击 **「▶ 演示巡航」**；相机开始环绕 | 「我点一下演示巡航，系统会自动带我走过这条产业链的关键枢纽。」 | 鼠标移开；让巡航自驱动 |
| 0:25–0:50 | 巡航停留 **AI 产业全景**（`ai-landscape`）；侧栏自动展开 | 「首先是产业全景——算力、模型、Agent、应用，不是表格，是**可走动的关系结构**。」 | 侧栏需清晰可见 |
| 0:50–1:10 | 巡航至 **基座大模型**（`foundation-llm`） | 「往下游走，基座模型连接训练框架、推理服务——依赖方向一眼能看懂。」 | 高亮节点 + 邻域 |
| 1:10–1:25 | 巡航至 **RAG 流水线**（`rag-pipeline`）→ **Agent 框架**（`agent-framework`） | 「RAG 把知识接到模型上，Agent 框架再往上接工具调用和应用——**三四跳就把故事讲圆**。」 | 完成 ≥3 锚点 |
| 1:25–1:35 | 巡航结束，相机缓慢 orbit；可停顿 2s | 「全程不需要我拖文件、连数据库。**3 秒进图，30 秒讲清结构**——这是第一眼看关系的方式。」 | 为路径 2 做过渡 |

**通过标准**：冷启动 ≤3s；巡航全程 ≥30fps；≥3 锚点；侧栏同步。

### 路径 2：关系洞察 ——「点击 → 邻域 → 读懂一个模块」（1:45）

**目标用户**：有技术背景的评估者（对内 / 深度访客）  
**场景**：A · Chrome 扩展 / Bridge 产品架构  
**话术锚点**：*「不是静态 PPT，而是可以沿着依赖关系逐层展开的活地图。」*

| 时间 | 画面 / 操作 | 讲解词（中文） | 镜头备注 |
|------|-------------|----------------|----------|
| 1:35–1:45 | 下拉 **场景** → 选「A · Chrome 扩展 / Bridge 架构」；等待 ≤2s | 「接下来切到**真实产品架构**——这是我们 Chrome 扩展和 Cursor Bridge 的模块关系，不是概念图。」 | 场景切换动画可保留 |
| 1:45–1:55 | 若演示仍在运行，点 **「暂停」** | 「我暂停自动巡航，手动展开你们最关心的部分。」 | — |
| 1:55–2:15 | 点击 **Cursor Bridge**（`cursor-bridge`） | 「点选 Bridge 服务——侧栏出现类型、简述、关联数。注意周围：**只高亮直接邻居**，其余降透明度。」 | 邻域高亮明显 |
| 2:15–2:35 | 侧栏展示：依赖 Agent Pool、SQLite、Fastify API 等 | 「Bridge 向下依赖 Agent Pool 和本地 SQLite，向上通过 Fastify 暴露多角色引擎、浏览器自动化——**评审时不用再问『这个模块连谁』**。」 | 侧栏滚动展示 neighbors |
| 2:35–2:55 | 点击 **Agent Pool**（`agent-pool`）→ 再点 **Multi-Role Engine**（`multi-role-engine`） | 「再点 Agent Pool，看 Multi-Role 编排如何挂接 Cursor SDK——**沿依赖逐层展开**，比 PPT 少一轮『你指的是哪一块』。」 | 二次点选 |
| 2:55–3:10 | 拖拽 orbit 旋转；滚轮缩放局部 | 「我可以自由旋转、缩放，从任意角度验证架构——这是**活地图**，不是截图。」 | 展示交互 |
| 3:10–3:20 | 可选：点 **GraphSphere Demo**（`graphsphere-demo`）展示自指 | 「图谱 Demo 本身也是 Dock 里的一个模块——产品狗食自己的可视化。」 | 彩蛋，可删 |

**通过标准**：点选响应 ≤200ms；邻域正确；侧栏与选中态同步。

### 路径 3：韧性证明 ——「双场景切换 + 降级仍可用」（1:25）

**目标用户**：技术决策人 / 运维  
**话术锚点**：*「同一套浏览体验，对内讲架构、对外讲趋势；老设备自动降级，演示不会翻车。」*

| 时间 | 画面 / 操作 | 讲解词（中文） | 镜头备注 |
|------|-------------|----------------|----------|
| 3:20–3:35 | 场景 A → 切回 **场景 B**；等待布局收敛 | 「同一条链接，对内讲架构、对外讲 AI 趋势——**场景切换 2 秒内完成**。」 | 展示下拉切换 |
| 3:35–3:50 | 在场景 B 手动点选 1 个节点；orbit 验证 | 「切换后交互不丢：点选、侧栏、旋转都正常。」 | — |
| 3:50–4:10 | 点击工具栏 **「2D」** 或 URL 加 `?force2d=1` 刷新 | 「如果现场机器 GPU 较弱，或 WebGL 不可用，会自动或手动切到 **2D 浏览模式**——文案会明确告知，但**核心能力都在**。」 | 角标变为 Canvas 2D |
| 4:10–4:25 | 2D 模式下点选节点 + 侧栏 | 「2D 模式照样点选、看邻域、读详情——**演示不会翻车**。」 | 降级必演项（技术观众） |
| 4:25–4:40 | 切回 **3D**；点 **重置视角** | 「切回 3D，一键重置视角——录屏、路演、投屏都能复现同一布局。」 | seed 固定可复现 |
| 4:40–5:00 | 全屏展示图谱 + CTA 口播 | 「GraphSphere v0.1 现在是**可演示的 3D 知识图谱浏览器**——零后端、离线可用、打开即看。欢迎扫码/访问链接试用；若要对接你们自己的 GraphSnapshot，导入能力在下一版。谢谢。」 | 结尾 CTA 卡片 |

**通过标准**：场景切换 ≤2s；2D 下 P0 交互不缺失；连续 3 次彩排无 P0/P1。

### 3.2 主录屏 ASSET-01 分镜（90s 精华版）

### 3.3 GIF 制作规范

| 项 | 规范 |
|----|------|
| **帧率** | 15–24 fps（文件大小优先） |
| **循环** | 无缝循环或 1 次播放后停最后一帧 |
| **鼠标** | 保留真实光标；高亮点击瞬间 |

## 四、风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 录屏帧率不足 | 中 | 传播质感差 | 录制前重启浏览器；关演示无关 Tab；必要时锁 150 节点场景 |
