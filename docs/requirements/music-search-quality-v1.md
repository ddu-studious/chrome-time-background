# 音乐搜索体验优化（2026-09-14）

## 已修复的问题

- 提交搜索后不再调用输入联想调度；清除定时器并递增联想版本，迟到响应不能重新遮住结果。
- 普通搜索默认“综合”，按歌曲、歌手、歌单分组。准确同名歌手优先出现，保留显式分类切换。
- AI的“播放某某”先用auto检索真实歌手和歌曲；同名歧义需要选择，不直接播放相关歌曲。明确歌手或歌单在AI区域保留候选和序号续选。
- 歌曲按准确歌名、指定歌手排序并按ID去重；保留Live等版本区别，候选显示专辑。组合关键词未准确命中时重搜歌名，重新核对歌手后再决定是否播放。
- 歌手搜索增加多端点回退；失败与没有结果分别提示。综合搜索部分失败时保留可用分类结果。
- 明确的歌曲/歌单前缀及书名号优先解析，避免把名称中的“的”误拆成歌手。
