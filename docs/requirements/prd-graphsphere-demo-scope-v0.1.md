**产品名称**：GraphSphere（3D 知识图谱浏览器 · 演示版）  
**版本**：v0.1 Demo Sprint

**定位**：可演示的 3D 知识图谱浏览器 —— 路演 / 获客 / 品牌载体，**非**知识管理平台或独立商业化 App

## 二、三条必演示路径（Demo Script Core）

> 每条路径 ≤2 分钟；三条合计 ≤5 分钟。QA 验收须 **连续 3 次** 无 P0/P1 缺陷。

### 路径 1：震撼开场 ——「一镜到底自动巡航」

| 项 | 内容 |
|----|------|
| **目标用户** | 首次观看 Demo 的陌生人（对外路演） |
| **入口** | 默认加载 **场景 B（AI 技术栈 / 产业链）** |
| **操作步骤** | ① 打开 Demo → ② 无需操作，自动进入 **演示模式**（相机缓慢环绕 + 沿预设路径巡航 ≥3 个核心节点）→ ③ 巡航结束停留于高亮节点，侧栏自动展开摘要 |
| **必现能力** | 3D 力导向布局、orbit 背景旋转、节点标签可读、演示模式可一键重播 |
| **话术锚点** | 「复杂 AI 产业链，3 秒进入、无需导入，关系结构自动呈现。」 |
| **通过标准** | 冷启动 ≤3s；巡航全程 ≥30fps；无卡顿跳帧、无标签重叠导致不可读 |

### 路径 2：关系洞察 ——「点击 → 邻域 → 读懂一个模块」

| 项 | 内容 |
|----|------|
| **目标用户** | 有技术背景的评估者（对内 / 深度访客） |
| **入口** | **场景 A（Chrome 扩展 / Bridge 产品架构）** |
| **操作步骤** | ① 暂停演示模式 → ② 点击核心节点（如 `Cursor Bridge` / `Agent Pool`）→ ③ 侧栏展示节点详情（名称、类型、简述、关联数）→ ④ **1 跳邻域高亮**，其余节点与边降透明度 → ⑤ 拖拽 orbit 旋转观察局部结构 |
| **必现能力** | 点选反馈、侧栏详情、邻域高亮 / 非邻域弱化、orbit 交互 |
| **话术锚点** | 「不是静态 PPT，而是可以沿着依赖关系逐层展开的活地图。」 |
| **通过标准** | 点选响应 ≤200ms；邻域计算正确（无漏边 / 误高亮）；侧栏与选中态同步 |

### 路径 3：韧性证明 ——「双场景切换 + 降级仍可用」

| 项 | 内容 |
|----|------|
| **目标用户** | 技术决策人 / 运维（关注稳定性与边界） |
| **入口** | 任意场景内 |
| **操作步骤** | ① 场景 A ↔ 场景 B **切换**（布局重新收敛，seed 固定可复现）→ ② 切换后手动选中 1 个节点验证交互未丢失 → ③（可选）在 WebGL 不可用环境展示 **2D Canvas 降级**，仍完成点选 + 侧栏 |
| **必现能力** | 场景切换、布局 seed 可复现、WebGL → 2D 降级、离线可用 |
| **话术锚点** | 「同一套浏览体验，对内讲架构、对外讲趋势；老设备自动降级，演示不会翻车。」 |
| **通过标准** | 场景切换 ≤2s；切换后 3 条交互（orbit / 点选 / 侧栏）均正常；2D 降级后 P0 交互不缺失 |

## 三、P0 / P1 砍需求清单

### 3.1 P0 —— D10 必须交付（In Scope）

| ID | 功能 | 用户故事 | 验收要点 |
|----|------|----------|----------|
| F-01 | 2 套预置场景 | 作为访客，我希望打开即可看到完整图谱，无需准备数据 | 场景 A/B 各 100–150 节点；GraphSnapshot JSON 离线加载 |
| F-02 | 3D 力导向渲染 | 作为访客，我希望看到节点自然聚类、关系清晰 | 200 节点内 ≥30fps；布局 seed 固定可复现 |
| F-03 | Orbit 交互 | 作为访客，我希望拖拽旋转、滚轮缩放观察结构 | 旋转 / 缩放流畅，无「甩飞」或无法回正 |
| F-04 | 点选 + 邻域高亮 | 作为访客，我希望点击节点后看到其直接关联 | 1 跳邻域高亮；非邻域弱化 ≥60% 透明度 |
| F-05 | 侧栏详情 | 作为访客，我希望读懂节点是什么、连向哪里 | 展示 label / type / 简述 / 度（入度+出度） |
| F-06 | 演示模式 | 作为讲解者，我希望一键自动巡航，不用手动操作 | 自动旋转 + ≥3 节点路径；可暂停 / 重播 |
| F-07 | 场景切换 | 作为讲解者，我希望在对内/对外叙事间切换 | A/B 切换 ≤2s；状态（演示/选中）合理重置 |
| F-08 | WebGL / 2D 降级 | 作为访客，我希望 WebGL 不可用时仍能浏览 | Probe 检测后自动降级；P0 交互保留 |
| F-09 | 离线可用 | 作为讲解者，我希望无网络环境也能演示 | 零后端；静态资源本地加载 |
| F-10 | 节点规模硬限 | 作为系统，我需要在超限时有明确边界 | 预置 ≤150；运行时硬限 200；超限走失败态文案 |

**P0 性能红线**：冷启动 ≤3s · 200 节点 ≥30fps · Chrome 120+ · 中配 MacBook + 1 台集显/触屏

## 四、失败态文案（User-Facing Copy）

> 原则：**说人话、给出路、不甩锅**。技术细节仅在有行动时使用「查看详情」折叠。

### 4.1 启动与渲染

| 场景 | 触发条件 | 主文案 | 副文案 / 行动 |
|------|----------|--------|---------------|
| **WebGL 降级** | Probe 检测 WebGL 不可用 | 当前环境已切换为 **2D 浏览模式** | 3D 效果需要较新的显卡驱动。您仍可查看节点与关系，所有演示功能均可使用。 |
| **布局计算中** | 力导向未收敛（首屏 >1s） | 正在整理图谱布局… | 节点较多，首次加载可能需要几秒钟。 |
| **冷启动超时** | 首屏 >5s 仍未可交互 | 加载时间超出预期 | 请刷新页面；若仍失败，尝试关闭其他占用 GPU 的标签页。 |
| **场景加载失败** | JSON 解析 / 校验失败 | 场景暂时无法打开 | 预置数据可能已损坏。请刷新或切换到另一场景。 |

### 4.2 规模与性能边界

| 场景 | 触发条件 | 主文案 | 副文案 / 行动 |
|------|----------|--------|---------------|
| **节点超限（P0）** | 运行时 >200 节点 | 当前图谱超出演示版规模上限（200 个节点） | 请使用预置场景，或等待后续版本支持更大图谱。 |
| **节点超限（P1 预览）** | 导入 >500 节点 | 图谱过大，建议拆分为多个场景 | 单个场景建议不超过 500 个节点，以保证流畅体验。 |
| **帧率过低** | 连续 3s <20fps | 检测到性能压力，已简化视觉效果 | 可尝试缩小浏览器窗口、关闭演示模式，或切换至 2D 模式。 |
| **内存压力** | 浏览器 Tab 内存告警 | 页面占用内存较高 | 建议刷新页面后从预置场景重新开始。 |

### 4.3 交互与演示

| 场景 | 触发条件 | 主文案 | 副文案 / 行动 |
|------|----------|--------|---------------|
| **未选中节点** | 侧栏打开但无 selection | 点击任意节点查看详情 | 演示模式下巡航会自动选中节点；也可随时手动点击。 |
| **演示模式冲突** | 演示中用户拖拽 orbit | 已暂停自动巡航 | 点击「继续演示」恢复自动路径，或自由探索。 |
| **演示路径异常** | 巡航目标节点不存在 | 演示路径暂时中断 | 请重新加载场景，或切换场景后重试。 |
| **场景切换中** | 切换 A/B 进行中 | 正在切换场景… | 布局将重新计算，请稍候。 |

### 4.4 浏览器与环境

| 场景 | 触发条件 | 主文案 | 副文案 / 行动 |
|------|----------|--------|---------------|
| **浏览器过旧** | 非 Chrome 120+ / 无 ES Module | 建议使用 **Chrome 120 或更高版本** | 当前浏览器可能无法完整展示 3D 效果。 |
| **离线资源缺失** | 静态资源 404 | 部分资源加载失败 | 请检查网络后刷新；完整离线演示需本地部署包。 |
| **P1 搜索无结果** | 搜索关键词无匹配 | 未找到「{query}」相关节点 | 尝试更短的关键词，或浏览预置场景中的核心节点。 |
| **P1 导入失败** | JSON 不符合 GraphSnapshot Schema | 无法导入该文件 | 请确认文件符合 GraphSnapshot v1 格式。{首个校验错误} |

## 五、边界条件与极端情况

| 边界 | 产品策略 |
|------|----------|
| 孤立节点（无边） | 允许存在；点选后邻域为空，侧栏提示「该节点暂无直接关联」 |
| 自环 / 重复边 | 数据层校验拒绝；不进入渲染（场景数据由 BA R-KG 合规保证） |
| 超长 label（>40 字） | 3D 标签截断 + 省略号；侧栏展示全文 |
| 同类型节点 >30 | 依赖聚类与演示巡航路径，不强制 P0 标签全显 |
| 演示录制中刷新 | seed 固定 → 布局一致；演示路径可复现 |
| 触屏设备 | P0 支持单指 orbit + 点选；不要求双指手势优化（P1） |
| 用户快速连点 | 防抖 150ms；以最后一次有效点选为准 |
