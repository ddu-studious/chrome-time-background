# PRD：YouTube 工作台集成 v3.20.0

> 实施状态：已完成 R2 级工程骨架。访客链接播放、本地稍后看/学习清单、官方 iframe、只读 OAuth/Data API 代理、错误模型、设置与启动台入口已实现；账号状态已拆分为“OAuth 未配置 / 待授权 / 已连接 / 授权过期”，本地数据清空采用二次确认。Google OAuth client_id、真实账号数据、分页、导出与 `chrome-extension://` 播放验收仍按下文验收项推进。

## 一、产品定义

### 1.1 背景

中国风景时钟已有完整的 B 站视频工作台。国际内容、英文教程和公开课程主要集中在 YouTube，用户需要在新标签页中完成搜索、订阅浏览、播放列表整理与学习观看，而不是频繁切换站点。

YouTube 官方 API 不开放个性化首页、观看历史和官方稍后看，因此本需求不是 B 站功能的复制，而是在同一视觉框架下提供一个能力边界清晰的 YouTube 工作台。

### 1.2 产品目标

- 在扩展内完成 YouTube 内容发现、账号资料浏览和官方播放器观看。
- 复用 B 站工作台的高密度桌面布局、列表操作和状态反馈。
- 使用官方 OAuth、Data API 与 Embed，不依赖 Cookie 注入、DOM 抓取或媒体直链。
- 对不可提供的历史、官方稍后看、YouTube 官方首页推荐流与画质外控给出诚实说明。

### 1.3 非目标

- 不复制 YouTube 首页，不嵌入完整 `youtube.com` 页面。
- 不读取观看历史，不同步官方 Watch Later。
- 不下载、提取、代理或后台播放 YouTube 音视频流。
- 不屏蔽广告、品牌、相关推荐或原生控制。
- 不在 MVP 提供上传、发评论、订阅管理和播放列表写操作。
- 不把扩展根据订阅整理的「为你推荐」宣称为 YouTube 官方首页算法结果。

## 二、目标用户与核心场景

### 2.1 用户

- 经常通过 YouTube 学习技术、产品、设计和英语内容的桌面用户。
- 已有 Google / YouTube 账号，希望浏览订阅、喜欢和播放列表。
- 只想临时搜索并播放公开视频、不愿授权账号的访客。

### 2.2 用户故事

1. 作为访客，我希望粘贴 YouTube 链接或视频 ID 并直接播放，不先授权账号。
2. 作为用户，我希望授权后查看订阅频道、喜欢的视频与自己的播放列表。
3. 作为学习者，我希望把公开视频加入扩展本地「稍后看」或「学习清单」。
4. 作为用户，我希望搜索时能看到视频、频道、播放列表，并明确搜索配额状态。
5. 作为用户，当视频禁止嵌入时，我希望一键在 YouTube 原页继续。
6. 作为用户，我希望随时断开账号并删除扩展保存的 YouTube 数据。
7. 作为用户，我希望首页先看到订阅频道的近期内容，并让趋势只展示我主动选择的兴趣分类。

## 三、版本范围

### R0：可行性 PoC（开发前闸门）

| 编号 | 验证项 | 通过标准 |
|---|---|---|
| POC-01 | 打包扩展中嵌入官方播放器 | 公开视频可播放，Referer / Client ID 合规，不出现 `153` |
| POC-02 | 禁止嵌入视频 | 能识别 `101/150` 并显示原页打开 |
| POC-03 | OAuth 只读授权 | `chrome.identity.getAuthToken()` 成功，能获取 `channels.list(mine=true)` |
| POC-04 | 令牌恢复 | 401 后清理缓存令牌并可重新授权 |
| POC-05 | 撤销与删除 | 断开后令牌失效，本地账号数据和 API 缓存被清除 |

任一核心闸门失败时：

- POC-01 失败：工作台保留数据浏览，播放统一跳 YouTube 原页。
- POC-03 失败：仅保留访客模式和公开视频搜索；不上线账号能力。

### R1：MVP（只读）

| 能力 | 优先级 | 说明 |

| YouTube 入口 | P0 | Dock 增加 YouTube，设置中可启停 |

| 为你推荐 | P0 | 从最多 12 个订阅频道各取近期公开视频，按发布时间整理；明确不是 YouTube 官方首页算法 |
| 兴趣趋势 | P0 | 对文化、旅游、科学与技术、教育、娱乐、游戏、音乐、体育执行跨圈层官方评分排序搜索；每轮目标为中华文化圈 40%、欧美 30%、泛亚 30%，只展示 4 分钟以上的优选常规视频 |
| 搜索 | P0 | 视频 / 频道 / 播放列表；只在显式提交时调用 |

| 账号与隐私设置 | P0 | 授权状态、撤销、删除本地数据、政策链接 |

### R2：增强写操作

- 对单个视频点赞/取消点赞。
- 新建或选择 YouTube 播放列表并添加视频。
- 订阅/取消订阅频道。
- 评论读取；写评论单独评估，不与 MVP 一起申请权限。
- 所有写操作在触发时增量申请 `youtube.force-ssl`，并展示目标对象和结果。

### R3：体验增强

- 若官方 IFrame Player 在 MV3 中的合规控制方案 PoC 通过，增加外部播放/暂停、进度和倍速状态。
- 不增加外部画质控制；IFrame API 已不支持设置画质。
- 支持从剪贴板识别 `youtube.com/watch`、`youtu.be`、`youtube.com/shorts` URL。
- 支持频道内筛选、播放列表分页和本地学习进度备注。

## 四、信息架构

### 4.1 顶部

- 来源标识：YouTube。
- 账号状态：OAuth 未配置 / 待授权 / 已连接账号 / 授权过期；“访客能力”只描述可用能力，不再冒充账号状态。
- 全局搜索：视频、频道、播放列表或 YouTube URL。
- 操作：刷新、账号与隐私、关闭。

### 4.2 一级与二级导航

```text
发现
├── 为你推荐
├── 兴趣趋势
└── 搜索（由顶部输入触发，保留结果页）

我的
├── 订阅
├── 播放列表
├── 喜欢
├── 扩展稍后看
└── 学习清单
```

导航使用「为你推荐」，但页面必须同时标明「来自你的订阅频道 · 非 YouTube 首页算法」；不出现「历史」「YouTube 稍后看」「课程」。

### 4.3 主工作台

- 左侧约 70%：播放器、当前视频信息、来源动作和空态概览。
- 右侧约 30%：当前导航对应的内容列表与分页。
- 播放器使用完整 16:9 区域，任何提示、按钮、Toast 不得覆盖 iframe。
- 列表切换不自动播放，不中断当前视频；关闭工作台销毁 iframe 并停止播放。

## 五、详细功能

### 5.1 连接与授权

#### 访客模式

- 可粘贴视频链接/ID并播放。
- 若公共 Data API 凭证方案通过发布审查，可使用趋势和搜索；否则搜索按钮跳 YouTube 原页。
- 不显示订阅、喜欢和私人播放列表内容。

#### 已连接模式

- 展示 Google / YouTube 账号头像、频道名和只读授权范围。
- 登录按钮必须由用户点击，不能在初始化或打开工作台时自动弹窗。
- 权限被拒绝后保留访客模式，并说明受影响功能。

### 5.2 为你推荐

- 默认首页读取 `subscriptions.list(mine=true)` 的前 12 个订阅频道，并从各频道上传列表最多取 2 条近期公开视频。
- 合并结果按发布时间倒序，最多展示 24 条；不计算或展示自有推荐分。
- 页面固定展示推荐依据和来源边界，不宣称等同 YouTube 首页个性化推荐。
- 没有订阅或近期投稿时，不回退到无关的全站趋势，改为引导用户选择兴趣趋势分类。

### 5.2.1 兴趣趋势

- 默认主题为「文化」，可切换文化、旅游、科学与技术、教育、娱乐、游戏、音乐、体育并持久化。
- 旅游覆盖简繁体的中国旅游、中文旅行、旅游攻略、城市漫游与人文地理主题。
- 每个主题拆为三套独立查询：中华文化圈使用简繁体主题词与 `relevanceLanguage=zh-Hans`，欧美使用欧美主题词与英文相关性，泛亚覆盖日本、韩国、印度和东南亚且不锁定单一语言。
- 每轮最多 20 条，目标配额固定为中华文化圈 8、欧美 6、泛亚 6，即 4:3:3；某圈层不足时展示实际数量，不允许其他圈层越界补位。
- 加载顺序固定为中华文化圈 → 欧美 → 泛亚。每层完成后立即渲染已有卡片与圈层进度，不等待三层全部完成；单层失败不清空已经成功的结果。
- 不再对任意分类调用 `videos.list(chart=mostPopular, videoCategoryId=...)`；该榜单已主要收敛到音乐、电影和游戏，其他分类可能返回 `videoChartNotFound` / `Requested entity was not found`。
- 每个主题按三个圈层分别调用一次 `search.list(order=rating, videoDefinition=high, publishedAfter=近90天)`，每层搜索后立即调用 `videos.list(id=...)` 补齐状态与公开统计。
- 详情阶段使用 `contentDetails.duration` 排除 4 分钟以下视频；不通过页面抓取判断 Shorts。
- 质量优选只使用 YouTube 原始字段：排除不可嵌入、正在/即将直播及直播回放，优先至少 1 万观看且点赞信号充分的内容；不足 24 条时依次放宽到 1 千观看和其他合格长视频。
- 每个圈层内同一频道最多展示 2 条，避免单个大频道占满圈层配额；不生成或展示自定义“质量分”。
- 每类结果缓存 15 分钟，切换回来不重复消耗搜索额度；合并过滤后最多展示 24 条，过滤为空时不混入 Shorts 补位。
- 卡片展示官方标题、频道、发布时间、时长和公开统计。
- 刷新不重建播放器，不清除当前列表滚动位置。

### 5.3 搜索

- 支持视频、频道、播放列表三类结果。
- 视频请求增加 `videoEmbeddable=true`，但仍要处理视频后续变为不可嵌入的情况。
- 输入联想仅使用本地搜索历史，不逐字符请求 YouTube。
- 每次显式提交或翻页消耗一次独立搜索额度。
- 配额用尽后保留已有结果，并提供「在 YouTube 搜索」。

### 5.4 订阅

- `subscriptions.list(mine=true)` 分页展示，支持字母/相关性排序。
- 默认只展示频道，不对全部订阅频道并发拉取最新视频。
- 用户点击频道后，再请求该频道最新公开视频。
- 提供显式「最近更新」入口：只汇总当前已加载的最多 50 个订阅频道，每个频道取最新 1 条并按发布时间倒序；不在进入订阅页时自动消耗这批配额。
- 订阅动作属于 R2，需要写权限和明确确认反馈。

### 5.4.1 内容布局

- 为你推荐、兴趣趋势、订阅、频道更新、播放列表、喜欢、搜索结果、本地稍后看与学习清单都提供「方框 / 列表」切换。
- 布局偏好保存在扩展本地，对所有 YouTube 内容页统一生效；不写回 YouTube。
- 频道卡与播放列表卡必须可点击，分别进入频道最近更新与播放列表内容，不得使用禁用按钮伪装入口。

### 5.5 播放列表与喜欢

- 播放列表页展示用户创建的列表，不把系统 Likes 混入普通列表。
- 「喜欢」使用账号 `relatedPlaylists.likes` 对应列表。
- 私密播放列表仅在 OAuth 授权成功时展示。
- 删除、移动、添加属于写操作，R1 只读。

### 5.6 扩展稍后看

- 使用 `chrome.storage.local`，结构至少包含 `videoId/title/channel/thumbnail/duration/addedAt/source`。
- 所有入口展示「扩展本地」标识。
- 不与 YouTube Watch Later 同步，也不使用 Watch Later 名称或图标暗示同步。
- 支持单项移除、清空前确认、导出 JSON。

### 5.7 学习清单

- 用户可把视频或播放列表加入本地学习清单。
- 可记录备注、学习状态（未开始/学习中/已完成）和最近打开时间。
- 不使用 YouTube API 数据生成自有学习评分。
- 学习状态是扩展本地数据，必须与 YouTube 播放统计分开显示。

### 5.8 播放器与视频动作

- iframe 使用官方 Embed；播放器内原生控制全部保留。
- 外部仅显示标题、频道、发布时间和明确动作，不重复画进度条、速度或画质状态。
- R1 动作：加入扩展稍后看、加入学习清单、复制链接、原页打开。
- R2 动作：点赞、加入 YouTube 播放列表、订阅。
- `101/150`、`153`、地区限制、年龄限制、私密/删除、网络失败使用不同文案。

## 六、状态设计

| 状态 | 主区 | 侧栏 | 主操作 |
|---|---|---|---|
| 首次进入 | 能力说明和隐私摘要 | 推荐能力或访客说明 | 连接 YouTube |
| 已连接无播放 | 订阅推荐 / 兴趣趋势 | 当前列表 | 选择视频 |
| 播放中 | 官方播放器 + 元数据 | 列表保持上下文 | 原页打开 / 本地收藏 |
| 授权过期 | 仍保留本地列表 | 私人列表锁定 | 重新连接 |
| 搜索配额用尽 | 保留最后结果 | 不允许继续翻页 | 在 YouTube 搜索 |
| 禁止嵌入 | 官方封面、原因、视频元数据 | 列表可继续选择 | 在 YouTube 打开 |
| `153` 客户端标识错误 | 技术诊断摘要 | 暂停新 iframe | 原页打开 / 查看诊断 |
| 离线 | 最近缓存和本地清单 | 网络数据不可用 | 重试 |

## 七、数据与接口

### 7.1 P0 接口

| 用途 | API | 缓存 |
|---|---|---|
| 当前频道 | `channels.list(mine=true)` | 会话 + 15 分钟 |
| 为你推荐 | `subscriptions.list` + `channels.list` + `playlistItems.list` | 15 分钟 |
| 兴趣趋势 | 三圈层 `search.list(order=rating, videoDefinition=high)` + 分层 `videos.list(id=...)` | 15 分钟 |
| 视频详情 | `videos.list(id=...)` | 15 分钟，最多 50 ID 合并 |
| 搜索 | `search.list` | 相同查询 10 分钟 |
| 订阅 | `subscriptions.list(mine=true)` | 15 分钟 |
| 播放列表 | `playlists.list(mine=true)` | 15 分钟 |
| 列表内容 | `playlistItems.list` | 15 分钟 |
| 评论 | `commentThreads.list(videoId=...)` | P1，10 分钟 |

### 7.2 本地存储

```js
youtubeSettings = {
  enabled: true,
  regionCode: 'CN',
  lastTab: 'recommended',
  trendCategoryId: 'culture',
  trendPreferenceVersion: 2,
  accountChannelId: '',
  grantedScopes: [],
}

youtubeLocalQueue = [{
  videoId, title, channelId, channelTitle,
  thumbnail, duration, addedAt,
}]

youtubeLearningList = [{
  videoId, title, channelTitle, thumbnail,
  status, note, addedAt, lastOpenedAt,

```

禁止把 OAuth access token 写入 `chrome.storage`；由 `chrome.identity` 管理。

## 八、权限与发布要求

### 8.1 Manifest

- 新增 `identity` 权限。
- 增加 `oauth2.client_id` 与只读 scope。
- 精确增加 Google APIs、YouTube Embed 和官方图片域权限；不因 YouTube 功能扩大到新的 `<all_urls>` 依赖。
- 不新增 YouTube 内容脚本，不注入完整 YouTube 页面。

### 8.2 Google Cloud / OAuth

- 一个扩展对应一个 YouTube API Project。
- 启用 YouTube Data API v3。
- 创建 Chrome Extension OAuth Client，绑定发布扩展 ID。
- 配置 OAuth Consent Screen、测试用户、隐私政策、服务条款与授权撤销说明。
- 正式发布前完成敏感 scope 验证；写权限单独评审。

## 九、验收标准

### R0

- [ ] 打包扩展中连续播放 10 个允许嵌入的视频，无 `153`。
- [ ] 禁止嵌入视频稳定进入原页兜底。
- [ ] OAuth 首次授权、静默续期、401 恢复、用户拒绝、撤销五条链路通过。

### R1 功能

- [ ] 趋势、搜索、订阅、播放列表、喜欢均能分页和恢复上下文。
- [ ] 工作台任何时刻最多只有一个播放器实例。
- [ ] 切换列表不会自动播放或中断当前视频。
- [ ] 本地稍后看与学习清单不被描述成 YouTube 官方数据。
- [ ] 画质与速度不显示无法验证的外部状态。
