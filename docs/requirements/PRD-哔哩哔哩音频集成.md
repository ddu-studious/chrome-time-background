# PRD: 哔哩哔哩音频集成

> 版本：v1.0  
> 创建日期：2026-03-20  
> 状态：**待开发**  
> 前置调研：[bilibili-offscreen-audio-research.md](../research/bilibili-offscreen-audio-research.md)

## 1. 背景

当前扩展已实现网易云音乐的 Offscreen Document 独立播放模式。用户反馈希望能支持更多音乐/音频来源。哔哩哔哩作为国内主流视频平台，拥有大量音乐、ASMR、播客等音频内容，是优先扩展的方向。

## 2. 目标

在现有音乐播放器架构上，新增哔哩哔哩音频播放能力，复用 Offscreen Document 播放引擎。

## 3. 功能需求

### 3.1 核心功能

| 功能 | 优先级 | 描述 |
|------|--------|------|
| 登录检测 | P0 | 通过 chrome.cookies 检测 bilibili.com SESSDATA |
| 视频音频播放 | P0 | 提取视频音频轨，在 Offscreen Document 播放 |
| 搜索 | P0 | 搜索视频/音频内容并播放 |
| 收藏夹浏览 | P1 | 浏览用户收藏夹，选择播放 |
| WBI 签名 | P0 | 实现 B 站 API 所需的 WBI 签名机制 |

### 3.2 播放器 UI

复用现有音乐播放器 UI，在连接面板增加哔哩哔哩入口：

```
┌─────────────────────────────┐
│  连接音乐平台                │
│  ┌──────────┐ ┌──────────┐ │
│  │ 网易云音乐 │ │ 哔哩哔哩  │ │
│  └──────────┘ └──────────┘ │
│  无需打开网站，登录浏览器即可 │
└─────────────────────────────┘
```

### 3.3 技术约束

- 使用 declarativeNetRequest 处理 CDN Referer
- WBI 密钥缓存 30 分钟
- 完整 Cookie 传递（含 buvid 系列）
- 错误码统一处理（-352、412 等）

## 4. 非功能需求

- 不增加额外的 host_permissions（使用 optional_host_permissions）
- 首次使用时动态申请权限
- 播放错误自动重试（最多 3 次）

## 5. 验收标准

- [ ] 浏览器登录 B 站后，扩展能检测到登录状态
- [ ] 能搜索并播放 B 站视频的音频轨
- [ ] 能浏览收藏夹并批量播放
- [ ] 切换网易云/B 站时，播放状态正确切换
- [ ] CDN 播放不出现 403 错误

## 6. 排期估计

| 阶段 | 工作量 | 产出 |
|------|--------|------|
| Phase 1: PoC | 1-2 天 | WBI + 播放验证 |
| Phase 2: MVP | 3-5 天 | 搜索 + 播放 + 收藏夹 |
| Phase 3: 增强 | 2-3 天 | 音质选择 + 推荐 + 错误处理 |
