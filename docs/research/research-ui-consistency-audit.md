## 二、发现的不一致问题

### 🔴 严重不一致（3 处）

1. **磨砂玻璃参数混乱**  
   - 标准版: `blur(24px) saturate(180%)` — 任务侧边栏、备份、日历、浮动面板
   - 降级版: `blur(20px)` — 设置面板、任务表单弹窗  
   - 缺失: 无磨砂 — 番茄钟、统计面板
   - 特殊: `blur(14px)` — Ticker

2. **背景色方案分裂为 3 套**  
   - A 方案（半透明白）: `rgba(255,255,255,0.08) → 0.03` — 侧边栏、备份、日历、浮动面板
   - B 方案（深色实底）: `rgba(40,40,50,0.98)` / `rgba(30,35,50,0.95)` — 番茄钟、统计、关于
   - C 方案（黑色实底）: `rgba(0,0,0,0.8)` — 设置面板

3. **设置面板与其他面板风格完全不同**  
   纯黑背景、无边框、blur 参数低、无 saturate，像是早期代码遗留

### 🟡 轻微不一致（5 处）

4. 圆角值不统一：有 `16px`、`20px`、`12px` 三种
5. 阴影层级不一致：有 `0.4`、`0.5` 两种透明度
6. 关闭按钮尺寸不一致：有 `32×32`、`28×28`、`26×26` 三种
7. 遮罩色不一致：有 `rgba(0,0,0,0.6)` 和 `rgba(0,0,0,0.5)` 两种
8. 边框透明度不一致：有 `0.08`、`0.1`、`0.12`、`0.15` 四种

## 三、统一方案建议

### 设计理念

> **"毛玻璃山水画"** — 所有组件都是悬浮在中国风景背景之上的毛玻璃层。  
> 统一的半透明白色渐变 + 磨砂效果，让背景隐约可见，营造层次感和一致感。

### 推荐的 Design Tokens

```
/* ===== 全局 Design Tokens ===== */

/* 遮罩层 */
--overlay-bg: rgba(0, 0, 0, 0.6);
--overlay-blur: blur(4px);

/* 面板背景（统一半透明白色渐变） */
--panel-bg: linear-gradient(135deg, rgba(255, 255, 255, 0.08), rgba(255, 255, 255, 0.03));
--panel-bg-solid: linear-gradient(135deg, rgba(40, 40, 50, 0.95), rgba(30, 30, 40, 0.95));

/* 磨砂玻璃 */
--glass-blur: blur(24px) saturate(180%);

/* 圆角 */
--radius-panel: 20px;       /* 大面板 */
--radius-card: 16px;        /* 卡片/弹窗 */
--radius-element: 12px;     /* 内部元素 */
--radius-button: 8px;       /* 按钮 */

/* 边框 */
--border-panel: 1px solid rgba(255, 255, 255, 0.1);
--border-light: 1px solid rgba(255, 255, 255, 0.08);

/* 阴影 */
--shadow-panel: 0 20px 60px rgba(0, 0, 0, 0.4);
--shadow-float: 0 8px 32px rgba(0, 0, 0, 0.25), 0 2px 8px rgba(0, 0, 0, 0.15);

/* 按钮 */
--btn-close-size: 32px;
--btn-close-radius: 8px;
--btn-close-bg: rgba(255, 255, 255, 0.08);
--btn-close-hover: rgba(255, 100, 100, 0.2);

/* 头部 */
--header-bg: linear-gradient(180deg, rgba(255, 255, 255, 0.05), transparent);
--header-border: 1px solid rgba(255, 255, 255, 0.08);
--header-title-color: #fff;
--header-title-size: 16px;

/* 强调色 */
--accent-blue: rgba(100, 180, 255, 0.85);
--accent-red: #ff6b6b;
--accent-green: #5cd85c;
--accent-orange: #ff9800;
--accent-purple: #ab47bc;

/* 文字 */
--text-primary: rgba(255, 255, 255, 0.95);
--text-secondary: rgba(255, 255, 255, 0.7);
--text-muted: rgba(255, 255, 255, 0.5);
```

### 各组件应统一为

| 组件类型 | 背景 | 磨砂 | 圆角 | 关闭按钮 |
|---------|------|------|------|---------|
| 模态面板 | `--panel-bg` | `--glass-blur` | `20px` | `32×32 r8` |
| 侧滑面板 | `--panel-bg` | `--glass-blur` | 0 | `32×32 r8` |
| 内嵌弹窗 | `--panel-bg-solid` | `blur(20px)` | `16px` | `28×28 r8` |
| 浮动面板 | `--panel-bg` | `--glass-blur` | `16px` | `26×26 r8` |
| 信息栏 | `--panel-bg` 简化 | `--glass-blur` 简化 | `12px` | — |

## 六、图标设计升级

> 升级日期：2026-02-08

### 旧图标问题
- 蓝色圆形底 + 粗糙绿色三角山 + 简陋白色时钟
- 配色方案（Material Blue + Green）与项目"深蓝夜空山水"主题不匹配
- 16px/48px 缩小后细节丢失严重

### 新图标设计
- **设计理念**: "深蓝夜空下的山水时钟" — 与毛玻璃山水画主题统一
- **底色**: 深蓝渐变 `#1a2a4a → #2a3d6b`（非 Material Blue）
- **形状**: 圆角矩形 `rx=28`（更现代，非传统圆形）
- **山水**: 双层渐变山脉剪影 + 底部水面光泽
- **时钟**: 精致刻度 + 10:10 经典指针 + 蓝色中心点
- **16px 专用**: 简化为仅保留时钟圆圈+指针+山脉轮廓，确保小尺寸可辨识
