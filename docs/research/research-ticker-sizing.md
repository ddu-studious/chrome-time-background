# Ticker 尺寸优化调研报告

> **调研日期**: 2026-02-08  
> **项目**: 中国风景时钟 Chrome 扩展 — 信息栏尺寸优化  
> **调研目标**: 评估用户反馈"信息栏偏小"是否合理，制定最佳尺寸方案  
> **结论**: ✅ **用户感知正确**，当前尺寸偏保守，推荐适度放大

### 1.3 问题诊断

- **宽度偏窄**：720px 仅占 1920px 屏幕的 37.5%，用户在大屏上会感觉信息栏"缩在中间"
- **主卡片偏紧凑**：52px 高度下，中文标题（14px）+ 描述（12px）显示空间有限
- **迷你栏可读性**：12px 字号在 30px 高度内，视觉上偏密集
- **控制按钮**：22px 低于 WCAG 2.2 AA 级最低标准 24×24px

## 三、放大方案评估

### 3.1 用户需求：整体 ×1.5、宽度 +1/3

| 参数 | 现值 | 用户期望（×1.5 / +1/3） | 评估结论 |
|------|------|------------------------|---------|
| 最大宽度 | 720px | 960px（+1/3） | ✅ 合理，960px = 50% 1920px，在推荐范围内 |
| 主卡片 padding | 12px 18px | 18px 24px | ✅ 合理，提升呼吸感 |
| 标题字号 | 14px | 18px（×1.29） | ⚠️ 过大，建议 16px |
| 描述字号 | 12px | 14px | ✅ 合理 |
| 迷你栏高度 | 30px | 38px | ✅ 合理 |
| 迷你栏字号 | 12px | 13px | ✅ 合理 |
| 数据源图标 | 20px | 26px | ⚠️ 略大，建议 24px |
| 控制按钮 | 22px | 28px | ✅ 合理，超过 WCAG AA 24px |
| **总高度** | **~82px** | **~115px** | ✅ 合理，在推荐 96~114px 范围 |

### 3.2 推荐方案（折中优化）

综合用户感受和行业标准，不是简单粗暴地将所有尺寸 ×1.5，而是**按层级差异化放大**：

| 参数 | 现值 → 推荐值 | 放大比 | 理由 |
|------|--------------|--------|------|
| `max-width` | 720px → **960px** | ×1.33 | 用户需求 +1/3，恰好 50% 屏宽 |
| 主卡片 padding | 12px 18px → **16px 22px** | ×1.33 / ×1.22 | 增加呼吸感但不浪费空间 |
| 标题字号 | 14px → **16px** | ×1.14 | 中文标题 16px 更舒适，不过分 |
| 描述字号 | 12px → **13px** | ×1.08 | 微增即可，避免主次混淆 |
| 图标尺寸 | 20px / 28px → **24px / 32px** | ×1.2 / ×1.14 | 适度放大 |
| 迷你栏高度 | 30px → **36px** | ×1.2 | 增加可读性 |
| 迷你栏字号 | 12px → **13px** | ×1.08 | 微增 |
| 迷你栏图标 | 10px → **12px** | ×1.2 | 与正文对齐 |
| 控制按钮 | 22px → **28px** | ×1.27 | 超过 WCAG AA |
| metric 字号 | 12px → **13px** | ×1.08 | 与主卡片协调 |
| metric padding | 3px 8px → **4px 10px** | — | 视觉平衡 |
| 计数器字号 | 10px → **11px** | ×1.1 | 微增 |
| Task Ticker 高度 | 34px → **40px** | ×1.18 | 与 Tech Ticker 保持比例 |
| Task Ticker 宽度 | 720px → **960px** | ×1.33 | 统一 |

### 3.3 预期效果

| 指标 | 改善 |

## 四、风险与注意事项

1. **小屏适配**：960px 在 1366×768 笔记本上约占 70%，仍在合理范围，但需保留 `width: 100%` 自适应
2. **布局比例**：Ticker 放大后与时钟、天气区域的视觉层级关系需验证，不可喧宾夺主
3. **Task Ticker 同步**：两个 Ticker 宽度必须统一，避免上下错位

## 五、结论

| 结论 | 说明 |
|------|------|
| **用户感知正确** | 720px 在大屏上确实偏保守 |
| **推荐放大** | 宽度 +1/3 至 960px，整体约放大 20%~30%（非均匀 ×1.5） |
| **差异化策略** | 结构尺寸（宽度、padding）放大更多，文字字号温和增长 |
| **WCAG 改善** | 控制按钮达标 AA 级 |
