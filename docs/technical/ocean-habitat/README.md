本目录是海洋能力后续开发的入口。当前只在 `test/demos/reef-3d-lab-20261021/` 验证，正式首页、背景设置和真实任务数据不改。用户约束：相对尺度真实、同种个体不同大小；固定造景可关闭；喂食、拖拽、任务水母保留；优先复用 Deskworlds / Three.js 和现有模块。
