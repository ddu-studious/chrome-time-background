## 第二轮结果（历史）

复现入口 `http://127.0.0.1:18766/`。点“开始礁缝追逃”会重置为 4 cm 小鱼与 25 cm 捕食者并开启礁缝栖息地；这一步只改变本页内存。事件/状态显示用于核对实际运行。

确定性样本：同一个固定种子和实际 World / Yuka / BVH 步进，在约 2.40 秒进入躲藏、6.88 秒大鱼到达另一侧出口、8.48 秒因掩体不可达结束追击、11.58 秒小鱼离开。24 秒轨迹逐步检查为 0 个穿透姿态，单步最大位移约 3.97 mm。这些是当前固定场景结果，不是自然界生物速度或成功率，也不是所有场景非穿透证明。

路径反例包括：同缝大小体型区别；隐藏猎物换位置不改变捕食者最后记忆与已选路径；场景关闭清图/清路线；低造景范围不把演练鱼随机搬离场景。三维水母几何和绘制注入形状也有自动检查。

Chrome 实际验收已看到重复的躲藏、出口搜索、结束追击和离开事件；三维水母在观察模式有钟罩/内层/实体触手；真实拖拽模拟失败时保留任务，关闭失败模拟后同样拖拽收到完成 1/3 的回执。证据在 `output/aquarium-review-20261021/reef-3d-v2/`，最终统计以该目录 `RESULTS.md` 为准。

运行新检查：`npm --prefix test/demos/reef-3d-lab-20261021 test`。复现轨迹：`node test/demos/reef-3d-lab-20261021/probe-crevice.mjs`。服务启动时冻结资源，所以修改后须 build、重启、reload。最终 bundle、源文件指纹、截图和日志应一起保留。

## 第二轮当时的限制

- 导航是编排栖息地内的有限水平航路，节点是三维位置；尚非任意海域的全空间导航、自动孔洞识别或群体交通协调。
- 完整 Deskworlds 浅礁保留旧局部掩体搜索；不能把礁缝场景的验收泛化到它的全部洞穴。
- 胶囊/包围球与有限采样偏保守，不能代替独立物理求解器；珊瑚触手和软组织未做逐根碰撞。
- 三维水母的运动/任务命中仍由原屏幕坐标核心提供，视觉映射到三维前景；不是已迁移到米制生态中的水母生物学模拟。透明材质没有对 DOM 壁纸做物理折射。
- 未录制视频；提供固定步长轨迹、事件和操作截图。CPU 模拟耗时与 Three 提交耗时不能冒称 GPU 耗时或整页能耗。
- 本轮无新增依赖，既有固定上游/模型校验继续生效；原型 HTTP 页面验证不代表 MV3 正式扩展与真实账号已验收。

## 正式接入前的开发清单

1. **固化视觉与行为验收**：用户体验体积、真实比例、躲藏等待、绕行与水母手感；扩展 18/25/45 cm、不同小鱼尺寸、场景比例/镜头、窄屏与低性能设备矩阵。无入口/无路线时显示降级原因。
2. **正式绘制接口**：为本仓库 JellyfishSkin.create 提供显式 drawFrame 参数，保持默认 2D 回退路径由配置选择；删除原型构建文本转换。新旧渲染器互斥，不允许双绘制或静默冒充 3D。
3. **资产与尺度合同**：逐物种确认科学名称、TL/SL/盘宽、模型锚点、授权与纹理预算。年龄未知保持未知，成长曲线有资料后再启用；任务水母继续与生态居民分开。
4. **数据迁移**：由唯一居民存储入口持久化个体尺寸/阶段/版本，先备份，拒绝未知版本写入；捕获只影响展示状态，不永久删居民或任务。原型内存键不直接变成正式存储键。
5. **正式生命周期**：加载失败、取消、WebGL context lost、切模式、失焦、隐藏 60 秒深度释放、回来重建均做原宿主合同验收；关闭造景撤颜色/深度/导航；释放整个 renderer/纹理后任务回执不能重放。
6. **交互与权限**：喂食/捞出/任务完成走原所有者；任务失败/超时/unknown 继续保持原规则。无摄像头、麦克风、外部模型调用或新网络权限。保持 CSP；若未来引入 WASM 物理库再单独评估。
7. **性能门槛**：最终构建在真实 Chrome 扩展逐档测 8/20/40 动物、任务水母数上限、首次模型加载、导航建图、透明材质 overdraw、GPU 时间和隐藏恢复；降画质先减少细节和频率，不能把鱼变回纸片却标称真 3D。
8. **可回滚集成**：先独立设置开关和小范围实验，备份旧入口/旧数据结构；真实扩展、实际任务与背景验收通过后再默认启用。本轮没有执行这些正式步骤。
