## 2. 新体态的完整包围合同

`clown-analytic-v1` 覆盖原版/参考版各自的 FULL 与 FAR 网格，共 **19,060 个顶点**。这是四份几何的合计，不是单条鱼的顶点数。依据见 [身体包围证明](../../../output/aquarium-review-20261022/reef-3d-v5/body-envelope-proof.json)。

| 项目 | 合同 |
|---|---|
| 总长 | TL，物理世界单位为米；原模型 TL 为 1.25 |
| 胶囊半径 | `0.395 × TL` |
| 胶囊轴段半长 | `0.28 × TL`，轴段为 `[-half,+half]` |
| 包含整个胶囊的转身球半径 | `0.675 × TL` |
| 尾摆幅度 | `0 ≤ tailAmplitude ≤ 0.117` |
| 弯身 | `abs(bend) ≤ 0.42` |
| 胸鳍划动 | `0 ≤ rowing ≤ 0.85` |
| 联合约束 | `tailAmplitude + abs(bend) ≤ 0.495` |

旧动作的尾幅上限为 0.117、弯身为 0；新动作目标尾幅不超过 0.075、弯身绝对值不超过 0.42。尾幅与弯身使用相同平滑系数，凸组合保持联合约束；任意非有限数、越界或破坏联合约束的状态都会明确报错，不能把渲染状态悄悄裁剪后声称碰撞安全。

证明对每个真实生成的顶点使用正弦函数的连续上界，包含尾部弯曲、胸鳍的轴向/横向位移和模型中心偏移，不依赖有限相位抽样。计算得到最大距离约为 `0.389789303 × TL`，采用 `0.395 × TL`，余量约 `0.005210697 × TL`。胶囊为凸集，GPU 三角面位于其三个变形顶点的凸包中，因此覆盖全部变形顶点也覆盖这些三角面。

该结论仅适用于已锁定的原模型、外形适配和动作实现。构建探针核对这些文件 SHA-256，并拒绝不匹配；修改形体、shader 位移、幅度或插值方式后必须重新建立证据。它证明的是身体形状被包住，不单独证明鱼能通过某条路线。尖吻鲈仍使用已有保守代理，未被提升为本次小丑鱼资产证明；无物种的零长度球形查询代理仍保留其明确半径。

## 3. 平移与旋转扫掠

`clearMotion` 对一次接受的平移/四元数插值使用位移上界：

`D = 起终点距离 + rotationRadiusM × 四元数夹角`

将其分为 N 段，每段内身体任一点的位移不超过 `D/N`。每个区间两端的胶囊半径均增加 `D/(2N)`，另加 1 微米数值余量；因此区间内任一点至少被邻近一端的膨胀包围覆盖。检查包含起始姿态，不能让已相交的鱼通过“终点合法”检查逃出。

分段依据 `max(0.0003 m, radiusM × 0.20)`，单次最多 24 段；预算超出即拒绝该运动，不减少采样冒充通过。最终仍通过真实地形 BVH 的三角形距离/实体内外判断，不以路径图或可视阴影替代碰撞。

新增反例使用 6 cm 小丑鱼：90° 原地转向的两端姿态均与小礁块分离，中间姿态相交；扫掠应拒绝，且确认实际发生 BVH 查询，排除“仅因 24 段预算拒绝”的伪通过。同样转向移开礁块后应允许。边界与扫掠是保守离散执行中的覆盖检查，不是刚体接触、摩擦或水动力模拟。

## 4. 连续路线跟随与有界恢复

前视沿既有 A* 折线前进，距离由体长和实际速度计算并限制在 1.8–16 cm，最多看后面两段。按完整、二分之一、四分之一三个距离尝试，只有完整身体净空走廊通过才选用；不能把礁角对面的可见点直接当作安全捷径。

中间路标可以在靠近或已经过其截面后推进，但当前位置到下一路标必须通过 `clearEdge`，每步最多推进四个。中间前视使用 Yuka `SeekBehavior`，最后端点才使用 `ArriveBehavior`。终点仍按原到达距离产生 `hidden/emerged/searched-exit`，前视点经过不代表业务到达。

转弯限速同时考虑目标夹角、前视距离和当前物种的转速上限；完整浅礁取消原来“超过约 4.6° 就停车”的普遍规则。普通转向允许边走边转，大角度掉头仍可减速调整。路线上的加速/减速分别限为 `3 × cruise` 和 `4 × cruise` 每秒；安全拒绝可立即停止，不能为维持平滑度继续推进已知不安全的动作。

完整浅礁中所有移动（包含没有路线的自由追击）都保持在可转身、可接路的净空域内。实时点查询、缓存净空和通道查询统一采用 `rotationRadius × 1.08 + 0.0002 m`，避免点合法却连接不到任何边的判定缝隙。新游荡路线在本帧取前视目标之前创建；躲藏/搜索等待期间不创建游荡路线，获得可见猎物时撤掉旧游荡路线。

每步至多尝试三档推进幅度（1、1/2、1/4），均验证边界、路线净空和新包围下的扫掠；都不通过时才尝试经过验证的原地旋转。只有接受的位移和朝向写入 World，`fish-motion.mjs` 消费实际速度、转向和加速度，不把被拒绝的目标动作当成已经发生。渲染器不积分第二份位置。

进度按“距当前路标的距离＋后续折线长度”是否有效减少计量；绕路标打圈不算进度。连续 2.5 秒没有有效进度时，对原终点最多重规划两次；次数跨重规划保留。失败后清理路线并冷却，搜索路线还会结束当前追逐。恢复不重置 `hunt.start/seen/lastSeen`，不因路线重试取得隐藏猎物实时位置；失视与总追逐时间上限仍生效。放弃搜索后显式清理本帧旧的 seek 状态，防止读已清空的 hunt。

找不到游荡路线时设置明确冷却，完整浅礁的碰撞拒绝不能逐帧清零重试计时。已增加边界点 0.2 mm 余量一致性、失败游荡限流、新路线首帧、躲藏期间不得插入游荡等反例。造景加载失败保留原场景/可见状态；迟到加载不能覆盖更新的关闭或场景选择。

这里使用的是经检查的前视跟随，不是完整的圆弧曲线求解。狭缝、反向起步、遮挡及无法到达的点仍可发生停车、改路或放弃，须按证据记录。

## 5. 海月水母修形与任务边界

本轮以海月水母属 *Aurelia* 为结构参考，将伞体改为从外伞经柔软伞缘返回凹入伞下腔的连续闭合胶质外壳，修正三角形朝向与法线；不再依靠一条独立发亮圆环表达伞缘。归一化伞半径为 1，外伞顶高约 0.42、伞下中央约 0.245，作为视觉参数记录，不是标本测量。

内部保留四个马蹄形组织与放射管，中央口部连接四条较宽、较短且不等距起褶的口腕；伞缘采用 72 根短触手。72 是几何表达预算，不是物种定数。材质降低镜面强度，金属度与 clearcoat 均为 0，分组织控制透明度，避免口腕被高光和密集螺旋纹表现成硬质钻头。

收缩时伞缘向内、略向下，中央略升，保持伞下凹腔；不再把伞缘抬成扁盘。收缩、较长舒张、间歇三个阶段连续连接，口腕及伞缘触手使用有界滞后。模型 API 继续为 `createMoonJellyModel/update/dispose`，更新时间相同可重现局部顶点，不修改宿主根位置、旋转或尺度，也不创建自己的 RAF。

本轮结构参考来自 [Oregon Coast Aquarium 海月水母资料](https://aquarium.org/animals/moon-jelly/)及其[放大照片](https://aquarium.org/wp-content/uploads/2024/10/Moon-Jelly-compressed.jpg)，并参考[澳大利亚博物馆海月水母资料](https://australian.museum/learn/animals/jellyfish/moon-jelly/)。前轮运动观察依据仍见 [Gemmell 等，2013](https://pmc.ncbi.nlm.nih.gov/articles/PMC3816424/)。没有下载或打包这些参考照片/录像，没有把程序化形态称为某个实测物种的精确重建；脉动参数也不是完成生理标定的结果。

任务仍由原 `JellyfishCore/JellyfishSkin` 拥有位置、抓取、投篮、等待、失败、取消及完成回执。`jelly-3d.mjs` 只投影视觉，局部脉动不反向驱动 Core 的位移，任务显示尺寸不冒称生态米制伞径。沿用原命中区域，未实现随局部形变的逐像素拾取。透明合成保留原 DOM 背景，未实现对 DOM 壁纸的物理折射，也未增加全屏海水背板。

## 6. 本轮完整浅礁矩阵

运行条件：3 个礁区 × 4 个小鱼体长（2.5/4/6/7.4 cm）× 3 个捕食者体长（18/25/45 cm），共 36 组；每组 30 秒，固定步长 1/60 秒，种子 73。它们是工程体型档位，不是年龄标签。

| 指标 | 本轮结果 | 含义 |
|---|---:|---|
| 有捕食资格的组合 | 27/36 | 其余 9 组按原体型/食性规则不捕食 |
| 合格组合出现躲藏 | 27/27 | 每组至少出现一次 hidden 事件 |
| 合格组合出现搜索到达 | 27/27 | 每组至少出现一次 searched-exit 事件 |
| 检出的相交姿态 | 0 | 每个存活鱼姿态通过当前包围与 BVH 检查 |
| 检出的扫掠违规 | 0 | 接受的相邻姿态通过当前连续覆盖检查 |
| 最大单步位移 | 约 5.73 mm | 本次固定步长样本 |
| 有路线且移动中转向 | 合计 457.10 秒 | 跨组合、跨动物累加，不是单次视频时长 |
| 有路线且低速停留 | 合计 138.13 秒 | 速度低于 0.003 m/s；并非全程不停 |
| 路线重试 / 放弃 | 4 / 0 | 安全受阻或无进度后的有界恢复，不能从结果中删去 |

移动中转向的计数条件为有活动路线、速度大于 0.005 m/s 且单步角度变化大于 0.002 rad。低速停留只计活动路线期间，原躲藏/搜索业务等待已清空路线，因此不计入该项；并不将这 138.13 秒都归因于某一种原因。矩阵没有证明动物始终不停、捕食天然成功率或任意新地形正确性。

机器上的本次纯 CPU 矩阵耗时约 33.55 秒，最长单次规划约 78.52 ms；包含测试本身反复执行的检查，不能当作浏览器帧耗时或 GPU 基准。

## 8. 后续落地边界

本轮仅针对固定浅礁硬几何、现有鱼模型和允许动作范围。软珊瑚、海葵尚未逐枝碰撞；地形缩放、旋转、运动或换网格需重新定义/验证导航失效与烘焙合同。尖吻鲈仍是静态 glTF 加尾部变形，保持“行为测试”标识，不冒充典型珊瑚礁捕食群落。

下一步优先用真实动物的同视角参考和动作录像继续校准形态及节奏，区分人眼视觉验收与程序检查。自然共栖组合、幼体/成体形态、多物种独立动作、捕食口部动画、真实推进与水母位移耦合、跨设备 GPU/显存与能耗、正式扩展迁移均须独立验收。当前没有完整 CFD、流固耦合或所有海域的物理正确性保证。

安全自查：本轮范围为隔离 demo 与开发资料，沿用原任务权限、唯一状态和回执边界；不新增认证入口、网络权限、外部模型调用、依赖或真实数据写入。新包围超限和运动预算超限明确拒绝，不静默放宽净空；正式文件隔离与真实 Chrome 结果以最终回填证据为准。
