# 第六轮：自然、治愈与梦幻的轻动漫混合风格

2026-10-23。用户要求继续对照真实海月水母和小丑鱼照片、视频，改善柔软感，同时认为过度还原不够好看，希望微动漫。询问三个方向后，用户明确回复“全都要一点”。本轮将其落实为一个统一的“自然系轻动漫”选项，并保留“自然参考”切换；全部改动仍在隔离 demo。

## 设计建议与取舍

采用“自然约60%＋治愈约30%＋梦幻约10%”的审美配方。这是设计语言，不是生物参数、像素占比或材质混合的测量结果。

- **自然作底**：保留物种轮廓、鳍/口腕/触手结构、实际总长、共享三维空间、遮挡和追逃规则。没有因风格化放大动物的实际体型。
- **治愈作主要修饰**：鱼采用更清楚的暖橙和奶白，减少碎高光，增加克制的眼部亮点；水母内部线条更淡、舒张更从容，伞缘和口腕有先后跟随。
- **梦幻作局部点缀**：集中在水母的淡紫/淡粉、很弱的珠光与柔和填光。没有新增全屏滤镜、光晕背板或背景遮盖。

小丑鱼的圆润感主要来自更平缓的表面明暗，而非继续放大头或眼球网格。水母保留第五轮的凹入伞下腔，避免又退回简单半球。这样两类动物属于同一个画风，也不需要把礁石和整张壁纸都重新改色。

## 实现与复用

继续使用固定 Three.js 0.180.0、Yuka 0.7.8、three-mesh-bvh 0.9.16、Deskworlds固定提交和原构建工具，没有新增依赖。

| `moon-jelly.mjs` | 两套可恢复的材质，以及轻动漫的舒张节奏、局部伞缘滞后和细微不对称形变 |

### 小丑鱼

复用公开 `createFishSchool` 和现有 `applyClownAppearance`。通过 Three `onBeforeCompile` 串接已有材质 hook，仅修改片元颜色、明暗、高光与眼部亮点；保留原 key 并追加固定风格 key。风格强度是同一 shader 的 uniform，切换不会反复叠加 hook。

显示相位沿原相位增量推进，轻动漫使用0.9倍的相位增量，避免切换风格时把鳍的周期清零；尾摆显示幅度为原值的0.94倍，胸鳍幅度和弯身保持原输入。位置、速度、加速度、根姿态与状态仍由原World拥有。

这不会扩大第五轮已证明的身体包围：顶点 shader 没有改变，相位原本就是任意实数范围，尾幅只减少，弯身/划动上限不增加。`clown-analytic-v1` 仍有效；构建继续运行原几何/动作指纹证明，新测试额外确认风格 hook 不改变顶点 shader 或几何数组。

### 海月水母

自然版保持第五轮材质与节奏。轻动漫版将外伞变为淡紫胶质层、内部组织带淡粉，降低放射管与短触手的视觉对比；珠光仅使用 Three 原生 `iridescence=0.08`，外伞弱 `sheen=0.16`，没有新增后处理或大面积光晕。

轻动漫脉动频率为原参考版的0.88倍；一个周期的收缩/舒张/间歇分别占22%/62%/16%，自然版为24%/52%/24%。这些是本项目的艺术参数。伞缘以约0.18秒的滞后参与局部变形，口腕使用约0.24秒延迟，外缘增加很小的角向起伏；不再让整只水母像刚性零件同时伸缩。

模型仍可按同一时间重复求值得到相同顶点，形变保持在原裁剪球内；`update` 不修改宿主的根位置、旋转或尺度。风格切回自然时恢复颜色、透明度和粗糙度。任务成功、失败、取消、等待、拖拽继续由原Core处理，局部脉动不反向驱动任务位移。

## 对照方式

入口仍为 `http://127.0.0.1:18766/`。选择“小丑鱼 · 风格对照”或“海月水母 · 风格对照”，左侧是当前自然参考形体，右侧是所选风格。当前对照不再拿早期半球或旧鱼形来衬托新版；“自然参考”也不代表生物测量真值。

“动物风格”可在自然参考与混合风格之间切换。点击“体验喂食与拖拽”或进入完整浅礁后继续使用所选风格；不切换第二套World，也不清除任务或路线。正式首页及背景配置不消费这个开关。
