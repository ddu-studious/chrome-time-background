# 第九轮：11类动物的完整浅礁

2026-10-23。用户要求继续改善完整浅礁整体表现，复验不同体型小丑鱼的连续转弯、钻缝躲避和大鱼绕行，水母保持柔软淡彩，并把种类增加到10以上。本轮只改隔离demo及资料。当前为**10类鱼＋海月水母，共11类三维动物样板**，不是按配色、体型或版本重复计数。

## 体验方式与完成范围

- 底部“多样浅礁 · 11 类”：加载原完整浅礁，补齐缺失种类和25cm尖吻鲈，开启原追逃测试；保留已有居民、个体尺寸、任务、背景示例及造景范围。初始六条小丑鱼下，共15条鱼和一只待办水母。
- “居民种类”可选择九类小型鱼，再“加入所选”；每次个体尺寸在各自演示区间内独立生成。“近景看所选”明确重置演示居民为单鱼，保留任务，适合逐类查看和交互。
- 正式的2.5/3.2/4/4.8/6/7.4cm小丑鱼、V8连续转向、礁缝躲藏/出口搜索及水母材质/柔软跟随保留。新增八类接入巡游、米制尺寸、地形避障、演示喂食和抓取；本轮精细食物网仍只验证小丑鱼与尖吻鲈，不将未知食谱自动当作捕食关系。
- 自由水域与造景关闭继续撤除礁景颜色、深度及导航；物种选择不写正式设置。所有任务写入仍由原回执决定。

## 复用与实现边界

`community-view.mjs`直接使用Three公开GLTFLoader、SkeletonUtils.clone、AnimationMixer、BufferGeometryUtils.mergeVertices，播放原模型Swimming_Normal骨骼动画；仅随实际游速调整播放速率，不另造骨骼/动作引擎。只对原有顶点做去重与法线重建以柔化低多边形明暗，外形仍是新资源的轻卡通样板，未达到小丑鱼那样的逐项写实校准。材质复用Deskworlds公开underwater适配，水母仍保持V8淡彩。

新增类型不改变World的位置所有权。相机、模型LOD和骨骼播放不改变档案总长；GLB从+Z朝向转换为统一+X，按静止包围盒中心对齐，并按真实总长缩放。材质、骨骼与动画实例各自独立，抓取某条鱼的深度设置不会影响其他实例。

世界拒绝未知类型，新增体型无合法位置时在加入居民集合之前返回失败；仍最多40条鱼、24粒饲料。未知食谱的新增八类不参与原捕食资格关系，不能据同场出现宣称真实自然共栖复原。

## 动画净空与拾取

小丑鱼原解析胶囊体及联合弯身/尾幅限制保留。两种Deskworlds新增鱼遍历FULL/FAR每个顶点，以已有shader的最大弯曲、鳍划动及金花鲈鳍延伸形成保守球界。

六种GLB只允许本地嵌入buffer、无外部图片/URI、无所需扩展、无形变目标，限制文件/节点/顶点预算；仅接受Normal游泳clip中的旋转轨道。以骨骼链长度、最大缩放和非负蒙皮权重的三角不等式计算**任意骨骼旋转下的保守球界**，不把离散帧采样冒充连续证明。证书在 `certificates.json`，构建同时核对原文件与生成代码指纹。

当前GLB球界半径约1.455–1.631倍TL，显著宽于可见鱼身；这是本轮的安全取舍。新鱼可能绕开实际能通过的窄处，后续需按已选clip的关节角范围收紧证明。小丑鱼的窄缝能力仍使用原紧包围。GLB抓取使用真实SkinnedMesh三角形拾取，避免把宽碰撞球当成巨大点击区；拾取仍受礁石视线遮挡约束。

原地形未改变；包围入口新增分支后重新烘焙导航证据指纹，并保留原Yuka/BVH查路、旋转扫掠、失败恢复和预算。

## 混合场景与资源

已有六条不同尺寸小丑鱼保持同场，补齐八类新鱼和一条大鱼。新增图缓存通过原graphFor接口分步准备，再放入新居民，避免把所有图建立集中在第一动画帧；缓存仍最多12个体型图。只保留最多六个已验证模型模板。

原生鱼几何按实际对象/类型/大小/抓取状态判断是否需要重建，加入或抓取骨骼鱼时不再无条件重建全部小丑鱼。页面验证发现并修复骨骼纹理释放遗漏：移除实例会stopAllAction、uncacheRoot，释放该实例的独立材质和所有独立Skeleton纹理；模板几何由场景最终销毁负责，不误删其他实例共享的几何。

初步浏览器观察中，混合场景仍出现过规划峰值和帧间隔波动；分步预热不等于性能已达标。长时P95、GPU和功耗仍待目标设备专项测量。
