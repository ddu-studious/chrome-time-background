# 第八轮：连续转弯与柔软游动

后续第九轮已扩展至11类，见[V9](implementation-v9.md)。本文保留V8当时3类样板和验收结果。

2026-10-23。用户要求重点优化小丑鱼连续转弯、水母柔软游动，保持小鱼清爽自然、水母淡彩梦幻；只改隔离demo，保留造景、喂食、拖拽、任务能力，并同步资料。用户同时询问已制作数量，已核对为[3类真三维动物、2个原型入口](animal-demo-inventory.md)，其中专项打磨2类；本轮没有新增动物类型。

## 追踪到的问题与方案

原World把目标朝向按最高4rad/s立即转动，方向反转或路标切换时，角速度可以突变。原 `advanceFishMotion` 的弯身虽然有平滑，但根朝向仍会像机械转轴。水母已有局部延迟，不过大部分伞缘共用同一延迟，口腕采用统一收缩相位；脉动阶段的加速度和组织长度方向跟随仍可改善。

继续使用固定 Three.js 0.180.0 的 Quaternion/Vector3、Yuka 0.7.8 的既有转向和 A*、three-mesh-bvh 0.9.16、Deskworlds固定公开工厂，以及本仓库 Jellyfish/TaskCrumple。自有薄适配只增加有界朝向提案和局部组织变形；没有增加另一份位置引擎、物理库或任务事实库，也没有新增依赖/远程资源。

## 小丑鱼：朝向提案 → 原扫掠 → 接受后提交

`turning.mjs` 使用 Three 公开四元数 API 将目标差变为最短旋转轴。角速度向量逐步趋近目标，最高4rad/s，开阔条件下每秒变化不超过18rad/s²，响应系数24/s。航路绝对朝向采用6/s的误差反馈，普通游动使用Yuka本步已积分速度的角增量除以dt，避免将一次很小的转向增量再做一次低通而失去转向能力。

World仍是唯一位置所有者：先产生朝向，再用原身体代理和 `clearMotion` 检查平移/旋转扫掠；只对接受的姿态提交角速度。前进受阻可尝试原三档步长及原地转身，旋转本身受阻时清角速度；抓取也清角速度。无完整航路时，小丑鱼在水域边界受阻后最多每1.2s重选一个回转目标，给连续转向留出完成时间；此前每帧重随机目标会互相干扰。捕食者边界逻辑保持原样；场景重配清除该短时恢复状态。此类安全停止允许直接停车，不宣称硬碰撞时也遵守自由转向的舒适度上限。

弯身、尾鳍和胸鳍继续由 `advanceFishMotion` 消费实际接受的转动和速度；鱼几何、顶点shader、体型、尾幅/弯身联合约束均未扩大。`clown-analytic-v1`及其连续顶点包围仍由构建核验；地形、包围、导航和烘焙资料未改，不需重新烘焙同一净空图。

对照场景采用同一朝向适配和实际角速度驱动弯身，两侧共享根姿态，只比较原有自然/轻动漫样式。操作：观察方式“小丑鱼·风格对照”→“连续左右转弯”→侧面/3⁄4/正面。自然版切换恢复材质和视觉节奏，不撤销本轮共同的导航/转向修正。

## 水母：平滑脉动、渐进相位与宿主拖曳

自然参考保留原三阶段节奏；轻动漫沿用0.88倍率、22%/62%/16%的收缩/舒张/间歇比例，改用五次平滑函数，使阶段端点的速度、加速度均连续到0。这些仍是艺术参数，未做新的生物频率测量。

- 伞缘延迟从伞心到外缘渐进增加，外缘约0.24s，并叠加最多约0.025s的周向差异，形成软波沿伞体传播的观感。
- 口腕脉动跟随由根部约0.12s延迟渐进至末端约0.44s，附加克制、错开的褶皱摆动；保持根部连接处稳定。
- 任务适配只读原Core的vx/vy，以伞径归一化并限幅，转换到模型局部坐标。口腕末端最大局部拖曳为水平0.085、纵向0.060个伞半径；边缘短触手更小。只改变组织顶点，不反向改Core位置/速度/拾取/任务状态。
- 固定时间、相位、活动量和局部流输入可重复求值得到同一顶点；切换材质、等待回执和拖动前景深度仍由原路径处理。

几何仍是7个mesh、19,348顶点；没有增加网格或后处理。预计算每顶点固定半径权重、角度和沿臂参数，帧内脉动采样返回数字而不为每个顶点创建对象；仍复用原宿主调度和暂停，不增加RAF或后台计时器。该优化没有GPU/功耗达标结论。

## 验证与取舍

[本轮验收记录](../../../output/aquarium-review-20261023/reef-3d-v8/RESULTS.md)包含91项原型、423项原交互回归、36组完整浅礁矩阵及浏览器证据。

同一7.4cm个体、同一开阔S路线、1/60s固定步长，对照冻结且SHA核验的V7 World：最大角加速度约192.31→13.29rad/s²，走完路线约9.03→9.83s。新转弯更平缓，也稍慢；不是生物学测量或全场景性能指标。36组矩阵均无相交姿态和扫掠违规，27个合格组合均有躲藏及出口搜索；仍可安全减速/短停，不能承诺所有转弯不停车。

自由追逃初版回归中，种子73在120s内未捕获，首次失败日志保留。继续核查发现水域边缘每帧重选巡游目标会干扰有惯性的回转；增加小丑鱼回转目标的1.2s有界保持后，原先每个固定种子都需出现自然捕获和放弃的断言恢复通过，最终没有放宽该断言。另增加三种体型的实际近距离追击→口部接触→暂时离场用例。未改吞食资格、捕获半径、超时、追击预算或随机种子；前后统计单独存档。

## 正式接入边界

正式首页、背景、原任务数据与原喂食组件不改。水母仍是前景任务视觉，不是统一米制生态居民；不存在流体动力学、真实折射或幼体/成长标定。本轮角向惯性只用于隔离小丑鱼，尖吻鲈仍沿原朝向规则。下一步先做用户观感验收，再测目标设备长时帧间隔/GPU/功耗及资源释放；正式集成仍需原迁移清单中的绘制接口与宿主生命周期验收。

安全自查：只有隔离demo、开发探针和资料；固定本地模块、有限时间步/角速度与原扫掠、textContent及原任务回执，无新增权限、依赖、外部运行请求或真实数据写入。V7对照探针只在Node中读取本轮冻结且SHA核验的仓库源文件，不进入浏览器bundle或HTTP白名单。
