## 模块边界

`habitat.mjs`：可见礁缝网格与语义入口/掩体候选，采用上游公开 ellipsoid 工厂。`navigation.mjs`：有限节点图、体型净空和 Yuka A* 适配，无自写最短路。`world.mjs`：生态状态唯一所有者，记录感知/路线/躲藏/搜索/捕获事件。`spatial.mjs`：复用 BVH 查询，不执行行为。

`jelly-3d.mjs`：Three 几何与材质，消费原控制器传来的只读世界。`jelly-render-adapter.mjs`：对本仓库原控制器增加构建期 drawFrame 注入；严格匹配单个调用位置，源形状变化则构建失败。生产源码原样保留。正式落地应将此注入变成公开参数，而不是保留构建替换。

路径为当前礁缝栖息地的有限水平航路，节点存三维坐标。姿态安全仍由连续多次 BVH 检查；不宣称任意复杂海域的全局三维导航。任务水母是交互对象，尺寸按可读/可抓取投影，不冒充科学物种尺度，也不进入食物网。

## 验收门槛

同一窄缝小鱼可走、大鱼路线绕侧面；全程真实步进无穿石/瞬移；失视只追最后记忆和有限候选，不读隐藏猎物的实时位置追踪；躲藏有停留/警戒时间；取消/关造景清路线。任务只有原完成回执 ok 才完成，失败/取消不完成；无双重 2D/3D 绘制。正式首页资源与权限不变。
