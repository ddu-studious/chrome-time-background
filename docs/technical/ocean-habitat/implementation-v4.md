# 第四轮：小丑鱼与海月水母的外形、动作对照样板

后续状态：第五轮已在新包围证明下把新版鱼体态接回完整浅礁，并修正水母伞缘，见[当前 V5](implementation-v5.md)。本文件保留第四轮当时的范围和验收。

2026-10-22 用户授权按[写实化方案](animal-realism-plan-20261022.md)实施：先做一条小丑鱼和一只海月水母，外形与动作一起改善；只改隔离 demo，保留背景、造景开关、喂食、拖拽和任务能力，资料与验收同步记录。

本轮实现了**新旧单体对照和开阔水域交互样板**。它是参考驱动的视觉原型，尚未完成真实标本形态标定、录像动作测量或连续弧线绕礁。P3 连续绕礁与 P5 自然群落没有在本轮实施，不能把 V3 的导航验收转称为新版弯身通过礁缝。

## 体验入口与对照约定

入口仍为隔离页 `http://127.0.0.1:18766/`，默认进入“小丑鱼 · 新旧对照”；可切换“海月水母 · 新旧对照”、侧面/正面/俯视，以及小丑鱼的悬停、巡游、左右转弯、滑行、加速或完整循环。界面提供重新开始、暂停与真实动物参考入口。

左右两列是**同一个体的新旧表现**，不是两条不同年龄或不同大小的鱼。小丑鱼两侧都使用 7.4 cm 总长、相同根朝向与同一动作提示时间；形体变化和身体动画是本次对照变量。比较相机为 Three `OrthographicCamera`，避免横向位置造成透视角度与大小差别；自然游动仍使用原透视相机。近景放大用于观察，不把屏幕放大后的像素尺寸作为物理尺度。

两侧水母使用相同的归一化伞径与观察方向，对比原半球/长管样板和新的海月水母属形态。旧版仍按原方式脉动，新版按三阶段脉动；两者不是完成物种与生理参数标定后的实验动物。窄屏改为上下排布，使用同一个相机和场景灯光；现有水下光照仍随世界位置变化，因此不将截图当作严格同照度的材质测量。

“体验喂食与拖拽”进入自然游动，清理本页演示居民并加入一条 7.4 cm 小丑鱼，关闭捕食测试与固定礁景。演示存储包含一条“观察海月水母”任务；任务模型展示、抓取和放入纸篓仍由原控制器处理。本页数据只在内存中，刷新可重置，不访问正式居民或任务存储。

## 小丑鱼外形：复用上游并保留可逆对照

继续使用 Deskworlds 固定提交 `335d6c1aeb59b338b1cc59d734dc6eb87a596a88` 的公开 `createFishSchool` 和原程序化网格、材质、实例动画。没有修改 vendored 上游、复制隐藏材质工厂或下载另一套鱼资产。

`clown-appearance.mjs` 对工厂生成的 Three 标准对象做本地适配：读取公开 `BufferGeometry` 的 position/normal/uv/part 属性，平滑增加头胸部体厚、将眼部局部尺度乘 1.12、缩短腹鳍自由缘 16%；X 方向头尾极值保持不变。重算法线并合并同部件的重合接缝，保留鳍与鱼身的部件边界。FULL 静态网格长度保持 1.25 个上游单位，宽度约从 0.280758 改为 0.317802，含腹鳍高度约从 0.726103 改为 0.663616。

这些增量是本轮的**视觉假设**，不是来自标本的精确比例；眼部调整不表示变成幼鱼。物种身份沿用上游的 *Amphiprion percula*，参考澳大利亚博物馆的识别、照片与栖境信息，但尚未完成对应视角、镜头和测量口径的标定。[物种参考](https://australian.museum/learn/animals/fishes/eastern-clown-anemonefish-amphiprion-percula/)

材质通过 Three 的公开 `onBeforeCompile` 接口衔接原 hook，在原条纹、鳞片、鳍条、水下光照之后调节表面粗糙度、反射和配对鳍膜透明度；不覆盖上游运动 shader。保留并扩展原 `customProgramCacheKey`，对上游匹配点变化显式报错。调用 `applyClownAppearance(group,{variant:'legacy'})` 可恢复原位置、法线和 shader hook；不替换实例属性对象，避免上游每帧写入旧 buffer 而使动画失效。

## 小丑鱼动作：世界运动与身体表现分开

`fish-motion.mjs` 接收已接受的速度/体长、加速度、带符号的转向强度和行为状态，平滑输出 `phase / pectoral / tailAmplitude / rowing / bend`。真实位置、速度、根姿态仍由 `OceanWorld` 唯一积分。新模块不调用第二套 World 更新，也不移动渲染对象的根节点。

悬停使用较弱尾摆和持续胸鳍动作；滑行减小尾幅与划动；巡游、加速和左右转弯使用不同目标幅度，弯身随转向符号变化并限幅。相位连续累计、幅度指数平滑，不在状态切换时把相位清零。当前频率、幅度、平滑速度和转弯映射均为有界的演示参数；不能据此称为已复现小丑鱼的完整推进方式或生物学 C-start。

对照页的 `specimenCue` 提供 24 秒确定性动作循环；新旧两列共享根方向提示，新列使用新动作适配，旧列复现原速度驱动的摆动与 `bend=0`。对照时只推进样板时间，不推进隐藏的生态 World。自然游动则使用真实 World 接受的运动结果驱动身体表现。固定步长仍为 1/60 秒，一次宿主帧最多推进 4 步，不新增 RAF。

## 礁景边界：本轮明确保留旧体态

新的静态体厚与动态弯身尚未纳入原导航胶囊和运动包络。因此新版小丑鱼只在无障碍对照及关闭礁景的自然游动中启用。

开启固定礁景时，视图撤回新外形并将弯身归零；World 的新动作分支还要求 `spatial.active === false`，有活动礁石碰撞时继续采用旧尾幅/划动规则。新旧外形通过重建工厂生成的实例组切换；造景开关仍同时控制颜色、深度和空间查询。静态转身、尺度与遮挡观察不携带自然游动时遗留的弯身。

完整浅礁的 A*、体型图、原地转向净空检查、躲藏与失视搜索保持 V3 路线。下一轮只有先证明新外形及所有允许动画姿态被保守包络覆盖，更新路线筛选并通过窄缝反例，才允许把新体态放回礁区；然后再实施提前减速与连续弧线绕行。不能只删除停车阈值，也不能通过视觉平滑掩盖穿礁。

## 海月水母：结构、局部变形与任务所有权

`moon-jelly.mjs` 新增参考海月水母属 *Aurelia* 的薄伞样板：浅的外伞与伞下层、四个马蹄形内部组织、放射管、柔软伞缘、四条短褶皱口腕，以及密集的短伞缘触手。伞半径归一化为 1，伞顶高度约 0.34；72 根短触手是几何预算和外观表达的选择，不是某个实测个体的计数。[海月水母参考](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/moon-jelly)

几何通过 Three `BufferGeometry / MeshPhysicalMaterial` 与上游公开 `tube / merge` 组合，合并为 7 个 mesh。材质使用低金属度、较弱清漆与分组织透明度，没有增加发光器官或全屏海水背板。透明合成继续展示 DOM 背景；没有实现对 DOM 壁纸的物理折射。

脉动分为收缩、较长舒张、间歇三个连续阶段：改变伞缘局部形状，而非将整个半球统一缩放；口腕与短触手具有有界滞后和轻微摆动。CPU 在已有绘制节奏内更新顶点和法线，使用固定保守裁剪球；更新时间相同可重放相同顶点，更新不夺取宿主 position/rotation/scale。阶段比例和频率仍是视觉参数，相关研究只支持分阶段观察思路，未执行涡环或流固耦合求解。[运动研究参考](https://pmc.ncbi.nlm.nih.gov/articles/PMC3816424/)

任务水母仍由原 `JellyfishCore` 和 `JellyfishSkin` 拥有屏幕位置、抓取、投篮、等待、取消和完成回执。`jelly-3d.mjs` 把该位置映射到前景平面，仅替换视觉；钟罩脉动尚未反向驱动 Core 的实际位移。任务前景显示尺寸不冒称生态米制伞径。

**沿用原命中区域，新伞形与命中区域非逐像素一致。** 原 Core 的命中椭圆相对于新版较浅的伞覆盖了更大的可抓取区域；本轮没有新增或扩大命中代码，没有做精确变形拾取，口腕与触手下部仍不作为抓取目标。失败/超时不会因为视觉动作完成就改成任务成功。

## 模块、版本与资源生命周期

主要文件均位于 `test/demos/reef-3d-lab-20261021/`：

| 文件 | 职责 |
|---|---|
| `clown-appearance.mjs` | 可逆鱼形与材质薄适配、静态包围范围记录 |
| `fish-motion.mjs` | 身体动作参数、确定性对照提示与样板时间 |
| `specimen-view.mjs` | 同个体新旧并排/上下对照与资源释放 |
| `moon-jelly.mjs` | 海月水母几何、三阶段局部变形与透明组织材质 |
| `world.mjs` | 从已接受的世界运动调用身体动画，礁景门控 |
| `view.mjs` | 正交比较相机、旧透视相机、外形切换和唯一渲染器 |
| `jelly-3d.mjs` | 复用原任务控制器并投影海月水母视觉，绘制节流 |
| `jelly-render-adapter.mjs` | 隔离构建时为本仓库控制器加入 drawFrame 注入；匹配不唯一即失败 |
| `controller.mjs`、`bootstrap.mjs` | 观察/交互入口、固定步长、单鱼与单条内存演示任务、暂停与页面生命周期 |
| `index.html`、`app.css` | 对照标签、动作选择、角度选择、保留造景与原交互入口 |
| `build.mjs`、`build-info.json`、`ocean.bundle.mjs` | 固定构建工具及新模块指纹，最终产物由构建生成 |
| `test/clown-appearance.test.mjs`、`test/fish-motion.test.mjs`、`test/moon-jelly.test.mjs` | 外形恢复、运动与物理状态隔离、连续性、形变范围和释放检查 |

继续使用 Three `0.180.0`、Yuka `0.7.8`、three-mesh-bvh `0.9.16`、esbuild `0.28.1` 及既有锁文件。没有新增运行依赖、外部模型调用、远程脚本、WASM、下载素材或生图资产。本轮仍未取得前轮 Sketchfab 候选模型，因此没有把那些候选写成已集成资产。

所有绘制沿用宿主调度与暂停机制；任务模型绘制节流至约 32 ms，比较模式关闭生态任务显示，切回自然模式再恢复。模式切换取消正在进行的抓取，页面隐藏遵守宿主暂停；页面关闭清理计时器，释放比较样板与视图，再停止任务水母。鱼组按集合释放共享几何和材质；海月水母 dispose 幂等，迟到 update 不重新激活。真正后台深度释放、恢复和设备能耗是否达标仍以本轮浏览器证据为准。

## 验收记录与下一步

本轮新增检查重点：外形的 X 总长不变、静态范围和法线有限、legacy 精确恢复且不同实例组互不影响；新动作不改变相同输入下的 World 轨迹与交互事件；对照循环姿态与相位连续；活动礁景仍走旧动作；海月水母形变范围、局部伞缘变化、相位连续、宿主根变换不变和资源只释放一次。

本轮 **49/49 项原型检查、368/368 项任务与宿主相关回归通过**。Chrome 已验证对照角度和动作、暂停、投喂后进食、鱼抓取放回、任务失败保留/成功完成，以及造景切换的旧体态门控。最终 bundle 为 959,296 字节，源码与产物指纹一致；9 个正式关键文件修改前后 SHA-256 一致。

完整结果、截图、最终构建指纹和未验收边界见[单体样板验收记录](../../../output/aquarium-review-20261022/animal-samples/RESULTS.md)。短样本不构成稳定帧率或能耗验收；36 组矩阵未重跑，新弯身尚未进入礁区。

后续首先补真实参考的同视角形态对照与动作录像测量，记录参考个体、尺寸口径、镜头/环境和允许误差；再决定继续细化当前网格还是接入具备授权、绑定与原地动作的资产。新增幼体/成体形态需要独立证据，不能按大小直接命名年龄。复杂捕食口部动画、自然共栖组合、多物种独立动作、透明排序极端情况、跨设备性能及正式首页接入继续保持未验收状态。
