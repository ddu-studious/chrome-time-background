# 背景重复可玩性 v4 — 回声花园

## 调研输入

### Chrome Music Lab

- https://musiclab.chromeexperiments.com/
- 无需账号，打开实验即可开始；支持手机、平板和电脑。
- Song Maker、Rhythm、Kandinsky 等实验把“输入、声音、视觉、回放”压缩在同一条短链路里。
- 启发：不做配置前置；第一次拖动就能获得完整反馈，保存和声音均为可选增强。

### Blob Opera

- https://artsandculture.google.com/experiment/blob-opera/AAHWrq360NcGbw
- 拖动同一个角色即可连续控制音高与音色，复杂技术被藏在直接操控之后。
- 启发：一条轨迹同时决定位置、颜色、轨迹宽度和音高，不建立四套割裂的控制器。

### v3 实玩反馈

- 物理手势的即时反馈成立，但手势消散后不形成长期作品。
- “发现五种手势”适合首次探索，不足以支撑重复进入。
- 启发：v4 从发现能力转向创作能力，用户每次录制都会增加一个可循环的世界层。

## v4 核心循环

1. 点击录制，拖动 1–6 秒生成一条真实轨迹。
2. 松手后轨迹自动成为循环回声，光点沿路径重复运行。
3. 最多叠加三条不同颜色、不同音高的循环。
4. 两条轨迹靠近时产生和声涟漪；三层完成时触发一次“花园绽放”。
5. 用户可以调节速度、静音、撤销和清空；不需要账号，也不会上传轨迹。

## 正式接入边界

- 默认不录制，必须点击“开始录制”。
- 声音默认关闭，只在用户开启后创建 Web Audio 上下文。
- 轨迹仅保存在当前页面内；正式版本若持久化，需要单独设置开关。
- 最多三层、每层最多 160 个采样点，防止无界增长。
- 页面隐藏时停止绘制与声音。
- `prefers-reduced-motion` 下减少光点数量并降低帧率。
