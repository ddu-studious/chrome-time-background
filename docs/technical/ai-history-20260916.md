# 本机 AI 对话与调用历史

## 工具执行轨迹补充（2026-09-16）

快捷助手现在按实际执行留存规划、工具、候选操作、内部服务和外部请求。音乐、提醒、视频等登记工具共用执行器追踪；一个工具内部的网易云/B站/YouTube请求、本地资料读写、播放器操作也记录为子步骤。音乐播放进一步记录可播放资源准备、提交播放、播放器实际确认、队列保存。记录的是程序执行轨迹，不是模型的内部思考。

- 独立的 `tools[]` 存储工具记录：调用ID、会话/轮次ID、父调用ID、工具名称与标题、类型、开始/结束时间、耗时、状态。正文开启时再保存有界参数、返回结果和错误摘要。
- 工具首尾记录通过同一ID合并；并发调用各自有ID。模型调用新增 `toolCallId`，可以定位哪个步骤请求了模型。界面提供步骤编号及父步骤名称。
- 取消立即结束未完成工具，迟到成功不能覆盖取消；服务或浏览器后台重启的未完成步骤标记中断，不能将未确认操作报告为成功。
- 搜索失败后的备用接口尝试独立留存；接口业务错误保留失败状态，但不会改变原有业务回退行为。
- 旧文件没有 `tools` 字段时按空数组兼容。删除会话/清空历史同时覆盖工具记录，并阻止迟到结束重新创建已删除记录。
- 工具记录最多4,000条，与消息、模型调用共享12 MiB容量限制和留存期限。参数与结果遵循正文开关；长文本/长数组明确标注截断，不保存凭证、原始音频、播放链接或运行上下文对象。
- JSON与Markdown导出包含工具记录；页面支持按状态、工具名称、已保存参数/结果检索。统计分别展示工具动作、内部操作/请求、规划和模型次数，“未再次调用模型的回复”不再混称工具或规则执行次数。

范围：本次追踪覆盖快捷助手执行链。独立音乐/闹钟面板仍沿用已有会话消息与AI场景记录，不据此宣称扩展所有网络/播放行为都有工具轨迹。服务离线、留存清理或旧版本未记录的步骤无法补回；不提供无限期、无截断或凭证原文的归档。

验证：完整JS/MJS回归727/727；最后补充实际播放器确认与记录断言后，相关定向回归41/41。隔离页面已验证工具/失败回退展示、参数与结果展开、步骤父子关系，480px视口的scrollWidth为480。真实本机服务更新后历史接口返回200及tools数组，原有会话仍在，用户当前正文开启、保留7天的设置未修改。真实扩展需重新加载后产生新工具轨迹，本轮未操作用户播放器验证。

## 留存与使用

- `local-ai/.local/history.json`：原子替换写入，目录权限 700、文件权限 600。独立于原有 `control.json` 和每日请求预算 `usage.json`。
- 默认仅保存元数据，默认保留 30 天；正文开关由用户在控制台启用。可选 7、30、90、365 天，缩短期限在保存时立即清理。
- 上限为 2,000 条调用、4,000 条会话事件、12 MiB UTF-8 文件。读写历史时清理到期/最旧记录；服务停止时不执行清理。
- 正文包含用户消息、界面回复、经过场景校验的输入/输出。正文有长度上限并标记截断；不收集系统提示词、内部推理文本、原始音频、凭证字段。用户手动输入的敏感信息仍可能出现在正文中。
- 关闭正文留存只影响后续记录，不删除已有内容。未开启时的历史不能事后补回。历史仅用于回看，不作为模型上下文自动注入。
- 支持日期、场景、模型、状态、正文关键词筛选；JSON/Markdown 导出筛选结果；删除一条会话/独立调用、清空全部历史（界面二次确认，不可恢复）。删除不会减少原有当日请求预算计数。

## 数据关联与统计口径

- 快捷助手：连续追问共享 conversationId；每次提交仍保留独立任务 ID 和 turnId。记录用户输入、候选选择和实际界面回复。后台规划/解析通过 trace 关联会话，避免重复计数。
- 音乐与闹钟：复用现有 AssistantSession ID，记录输入、追问、选择、实际回复和完成/结束状态；本地规则回复也可留存。
- 其他 AI 场景：记录独立调用及其有界输入/结果，不把自动向量化/摘要视作用户发送消息。
- 模型调用记录保存当次 model、reasoning、policyRevision、输出上限、耗时、结果状态和错误码，当前设置变化不会重写旧记录。
- 仅保存提供者实际返回的 token 用量；没有返回时展示“服务未返回 token 用量”。不会推算费用或虚构推理 token。
- 页面按会话最近活动时间筛选，展示/导出匹配会话的所有留存事件和调用；统计为保留范围内的记录，并非终身累计。模型受理包括最终失败/取消，向量调用也计入；语音单独计数。

## 故障与边界

- GET/POST `/v1/history` 复用本机入口鉴权及 Host/Origin 限制；POST 支持 configure、event、delete、clear，不接受任意文件路径。
- 配置更新使用独立 revision 防止多页覆盖。事件 ID 去重，删除标记和清空代次阻止迟到结果恢复已删除历史。
- 服务重启后未完成调用标记 interrupted。写入失败不阻止业务操作，控制台/会话提示留存异常。
- 本机服务未连接或未配置令牌时，离线业务可继续，但无法保证记录留存；当前没有跨离线状态的正文补传队列。
- 新功能开始前没有保存的正文无法恢复。服务返回解析成功不代表媒体播放或闹钟保存成功，应结合会话实际回复查看。
