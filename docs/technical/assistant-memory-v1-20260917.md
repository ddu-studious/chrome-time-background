# 快捷助手个人记忆 v1

实现日期：2026-09-17。基于轻量本地方案，使用 Node 内置 SQLite，不引入 npm 运行依赖、向量服务或额外模型。

## 用户行为

- `张杰的热门歌曲`：默认为播放目标；真实结果中唯一精确匹配时直接取热门歌曲并播放，同名时等待选择。此前主动确认的歌手 ID 可帮助消歧，但必须出现在本轮真实结果里。
- `搜索张杰的热门歌曲`、`只搜索张杰的热门歌曲`、`播放张杰的热门歌曲，先别播放`：只展示。
- `播放张杰的热门歌曲，保留原队列`：本次要求优先于长期队列偏好。
- 自然语言播放热门歌曲默认追加并立即播放；可在记忆页面设为替换。已有搜索结果的 `+` 按钮仍保留其“替换整组并播放”的显式语义。
- `记住：以后歌手热门歌曲先展示，不自动播放`、`记住：以后歌手热门歌曲直接播放`、`记住：热门歌曲保留原队列`、`记住：热门歌曲替换队列`：保存对应的明确偏好。
- `查看我的记忆`：查看音乐偏好与记住的歌手数量。
- 助手页底部的“我的记忆”提供修改、删除、暂停使用、暂停记住歌手、导出与清空。

省略动词默认播放属于产品默认规则，不冒充从用户历史中提取的记忆。页面会区分“默认规则”与“已保存偏好”。自动精确匹配不记成用户主动选择，避免系统反复强化自己的猜测。

## 数据与生命周期

启动正式本机服务后，数据保存在 `local-ai/.local/memory.db`。该目录已被 Git 忽略，文件权限为 0600。SQLite 使用参数绑定、事务和全局 revision 乐观锁；不同页面的旧版本写入不会静默覆盖。

- `memory_meta`：revision、是否使用记忆、是否记录主动选择、清空时间。
- `memory_entries`：明确偏好和歌手实体，附来源、来源会话 ID、更新时间。最多保留 200 个歌手映射。
- `memory_deleted_sources`：删除会话的墓碑，阻止迟到任务重新写回。

偏好为固定枚举：`artistDefaultAction=play|browse`、`artistQueueMode=append|replace`。不存任意可执行指令。歌手映射为归一化查询、平台真实 ID 和真实名称，当前仅网易云。

记忆设置和对话正文留存独立。删除会话会清理关联记忆；清空历史会清理来自会话的记忆。在记忆页面直接设置的偏好没有来源会话，不随对话删除。清空记忆保留使用开关，但恢复默认偏好。导出为 JSON，本版没有导入按钮。

服务未连接或读取记忆失败时，普通点歌按默认规则继续，并显示说明。明确要求保存而写入失败时不会回复“已记住”。SQLite 无法打开时 `/v1/memory` 返回 503，其他 AI 路由仍能启动；删除历史涉及关联记忆时会报告失败，不谎报完整清理成功。

## 接入位置

- `js/assistant-memory.js`：固定偏好合同、明确记忆语句解析、歌手身份匹配。
- `local-ai/memory-store.mjs`：SQLite 持久化与版本校验。
- `local-ai/server.mjs`：受现有令牌和来源校验保护的 `GET/POST /v1/memory`，以及历史删除联动。
- `js/local-ai-client.js`：扩展后台桥接；页面不会收到连接令牌。
- `js/music-intent.js`：保留歌手目标 `goal`、热门集合 `collection` 和本次 `queueMode`。
- `js/assistant-contract.js`：自然语言意图优先于搜索动作前缀；注册受限 `memory.manage`。
- `js/assistant-tools.js`：规则执行读取偏好；模型规划只接收白名单枚举；真实曲目、最新播放器 revision 和成功回执仍由现有执行器验证。
- `js/assistant-engine.js`：保留会话起始时间、记忆使用提示和指代续播；不让旧的唯一候选快捷逻辑绕过歌手身份判断。
- `assistant-memory.html`、对应 CSS/JS：记忆管理页。

普通任务不增加记忆抽取的模型调用。本版没有行为推测、向量召回、自动总结、通用事件知识库、跨设备同步或音频播放撤销；这些属于后续阶段，不在页面宣称已具备。

## 启用与验证

需要 Node.js 22.13 或更高版本。本轮测试使用 Node.js 25.9.0。更新本地 AI 服务后重新加载 Chrome 扩展；使用已有守护服务的环境可运行 `./local-ai/service.sh restart`。无需安装 npm 依赖，也不会自动导入旧聊天记录。

自动化回归：`node --test test/*.test.js test/*.test.mjs`，本轮 776/776 通过，其中新增 21 项记忆测试。覆盖 SQLite 跨重启、CAS、删除墓碑、服务故障、损坏库降级、中文短词、播放限制、身份消歧、模型上下文、当次例外和来源清理。

浏览器验证使用隔离数据：

- `node local-ai/memory-preview.mjs`：管理页面连接真实 HTTP 服务和内存 SQLite 测试库。
- `ASSISTANT_PREVIEW_PORT=18767 node local-ai/assistant-preview.mjs`：真实助手 UI/执行器，模型和媒体接口为测试数据。
- 管理页已检查偏好保存和刷新恢复、删除恢复默认、暂停持久化、JSON 导出、歌手删除及 390px 宽度布局。
- 助手页已通过真实输入控件提交“张杰的热门歌曲”，取得热门曲目播放完成回执；提交“播放张杰的热门歌曲，先别播放”时展示歌手候选。媒体操作使用隔离模拟，没有发出实际声音。
- 截图保存在 `output/playwright/assistant-memory-desktop.png` 和 `output/playwright/assistant-memory-mobile.png`。

这些验证不等同网易云真实账号、安装版扩展或扬声器实际播放验收。本轮没有重启用户正式服务或重载日常浏览器扩展。
