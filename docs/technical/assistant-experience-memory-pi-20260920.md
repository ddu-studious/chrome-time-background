# AI 工作台经历记忆与明确偏好

实现日期：2026-09-20。延续个人记忆 v1，保留当前任务状态、历史留存与跨任务记忆各自的生命周期，不建立第二个活动任务事实库。

## 用户行为与触发时机

- 搜索出结果（包括等待用户选择）、手动选择、自动匹配并实际播放，以及有成功回执的提醒创建/修改/删除，可形成经历。原站视频打开仅记录“打开页面”，不记录观看完成。
- 写入发生在已匹配的历史工具 start/end 回执落盘后，不必等待整项复合任务结束；已完成的子操作不会因后续步骤失败而消失。失败、取消、中断、unknown、待确认及仅有模型计划均不算成功经历。
- 经历要求历史正文留存开启、个人记忆启用、经历采集启用，且该调用开始和完成时允许留存正文。默认历史仍不留正文，不隐式改变该设置。新增经历开关默认开启，但受前述正文开关约束。
- 已有历史不会在启动时全部导入。用户可在“我的记忆”点击“补充已留存历史”；缺正文、已过期、已删除的记录不能补回。
- “上次搜索了谁”“查看我的经历”“昨天搜索了哪些歌手”通过只读 `memory.recall` 返回时间、名称与历史回执。不是当前状态；回忆不会触发播放。
- “继续播放上次找到的歌手”等后续任务可携带相关记忆进入现有规划器，必须重新搜索并取得本轮引用，不能拿历史 ID/ref/revision 直接写入。
- `记住：我喜欢爵士乐` 等明确请求保存原文偏好；原有两项音乐偏好枚举保持兼容。未指定应用时按明确主题归入音乐、提醒或视频，无法判断时为通用。普通搜索不推断喜好。
- 自由文本偏好供模型规划时参考，不是可执行脚本，也不是所有规则快捷路径的全局设置。直接执行的固定快捷命令仍采用已有明确合同；音乐默认播放/队列偏好继续使用原有枚举。

## pi 复用与自有适配边界

固定依赖 `@earendil-works/pi-coding-agent@0.85.1`，MIT，Node >=22.19.0；包根公开导出与 `local-ai/package-lock.json` 已核对。依照锁文件执行 `npm ci --ignore-scripts --no-audit --no-fund`，未升级依赖。

查阅上游 `SessionManager`、`appendEntry`、`buildSessionContext`、`findCutPoint`、`generateSummaryWithUsage`、`serializeConversation` 以及 extensions/compaction/session-format 文档。会话管理与扩展条目不是现成的个人经历数据库；`appendEntry` 本身也不进入模型上下文。为记忆再建立一套 pi session 文件会重复本项目已有的历史和活动任务存储。

本次直接调用公开 `serializeConversation()` 将已选择的历史事实序列化为背景材料；SDK 实际路径由测试验证，不复制上游实现。已有 `assistant-compaction.mjs` 的 `findCutPoint`/`generateSummaryWithUsage` 继续负责长对话切分、迭代摘要，不添加平行摘要引擎。经历来自结构化执行回执，因此不额外调用模型抽取或猜测成功状态。

自有薄适配职责：领域回执白名单、个人偏好原文验证、SQLite 去重/生命周期、中文词法与范围/日期筛选、召回条数上限、SDK 输入投影。无向量服务和语义检索引擎；同义问法不保证命中。

## 数据与调用路径

- `history-store.event()` 在完整结果因大小截断前先提取有限经历字段，避免大搜索结果丢失查询事实；旧版已整体截断且没有字段的记录不猜测补回。它只在成功写入一个匹配 start 的首次 end 后返回已脱敏记录。`server.mjs` 将它交给 `memory.captureHistory()`；失败显示独立的记忆提示，不重放业务动作。
- `assistant-experience.mjs` 从允许的业务工具回执提取有限字段：应用、动作、查询、名称、回执文案、时间，以及可核对的歌手身份。排除候选集合、临时引用、版本、URL、凭证与任意工具数据。
- 复用 `memory_entries`，增加 `note` 和 `experience` 类型。经历 key 为原始工具回执 ID 的 SHA-256；相同回执重放或补充不重复写入。偏好按应用和归一化文本去重。
- `memory_meta` 原位增加 `remember_experiences`；旧库的歌手、偏好及开关保留，兼容旧客户端未传新增设置。
- 每次规划实时读取记忆快照，最多召回 5 条；`memory.recall` 独立返回经历。规划端重新验证类型/长度，再使用 pi 序列化。白名单排除可执行引用；材料作为背景数据，纳入现有 `prepareContext` 输入预算和传输上限。
- 无新增模型请求、模型重试或业务工具循环。继续服从 12 轮/12 工具/5 分钟、取消 guard、本机模型选择及现有网关。记忆服务故障时普通任务明确提示后继续；直接询问记忆时服务失败不会伪称“没有记忆”。

## 清理与保留

经历最多 300 条，保留时长为来源历史设置与 30 天的较小值；偏好最多 100 条。读取时清理过期经历；缩短历史期限会同步缩短现有经历期限，延长不会恢复已过期数据。

删除会话会同时删除关联歌手、偏好与经历；清空历史/记忆沿用来源墓碑和清空时间。新回执携带会话起始时间，清空前启动的会话不因迟到回执复活。单独删除经历另记回执 key 墓碑，手动补充历史也不会再次导入该条。不同真实调用可记录同一个人物的多次经历。
