# 快捷助手音乐真实调用修复（2026-09-16）

## 问题与证据

1. 歌手专辑接口错误地使用 `/api/artist/albums?id=6472`。不带浏览器 Cookie 的公开只读验证返回 HTTP 200、业务码400；正确的 `/api/artist/albums/6472?limit=3&offset=0&total=true` 返回业务码200及专辑数组。
2. 音乐控制器收到助手队列更新时只调用 `_updateUI()`，没有刷新 `_refreshPlaylist()` 对应的队列列表和计数；还错误地赋值 `_playlistName`，实际字段为 `_currentPlaylistName`。
3. 旧的两秒延迟保存可能覆盖新助手队列，造成持久化和展示不一致。修复会先核对缓存版本，再取消对应的旧保存任务。

## 改动

- 助手和现有音乐工作台优先使用带歌手ID的正确专辑路径。助手保留旧路径兼容，并在搜索回退时核对歌手ID，避免混入同名歌手。
- 请求失败显示实际接口与业务码，避免只返回笼统的“网易云请求未成功”。
- 队列同步使用正确名称、ID字段，同时刷新列表、计数和播放高亮；新缓存版本或手动切歌已变化时放弃旧更新。
- 添加后提供“查看当前播放队列”，从当前缓存读取真实曲目，方便核对。加入队列不等于立即播放，也不等于修改网易云云端歌单。

## 验证边界

- 使用修改后的生产 `AssistantMusic` 适配器调用真实公开接口，成功返回8张专辑候选；只读、未读取浏览器Cookie、未修改账号。
- 对真实控制器的队列刷新方法补回归：列表、计数、正确名称字段、播放高亮、旧延迟保存、新版本覆盖保护。
- 补充专辑ID路径、同名歌手排除及查看队列不重新搜索/播放的测试。
- 未代为重载扩展，未完成用户真实登录态的整个播放工作台验收。需重载扩展并刷新已有音乐主页，确保新控制器和后台同时生效。
