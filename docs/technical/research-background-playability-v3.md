# 背景可玩性实验 v3 — 调研结论与产品原则

## 目标

在保留 `test/demos/background-effects-v2/` 六个视觉基线 Demo 的前提下，验证一套可以复用于正式新标签页背景的“可玩性基础能力”。它不是新游戏，也不是持续抢占注意力的粒子层，而是一套只有用户主动唤醒才工作的轻量交互世界。

## 外部案例与启发

### Bruno Simon — 直接操控比观看动画更容易形成记忆

- 案例：https://bruno-simon.com/
- 用户通过驾驶小车探索内容，输入直接改变世界状态。
- 对本项目的启发：背景必须响应用户的意图，而不是只追随光标；拖、甩、按住等手势应产生不同物理结果。

### Patatap — 三秒学会，声音和视觉共用同一反馈语言

- 案例：https://patatap.com/
- 每次按键同时产生声音与动画，不需要教程即可建立因果关系。
- 对本项目的启发：声音默认关闭，但用户主动开启后，点击、蓄力、甩动和组合技应拥有不同且一致的音色。

### Silk — 操作必须留下“这是我创造的”痕迹

- 案例：http://weavesilk.com/
- 连续绘制会形成独一无二的生成艺术，而不是播放预制动画。
- 对本项目的启发：拖动生成弹性光带，轨迹由真实手势决定，并在一段时间后自然消散。

### Unity Game Feel — 渐进性、环境触发与统一反馈语言

- 案例：https://www.youtube.com/watch?v=yCKI9T3sSv0
- 重点包括微交互、反馈为什么重要、渐进反馈、环境触发和反馈语言。
- 对本项目的启发：同一手势先给即时反馈，再进入物理变化，最后累计能量并触发组合技；所有反馈使用同一套色彩、尺度、声音和衰减规则。

## v3 手势语法

| 手势 | 世界反馈 | 反馈层级 |
|---|---|---|
| 点击 | 脉冲波，推开附近光体 | 即时 |
| 拖动 | 生成由真实路径决定的弹性光带 | 连续 |
| 长按 | 生成短时引力核心，吸引世界中的光体 | 蓄力 |
| 快速甩动 | 发射带惯性的彗光 | 动量 |
| 双击 | 生成旋涡，改变附近光体轨道 | 高阶 |

## 可玩性循环

1. 用户完成一种手势，立即获得视觉反馈。
2. 首次发现该手势时点亮一枚发现徽章。
3. 连续操作累计世界能量，能量会缓慢衰减。
4. 收集五种手势或能量达到 100 时触发一次“世界共振”。
5. 12 秒无操作后回到安静背景，不继续制造视觉噪音。

## 正式接入边界

- 默认安静，必须显式唤醒可玩层。
- 声音默认关闭，只能由用户手势开启。
- 不在输入框、业务面板或 Dock 上捕获手势。
- 支持 `prefers-reduced-motion`、暂停和一键清空。
- 世界对象设置固定上限；页面隐藏时停止动画。
- v3 Demo 只验证手感，不直接进入生产首页。
