实现方案

同意架构师的方案。补充几点：

  • 使用 TypeScript 开发，编译为 ES Module
  • 游戏循环用 setInterval 更可控（固定 tick）
  • 蛇身用链表或数组均可，数组 + shift/push 足够
class SnakeEngine {
  tick() {
    this.move();
    this.checkCollision();
    this.checkFood();
  }
}
