关于这个扩展

中国风景时钟是一款精心设计的 Chrome 新标签页扩展。每次打开浏览器，你将看到一幅精选的中国风景壁纸、准确的实时时钟、农历日期、天气预报，以及强大的效率工具套件。

设计理念

我们相信工具应该既实用又美观。磨砂玻璃质感的界面设计，暗色主题减少视觉疲劳，每一个像素都经过精心打磨。功能不多不少，恰到好处。

"把新标签页变成你的个人仪表盘，在欣赏中国壮美风景的同时，高效管理你的工作和生活。"
— 中国风景时钟设计团队

上手指南

3 分钟即可上手
1

安装扩展 必要

从 Chrome Web Store 安装后，每次打开新标签页即自动显示中国风景时钟。无需额外配置，默认设置已满足大多数场景。

2

个性化配置 推荐

通过右下角工具栏的齿轮图标进入设置面板，按需开关各项功能。

  • 切换 12/24 小时制
  • 设置你所在的城市获取天气
  • 选择壁纸轮播频率
  • 开启或关闭农历、节假日显示
3

探索功能 推荐

  • 左侧备忘录面板 — 按 Ctrl+H 打开
  • 音乐播放器 — 底部工具栏音乐图标
  • 热搜资讯 — 底部工具栏火焰图标
  • 哔哩哔哩视频 — 底部工具栏 B 站图标
4

掌握快捷键 效率

  • Ctrl/⌘ + Shift + B — 切换壁纸
  • Ctrl + N — 新增任务
  • Ctrl + H — 备忘录面板
  • Space — 切换任务完成状态
5

Agent 矩阵 新功能

连接本地 Cursor Bridge 服务，同时运行多个 AI Agent 完成代码审查、功能实现、测试编写等任务。

  • 安装 cursor-bridge 后端服务
  • 配置 Native Host 连接
  • 使用命令面板 (⌘L) 快速创建 Agent

安装与配置

INFO 本扩展基于 Chrome Manifest V3 构建，使用 Service Worker 作为后台进程。安装后自动替换新标签页。
TIP 首次安装后建议配置天气城市。进入设置面板 → 天气 → 选择你的城市。默认使用浏览器地理定位。

存储与数据

INFO 用户设置存储在 chrome.storage.sync (100KB 限制)，备忘录数据存储在 chrome.storage.local (10MB 限制)。
WARN Agent 矩阵的对话历史存储在本地 SQLite 数据库 (cursor-bridge/data/)，卸载 bridge 服务将丢失历史数据。建议定期备份。
