架构师 架构 21.1s

技术选型：纯 TypeScript + Canvas API

SnakeEngine (pure logic)
  ├── Grid: 管理网格坐标
  ├── Snake: 蛇的状态 & 移动
  └── Food: 食物生成逻辑

CanvasRenderer (rendering)
  └── draw(state) → Canvas 2D

GameController (orchestrator)
  ├── 绑定键盘事件
  ├── 管理游戏循环
  └── 处理 UI 交互

测试策略：引擎层 100% 单元测试覆盖
