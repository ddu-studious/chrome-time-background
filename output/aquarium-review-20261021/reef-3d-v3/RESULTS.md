# 第三轮验收：完整浅礁的体型感知躲藏与绕行

开发目录沿用 2026-10-21；最终 Chrome 复核完成于 2026-10-22。入口 `http://127.0.0.1:18766/`，构建和关联源文件指纹见 `final-build-info.json`。只改隔离原型与相关文档，没有接入正式首页或真实数据。

## 本轮实际实现

- 完整浅礁的原始硬礁、砂床、碎石参与导航和碰撞；6,636 个三维节点、29,460 条无向候选边，包含 154 个上游公开开阔水域节点。
- Yuka A* 按个体保守转身净空筛图，连接点和简化后的路径经同一 BVH 复核。多层路线允许从侧面或上方绕过原始礁体，不再只在编排的两块石头间工作。
- 小鱼选择可达、失视且捕食者容不下的掩体，停留警戒后离开。大鱼按最后观测搜索可达位置，受失视和追逐总时限约束；无路不穿墙、不瞬移。
- UI 增加三个真实礁区、四档小鱼总长和三档捕食者总长；“开始完整浅礁演练”使用统一远景和 42% 造景范围，看清底部石拱。配置只在本页内存中，仍可调节和关闭造景。

## 体型矩阵

详表：[36 组矩阵](size-matrix.md)，原始数据 `size-matrix.json`，摘要 `matrix-summary.json`，代表轨迹与完整事件 `representative-traces.json`。三个区域 × 小鱼 2.5/4.0/6.0/7.4 cm × 捕食者 18/25/45 cm；同区域起点一致，每组种子 73、步长 1/60 秒、模拟 24 秒。

- 36 组中 27 组符合当前演示捕食资格；全部出现躲藏和搜索点到达。
- 9 组因猎物尺寸/口部横截面规则不合格，不发起捕食。
- 全部逐步检查为 0 个穿透姿态；单步最大位移约 5.68 mm，没有靠瞬移完成路线。
- 观察窗口内没有捕获；这些起点按几何条件选择可用掩体，未根据模拟结果筛选。不能据此声称一般场景捕获率为零。离开计数为 0 的组合照实保留，不补写为成功。

## 性能观察及边界

CPU-only 矩阵累计模拟 864 秒，实际执行约 3 秒；记录中的最大单次规划约 62 ms。没有运行 GPU 渲染，不能把它当成浏览器帧率。

Chrome 完整浅礁 + 2 条鱼 + 3 只三维水母，短样本约 27–30 fps、约 173 万三角形；任务完成后相应减少。提交耗时与规划峰值分开记录：浏览器规划曾到约 112 ms，重启演练的首次渲染提交也出现约 84 ms 峰值。并非每帧都如此，但仍可能看到短暂停顿；没有声称完成跨设备/GPU/能耗优化。原始数值见 `browser-cases.json` / `browser-final.json`。

当前数据针对固定版本完整硬礁，支持场景 Y 平移和已验证的体型范围；没有任意新模型的连续全空间导航或动态障碍。软珊瑚与海葵没有逐枝碰撞。导航和物理偏保守，窄弯会减速或停住转向。后台深度释放、真实账号、正式居民元数据迁移和扩展实际配置仍按 [落地清单](../../../docs/technical/ocean-habitat/validation-and-migration.md) 继续验收。
