全面了解中国风景时钟的功能和使用技巧

1

打开新标签页

安装扩展后，每次打开新标签页即显示中国风景时钟

个性化配置

开始使用

享受精美的中国风景壁纸、时钟、天气和效率工具

核心功能

  • 精美时钟 — 支持 12/24 小时制，显示农历和节假日
  • 中国风景壁纸 — 自动切换高清中国风景图，支持自定义间隔
  • 实时天气 — 当前天气、3 天预报、24 小时温度曲线
  • 节假日提醒 — 自动显示即将到来的节假日和调休信息

快捷键指南

  • Ctrl/⌘ + Shift + B — 切换背景壁纸
  • 点击时钟 — 展开/收起详细信息
  • 点击天气 — 展开温度曲线图
  • 右下角工具栏 — 快速访问各功能面板

任务管理

  • 任务面板 — 左侧常驻任务列表，支持分类、标签、优先级
  • 进度追踪 — 设置任务进度百分比，直观了解完成情况
  • 截止日期 — 到期自动提醒，过期任务高亮显示
  • 习惯打卡 — 支持每日/每周重复任务和习惯追踪
  • Markdown 备忘 — 支持完整 Markdown 语法和代码高亮

音乐播放器

  • 独立播放 — 无需打开音乐网站，浏览器登录过网易云即可
  • 歌单管理 — 浏览和播放个人歌单、每日推荐
  • 歌词同步 — 实时歌词显示，支持点击歌词跳转
  • 搜索 — 内置搜索，快速找到想听的歌曲
  • 播放模式 — 顺序、循环、单曲、随机四种模式

哔哩哔哩集成

  • Cookie 共享 — 自动共享浏览器登录状态，无需重复登录
  • 七大分类 — 热门、历史、稍后看、收藏、排行、课程、关注
  • 已购课程 — 直接访问已购买的 B站课堂课程
  • 关注列表 — 按分组浏览关注的 UP 主，一键查看最新视频
  • 沉浸播放 — 所有操作不离开当前标签页，关闭面板自动清除资源

热搜资讯

  • 多平台热搜 — 聚合微博、知乎、百度等热搜榜单
  • 实时滚动 — 双层信息栏，主卡片 + 迷你滚动条
  • 关键字监控 — 设置关注关键字，出现时自动通知
  • 收藏热搜 — 一键保存感兴趣的热搜为任务待看

扩展监控

  • 资源监控 — CPU、内存、磁盘实时占用率
  • 活动日志 — 扩展网络请求、任务操作等活动记录
  • 温情提示 — 定期推送名言金句和健康小贴士
  • 省电模式 — 按需关闭功能，降低资源占用
