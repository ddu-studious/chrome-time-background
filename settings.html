使用说明

全面了解中国风景时钟的功能和使用技巧

1

安装扩展 必要

从 Chrome Web Store 安装后，每次打开新标签页即自动显示中国风景时钟。无需额外配置，默认设置已满足大多数场景。

2

个性化配置 推荐

通过右下角工具栏的齿轮图标进入设置面板，按需开关各项功能。

  • 切换 12/24 小时制
  • 设置你所在的城市获取天气
  • 选择壁纸轮播频率
  • 开启或关闭农历、节假日显示
3

探索功能 推荐

  • 左侧备忘录面板 — 按 Ctrl+H 打开
  • 音乐播放器 — 底部工具栏音乐图标
  • 热搜资讯 — 底部工具栏火焰图标
  • 哔哩哔哩视频 — 底部工具栏 B 站图标
4

掌握快捷键 效率

  • Ctrl/⌘ + Shift + B — 切换壁纸
  • Ctrl + N — 新增任务
  • Ctrl + H — 备忘录面板
  • Space — 切换任务完成状态
5

Agent 矩阵 新功能

连接本地 Cursor Bridge 服务，同时运行多个 AI Agent 完成代码审查、功能实现、测试编写等任务。

  • 安装 cursor-bridge 后端服务
  • 配置 Native Host 连接
  • 使用命令面板 (⌘L) 快速创建 Agent

时钟与日期

实时时钟显示，支持 12/24 小时制切换，集成农历日期和节假日提醒。

  • 精确的实时时钟
  • 公历、农历双日历
  • 法定节假日与调休提醒
  • 二十四节气显示

天气预报

实时天气与三日预报，自动定位或手动设置城市。

  • 实时温度与体感温度
  • 空气质量指数 (AQI)
  • 三天天气预报
  • 支持手动设置城市

任务管理

完整的 GTD 工作流，分类、标签、优先级、截止日期一应俱全。

  • 多分类组织任务
  • 标签系统灵活标记
  • 高/中/低优先级
  • 截止日期与提醒
  • Markdown 备忘录
  • 每日习惯打卡

音乐播放

集成网易云音乐，无需切换标签页即可收听你的歌单。

  • 独立播放器，无需打开网站
  • 自动共享浏览器登录状态
  • 歌词同步显示
  • 顺序/循环/单曲/随机四种模式

热搜资讯

聚合微博、知乎、百度等多平台热搜，一站式了解热点。

  • 多平台热搜聚合
  • 实时更新榜单
  • 关键字监控通知
  • 一键收藏为待看任务

哔哩哔哩

在新标签页内浏览和播放 B 站视频，沉浸式体验。

  • Cookie 共享，无需重复登录
  • 七大分类浏览
  • 已购课程访问
  • 关注 UP 主列表
  • 沉浸式播放
