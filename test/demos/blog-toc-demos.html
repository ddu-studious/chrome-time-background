写作空间 — 目录导航 Demo

方案一 — 侧边栏固定目录（Notion 风格）

在文章详情右侧增加一个固定的目录面板。自动提取 ## 和 ### 标题，支持点击跳转、滚动高亮当前章节，底部有阅读进度条。适合长文阅读，目录始终可见。

    方案二 — 浮动迷你地图（VS Code 风格）

    在文章右上角浮动一个可折叠的目录卡片。不占据固定空间，点击展开后显示完整目录。圆点标记当前位置，可以一键折叠为小图标。适合不想浪费侧边空间的场景。

    方案三 — 顶部面包屑导航条

    在文章详情顶部增加一条面包屑，实时显示当前所在章节。点击可以展开完整目录下拉菜单。不占用侧边空间，保持阅读区最大化，适合宽屏和窄屏。

    方案四 — 左侧竖线指示器（Gitbook 风格）

    在文章左侧增加一条极简的竖线 + 圆点指示器。圆点对应各章节位置，悬停显示标题。滚动时高亮当前位置，黄色区间标记当前可见范围。不占额外空间，极简优雅。

    方案五 — 底部抽屉式目录（移动端优先）

    文章右下角浮动一个目录按钮，点击弹出底部抽屉。支持目录搜索和编号显示。点击跳转后自动收起。适合移动端和窄屏场景，不干扰正文阅读。
