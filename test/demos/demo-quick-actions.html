方案 A — 命令面板式（⌘K 触发）
按 ⌘ + K 或点击页面任意位置唤起命令面板
⌘K
内置命令
review — 代码审查
审查指定文件或目录的代码质量
review <path>
implement — 功能实现
根据描述实现新功能
implement <desc>
test — 测试编写
为指定模块生成测试
test <path>
refactor — 重构优化
分析并重构代码结构
refactor <path>
docs — 文档生成
生成项目或 API 文档
docs <path>
