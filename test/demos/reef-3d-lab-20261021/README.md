# 真三维海洋隔离原型

打开 http://127.0.0.1:18766/ 。这是独立 HTTP 实验页，未接入正式扩展，任务、居民、捕食离场都只存在本页内存中；刷新恢复初始样本。旧版对照在 18765。

## 体验

1. 选“转身观察”，切换侧面、3/4、正面、另一侧、俯视，检查同一条鱼的厚度。
2. 选“同深度尺标”：初始六条小丑鱼总长分别为 2.5、3.2、4.0、4.8、6.0、7.4 cm，横尺为 10 cm。该视图最多展示前六位居民，不改变其档案尺寸。
3. 选“遮挡检查（测试石）”：石前、石后、局部遮挡使用同一鱼体与不透明三维测试石，验证共享深度；这是暂停生态的诊断摆位，不冒充自然游动录像。
4. 回“自然游动”。固定礁景默认关，打开后可调整底部 20–42% 范围；关闭会同时撤掉造景颜色、深度和碰撞。
5. 喂食后观察“已吃饲料”计数；抓鱼移到别处，或拖到底部网兜捞出。任务水母仍按原交互拖入右下纸篓完成，任务不会进入捕食集合。
6. 打开“启用追逃测试”，比较 18 cm 与 45 cm 尖吻鲈。存在追击、逃跑、失视/超时放弃和口部接触捕获。捕获是陪伴模式中的暂时离场，25 秒后回场，居民档案保留。大鱼不保证每次抓到小鱼。
7. “居民与验证信息”可显示命中标记、资源统计与最近事件；“重置演示”恢复初始场景。

在仓库根目录：

```sh
npm --prefix test/demos/reef-3d-lab-20261021 ci --ignore-scripts
npm --prefix test/demos/reef-3d-lab-20261021 run build
node test/demos/reef-3d-lab-20261021/server.mjs
npm --prefix test/demos/reef-3d-lab-20261021 test
```

服务仅绑定 127.0.0.1，只提供固定白名单文件。修改源代码并构建后需重启服务、重新加载页面；服务启动时冻结文件内容。构建依赖使用现有 `local-ai/node_modules/esbuild@0.28.1`。

## 技术边界

- 世界统一米制；上游渲染坐标为分米，适配层统一乘 10。实体尺寸只在建档时决定，镜头和 LOD 不改尺寸。体长口径为 TL；上游小丑鱼实测模型 TL=1.25、SL≈0.98 分米。尺寸梯度是演示 fixture，不是野生年龄分布；没有捏造幼年/成年年龄或加速成长。
- 三维小丑鱼直接复用 Deskworlds 的几何、实例化与鱼鳍/尾部 shader。尖吻鲈是静态 glTF 加尾部变形，不含下颌骨骼或吞咽动画。该组合用于追逃程序验证，不宣称典型浅海珊瑚礁共栖关系。
- Yuka 只计算转向力；OceanWorld 是位置唯一所有者，固定步长 1/60 秒、最多补 4 步。原项目资格判断、随机生成器、食谱成本、追逐/休息/捕获间隔/补员和喂食限额被复用。原二维 FSM 依赖二维世界，隔离页用最小三维状态适配；没有修改正式捕食核心。
- 实体礁石/砂地/碎石使用 BVH 查询。鱼用保守胶囊体，平移与转动均有有限步姿态检查，超过采样预算拒绝位移。它不是精确连续碰撞求解器，不是流体或刚体动力学；珊瑚软枝、海葵触手未单独建立硬碰撞。
- 躲藏只做有尺寸净空、可达、对捕食者失视的局部候选搜索；复杂礁洞全局寻路和稳定自然钻洞尚未验收。捕食者不会隔实体礁石捕获，用户正在抓取的对象撤出生态。
- 拖拽时鱼临时位于可见交互层，释放恢复正常深度；非法放置回到合法点。任务水母仍为原 2D 交互层，任务所有权与完成回执不搬入三维世界。
- 最多 40 条鱼、24 粒饲料、80 条事件；渲染上限约 30 fps，焦散约 10 Hz，像素上限约 170 万。帧率与 CPU 提交数不是 GPU 耗时或整页功耗。

结果、截图、追逃固定种子轨迹见 `output/aquarium-review-20261021/reef-3d-lab/`；阶段验收与仍待验证项见仓库执行计划。正式接入、居民元数据迁移、全部动物、真实年龄档案、精确物理和跨设备性能未完成。
