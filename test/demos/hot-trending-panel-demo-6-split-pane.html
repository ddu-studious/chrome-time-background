📖 README 预览

Claude Code is an agentic coding tool that lives in your terminal, understands your codebase, and helps you code faster by executing routine tasks, explaining complex logic, and writing code.

🚀 Quick Start

Install globally using npm:

npm install -g @anthropic-ai/claude-code

Then navigate to your project directory and run:

claude

✨ Features

- Context Aware: Automatically reads your files, finds references, and understands your project structure.
- Command Execution: Can run tests, linters, and git commands to verify its own work.
- Agentic Loop: It doesn't just write code; it writes, tests, fixes errors, and iterates until the task is complete.
