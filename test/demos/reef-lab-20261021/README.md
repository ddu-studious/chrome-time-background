# 浅海珊瑚礁隔离 Demo

只用于研究与体验，不是正式扩展入口。所有居民与任务都是本页内存中的演示数据，刷新即重置。

## 启动

在仓库根目录执行：

```sh
node test/demos/reef-lab-20261021/server.mjs
```

打开 <http://127.0.0.1:18765/>，案例索引为 <http://127.0.0.1:18765/research.html>。

造景默认关；点开后显示真实 3D 珊瑚礁，可调底部 20%–42%。右下角“鱼”按钮提供原有喂食与居民操作。拖鱼到网兜可捞出，拖任务水母到纸篓可完成演示任务。暂停时只观察，继续游动后恢复交互。

默认背景为示例，不读取或修改正式扩展的背景。可切换预设，也可通过文件选择器选本地 PNG/JPEG/WebP（不上传、不保存；自动化文件选择本轮被连接器权限阻止，未验收）。

## 重新打包

```sh
node test/demos/reef-lab-20261021/build.mjs
```

复用已有 local-ai/node_modules 中锁定的 esbuild 0.28.1。启动服务器时会读入文件，修改后需重启服务并刷新页面。预生成 bundle 已包含在目录中，正常体验无需重新构建。

原型只复用 Deskworlds 的造景导出，不引入其完整入口或仿真。详见 [NOTICE.md](NOTICE.md)、[upstream-lock.json](upstream-lock.json) 和[研究与验证报告](../../../docs/research/research-aquarium-reef-lab-20261021.md)。

已知限制：原有动物是 2D，尚无鱼与 3D 礁石的遮挡、碰撞或栖息行为；不是完整生态系统。造景资源约 17.47 MB，未作为正式发布包预算。真实扩展、真实任务账号、触屏与长期 GPU/电量未验收。
