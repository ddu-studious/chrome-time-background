UI 组件一致性审计

可视化对比项目中所有面板/弹窗的实际样式，发现不一致并提出统一方案

✅ A 方案 — 标准磨砂玻璃（推荐基准）
备份面板 ✅ 标准

数据备份

半透明白色渐变 + 完整磨砂效果。背景风景隐约可见，层次感好。这是推荐的标准方案。

rgba(255,255,255,0.08) blur(24px) saturate(180%) r16px
日历面板 ✅ 标准

日历

同样的半透明磨砂方案。圆角 20px 略大，含 inset 高光。与备份面板一致度高。

rgba(255,255,255,0.08) blur(24px) saturate(180%) r20px
浮动备忘录面板 ✅ 标准

备忘录

标准磨砂 + 顶部高光边框(0.25)。关闭按钮 26px（比标准小）。

rgba(255,255,255,0.08) blur(24px) border-top 0.25 close 26px
⚠️ B 方案 — 深色实底（背景不可见）
番茄钟面板 ❌ 无磨砂

番茄钟

深色实底 0.98 透明度，几乎不透明。完全无磨砂效果，看不到背景风景。

rgba(40,40,50,0.98) 无 backdrop-filter r20px
统计面板 ❌ 无磨砂

任务统计

与番茄钟完全相同的深色实底。缺少磨砂效果，与标准方案差异明显。

rgba(40,40,50,0.98) 无 backdrop-filter r20px
关于面板 ⚠️ 有磨砂但色偏

关于

有磨砂效果但背景色偏深蓝(30,35,50)，不是标准的半透明白色渐变。

rgba(30,35,50,0.95) blur(24px) saturate(180%)
🔴 C 方案 — 特殊/遗留样式
设置面板 ❌ 完全不同

设置

纯黑底 0.8、无边框、低 blur(20px)、无 saturate。明显是早期代码，与其他面板风格完全不同。

rgba(0,0,0,0.8) blur(20px) 无saturate 无边框 无圆角

新建任务
