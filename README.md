# 中国风景时钟 Chrome扩展

一个展示时间、日期、天气和精美中国风景的Chrome新标签页扩展。

## 版本

当前版本：2.3.0

## 功能特点

- 显示当前时间和日期（支持12/24小时制切换）
- 显示农历日期
- 显示节假日信息
- 精美的中国风景背景图片轮播（支持自定义背景切换间隔）
- 实时天气信息显示（支持摄氏度/华氏度切换）
- 多语言支持（中文/英文）
- 备忘录功能（支持创建、编辑、删除和分类管理）
- 每日任务管理（支持截止时间、提醒通知、快速推迟）
- **书签智能检索**（Embedding 向量搜索 + BM25 关键词 + RRF 混合融合）
- **智能查询理解**（中英文混合分词 + 停用词过滤 + 自然语言搜索）
- **LLM 精排**（AI 重排序搜索结果 + 网页摘要抓取）
- **Spotlight 快捷搜索**（Ctrl+K 全局唤出）
- **贪吃蛇小游戏**（Dock 一键打开，支持方向键/WASD 与暂停）
- 磨砂玻璃效果的现代界面设计
- 平滑的背景切换动画
- 用户自定义设置

## 安装方法

1. 克隆本仓库到本地
2. 打开Chrome浏览器，进入扩展管理页面（chrome://extensions/）
3. 开启开发者模式
4. 点击"加载已解压的扩展程序"，选择本项目目录

## 使用指南

- 点击设置图标打开设置面板
- 可以自定义时间格式、温度单位、背景切换间隔等
- 点击备忘录图标打开备忘录面板
  - 点击"+"按钮添加新备忘录
  - 点击编辑按钮修改现有备忘录
  - 点击删除按钮删除备忘录
  - 备忘录支持按工作、生活、学习和其他进行分类
- 按 Ctrl/⌘ + Shift + B 键可以手动切换背景图片
- 点击刷新按钮可以立即更新天气信息
- 点击语言切换按钮可以切换显示语言
- 点击右下角工具栏的手柄图标可打开贪吃蛇小游戏
  - 方向键 / WASD 控制方向
  - 空格键暂停/继续
  - 支持随时重新开始

### 贪吃蛇规则层用例表（随 engine 变更同步）

| 用例ID | 规则点 | 前置状态 | 操作 | 期望结果 |
| --- | --- | --- | --- | --- |
| SG-RULE-001 | 初始化一致性 | 新建 game core | `getState()` | 蛇长=3、方向=`RIGHT`、`score=0`、`gameOver=false`、食物不与蛇重叠 |
| SG-RULE-002 | 移动一致性 | 初始状态，食物放远处 | `tick()` | 头部向前一格、长度不变、分数不变 |
| SG-RULE-003 | 180° 反向限制 | 初始朝向 `RIGHT` | `setDirection('LEFT')` 后 `tick()` | 设置被拒绝，实际方向保持 `RIGHT` |
| SG-RULE-004 | 吃食物增长与计分 | 食物放在头部前方 | `tick()` | `score +1`，蛇长 `+1`，食物重生 |
| SG-RULE-005 | 撞墙终局冻结 | 小网格持续前进到边界 | 连续 `tick()` | 触发 `gameOver=true`，后续 `tick()` 状态不再变化 |
| SG-RULE-006 | 自撞终局 | 构造回字形蛇身 | 调整方向并 `tick()` | 头部撞到身体后 `gameOver=true` |
| SG-RULE-007 | 重开一致性 | 经历若干步后 | `reset()` | 回到初始可玩态（含方向、分数、蛇身、食物位置规则） |
