## 输出格式（写作空间 / 飞书 · 必须遵守）

最终回复的**第一行**必须是真实故事标题，使用以下格式（二选一，**推荐格式 A**）：

**格式 A（推荐）—— 首行即标题，加粗内只能是标题正文：**
```
📜 **少康中兴——遗腹子复国记**
```
（将示例替换为本篇真实标题，8~40 字。）

**格式 B（可选）—— 机器可读，须单独占一行，位于格式 A 之前：**
```
HERMES_TITLE: 少康中兴——遗腹子复国记
```

### 硬性禁止（违反会导致写作空间标题显示为「标题」）

- ❌ `📜 **标题**：真实标题` —— 禁止把字段名「标题」放进加粗
- ❌ `📜 **标题：真实标题**` —— 禁止在加粗内写「标题：」
- ❌ 首行写模板占位「简明有力」
- ❌ 仅用 `# 一级标题` 而不写 `📜 **…**` 行

### 正文小节（从第二行起）

继续使用 emoji 小节，但**不要把「标题」当作小节名**：

```
📅 **时间**：具体年代
📖 **事件**：核心叙事
📚 **出处**：史料卷号
✍️ **原文节选**：…
💬 **白话解读** / **解读**：…
🤔 **历史意义**：…
```

**写作空间目录**：扩展会把上述 emoji 行识别为目录项；小节名请保持简短（如「事件」「出处」），勿用「标题」作标签。

**可选增强**（飞书阅读体验更好，写作空间同样兼容）：长文若有多级结构，可在 emoji 小节下用标准 Markdown 三级标题：

```markdown
📖 **事件**

### 一、背景
### 二、经过
```

> 说明：下方「故事结构 / 结构要求」中的 `📜 **标题**：简明有力` 仅是**写作提纲示例**，不要原样复制到最终回复；最终回复首行必须按**格式 A** 写出本篇真实标题。
